五、第 2 步：算总分与平均分（写成函数）

总分 = 三科相加。但不要到处写 stu['语文'] + stu['数学'] + stu['英语']——那是「以后改科目要改很多处」的写法。包成函数（第 22 篇）：

Python
1234567891011121314151617181920212223
# 准备数据
import csv
open('scores.csv', 'w', encoding='utf-8').write(
    '姓名,语文,数学,英语\n张三,88,92,79\n李四,76,72,78\n王五,95,88,84\n')
with open('scores.csv', encoding='utf-8') as f:
    rows = list(csv.reader(f))
SCORE_KEYS = ['语文', '数学', '英语']
students = [{'姓名': r[0], '语文': int(r[1]), '数学': int(r[2]), '英语': int(r[3])}
            for r in rows[1:]]


def total(stu):
    """三科总分。"""
    return sum(stu[key] for key in SCORE_KEYS)


def average(stu):
    """三科平均分，保留一位小数。"""
    return round(total(stu) / len(SCORE_KEYS), 1)


for stu in students:
    print(stu['姓名'], total(stu), average(stu))

输出：

输出
123
张三 259 86.3
李四 226 75.3
王五 267 89.0

两处小讲究：

写法作用
sum(stu[key] for key in SCORE_KEYS)循环里只写一遍 stu[key]；以后加一门「物理」，只改 SCORE_KEYS 就行
round(..., 1)平均分 86.33333… 没法看，保留一位小数。round 是第 9 篇学过的内置函数
total(stu) 里再调 average函数调函数很正常；不要为了让「看起来快」而复制一遍求和代码
函数名 total 和变量名不冲突，但为了读起来不别扭，通常把「算」的那部分叫 total()，把「存」的那部分叫 total_score。名字起对了，代码解释自己。

六、第 3 步：按总分排名次

排名不需要自己写排序算法（第 16 篇讲过 sorted），把「按什么排」用 key 告诉它就行：

import csv
open('scores.csv', 'w', encoding='utf-8').write(

students = [{'姓名': r[0], '语文': int(r[1]), '数学': int(r[2]), '英语': int(r[3])}
            for r in rows[1:]]


def total(stu):
    return sum(stu[key] for key in SCORE_KEYS)


ranked = sorted(students, key=total, reverse=True)

for i, stu in enumerate(ranked, start=1):
    print(i, stu['姓名'], total(stu))

三个易错点，一眼扫过去：

写法对 / 错原因
key=total✅ 对传的应该是函数本身；sorted 会拿每个元素去调它
key=total()❌ 错加了括号就是立刻调用，此时还没传参数，直接 TypeError
enumerate(ranked, start=1)✅ 对start=1 让名次从 1 开始，而不是默认的 0
sorted(students, key=total, reverse=True) 用的是总分排序，但列表里装的仍然是学生字典——排的是顺序，不是把学生变成了分数。这点想通，后面「既要名次又要姓名」就不别扭了。

把 LEVELS 从高到低排，第一个满足 avg >= low 的就是答案——这叫「查表」，比写一堆 if/elif 短得多，也不容易漏档。

接下来数人数。第 20 篇说过字典能当「计数器」，核心就一句 counts[x] = counts.get(x, 0) + 1：

Python
123456789101112131415161718
LEVELS = [('优秀', 90), ('良好', 80), ('中等', 70), ('及格', 60), ('不及格', 0)]


def level_of(avg):
    for name, low in LEVELS:
        if avg >= low:
            return name
    return '不及格'


avgs = [96.0, 89.0, 86.3, 75.3, 66.7, 58.0]
counter = {}
for avg in avgs:
    grade = level_of(avg)
    counter[grade] = counter.get(grade, 0) + 1

for name, _ in LEVELS:                    # 按固定顺序打印，哪怕某档是 0 人
    print(name, counter.get(name, 0), '人')

输出：

输出
12345
优秀 1 人
良好 2 人
中等 1 人
及格 1 人
不及格 1 人
写法为什么这么写
counter.get(grade, 0)第一次见到「优秀」时字典里还没有这个键，get 给个默认 0，不然直接 counter[grade] += 1 会 KeyError
for name, _ in LEVELS 而不是 for name in counter字典只存「出现过的档」，直接遍历会漏掉 0 人的档，报表就不完整了
_ 当下划线变量名表示「这个位置有值，但我不用它」——一种通用约定，别人一看就懂
统计这件事，还有一条更省事的写法：collections.Counter。Counter(等级列表) 一步到位。本页用手写循环，是因为它把 get 的用法讲透了；真实项目里你自己选顺手的那个。

解决办法也简单：自己写一个按显示宽度补齐的小函数（中文算 2 格）：

1234567891011121314151617181920
def pad(text, width, align='<'):
    """按『显示宽度』补齐：中文占两格，半角占一格。"""
    shown = sum(2 if ord(ch) > 127 else 1 for ch in text)
    gap = max(0, width - shown)
    if align == '<':
        return text + ' ' * gap
    return ' ' * gap + text


COLS = [('名次', 4, '>'), ('姓名', 6, '<'), ('总分', 6, '>'),
        ('平均分', 7, '>'), ('等级', 6, '<')]


def row_line(values):
    return '  '.join(pad(str(v), w, a) for v, (_, w, a) in zip(values, COLS))


print(row_line([name for name, _, _ in COLS]))
for i, (name, score) in enumerate([('钱七', 288), ('张三', 259), ('孙八', 174)], start=1):
    print(row_line([i, name, score, '%.1f' % (score / 3), '优秀']))

ensure_ascii=False 千万别漏。默认值 True 会把中文写成 \u94b1\u4e03 —— 文件本身没错，程序读回来也正确，但人打开一看全是乱码样的字符，等于白存。indent=2 让它带缩进，人能直接看懂结构；给程序读时省不省缩进无所谓，你随意。

十、把六步收成一个完整程序

现在把上面六步装进一个文件。关键是函数各管一件事，最后用一个 main() 串起来：

函数只干一件事
load_students(path)把 csv 读成学生字典的列表
total(stu) / average(stu)算一个人的总分 / 平均分
level_of(avg)把平均分翻译成等级
pad() / row_line()把一行数据摆成正的
build_report(students)排序 + 算出每个人的结果，返回报表和结果列表
save_csv() / save_json()各存一种格式
main()按顺序把它们叫一遍

文件末尾加两行——这是第 27 篇《模块与包》里讲过的入口约定：

Python
12
if __name__ == '__main__':
    main()

它保证：直接运行这个文件时程序会跑；但如果别人 import 你的文件，main() 不会自作主张地执行。少了这两行，别人一 import 你的模块，你的程序就在他那儿闷头打印一通报表。

看到没——整篇没有一句新语法。这次真正的新东西只有「顺序」：先定数据结构，再读数据，再算，再排，再统计，再输出，最后存盘。顺序对了，代码就是可读的。

十一、加一层保险：文件不在、格式不对怎么办

import csv
import json

SCORE_KEYS = ['语文', '数学', '英语']
LEVELS = [('优秀', 90), ('良好', 80), ('中等', 70), ('及格', 60), ('不及格', 0)]


def load_students(path):
    """读 csv，返回「学生字典」的列表。"""
    with open(path, encoding='utf-8') as f:
        rows = list(csv.reader(f))
    students = []
    for r in rows[1:]:                     # 跳过表头
        stu = {'姓名': r[0]}
        for key, value in zip(SCORE_KEYS, r[1:]):
            stu[key] = int(value)          # 读出来是字符串，必须转成整数
        students.append(stu)
    return students


def total(stu):
    """三科总分。"""
    return sum(stu[key] for key in SCORE_KEYS)


def average(stu):
    """三科平均分，保留一位小数。"""
    return round(total(stu) / len(SCORE_KEYS), 1)


def level_of(avg):
    """按平均分给一个等级。"""
    for name, low in LEVELS:
        if avg >= low:
            return name
    return '不及格'


def pad(text, width, align='<'):
    """按『显示宽度』补齐：中文占两格，半角占一格。"""
    shown = sum(2 if ord(ch) > 127 else 1 for ch in text)
    gap = max(0, width - shown)
    if align == '<':
        return text + ' ' * gap
    return ' ' * gap + text


COLS = [('名次', 4, '>'), ('姓名', 6, '<'), ('总分', 6, '>'),
        ('平均分', 7, '>'), ('等级', 6, '<')]


def row_line(values):
    return '  '.join(pad(str(v), w, a) for v, (_, w, a) in zip(values, COLS))


def build_report(students):
    """返回 (报表文本行, 每人的结果字典)。"""
    ranked = sorted(students, key=total, reverse=True)
    lines = [row_line([name for name, _, _ in COLS])]
    rows = []
    for i, stu in enumerate(ranked, start=1):
        avg = average(stu)
        grade = level_of(avg)
        rows.append({'名次': i, '姓名': stu['姓名'], '总分': total(stu),
                     '平均分': avg, '等级': grade})
        lines.append(row_line([i, stu['姓名'], total(stu),
                               '%.1f' % avg, grade]))
    return lines, rows


def save_csv(rows, path):
    with open(path, 'w', newline='', encoding='utf-8') as f:
        writer = csv.writer(f)
        writer.writerow(['名次', '姓名', '总分', '平均分', '等级'])
        for r in rows:
            writer.writerow([r['名次'], r['姓名'], r['总分'], r['平均分'], r['等级']])


def save_json(rows, path):
    with open(path, 'w', encoding='utf-8') as f:
        json.dump(rows, f, ensure_ascii=False, indent=2)


def main():
    students = load_students('scores.csv')
    lines, rows = build_report(students)
    for line in lines:
        print(line)

    counter = {}
    for r in rows:
        counter[r['等级']] = counter.get(r['等级'], 0) + 1

    scores = [stu[key] for stu in students for key in SCORE_KEYS]
    print()
    print('全班 %d 人 · 平均总分 %.1f · 平均分 %.1f'
          % (len(rows), sum(r['总分'] for r in rows) / len(rows),
             sum(scores) / len(scores)))
    print(' · '.join('%s %d 人' % (name, counter.get(name, 0))
                     for name, _ in LEVELS))
    top, low = rows[0], rows[-1]
    print('最高分 %.1f（%s）· 最低分 %.1f（%s）'
          % (top['平均分'], top['姓名'], low['平均分'], low['姓名']))

    save_csv(rows, 'report.csv')
    save_json(rows, 'report.json')


if __name__ == '__main__':
    main()

十三、进阶：用类重写数据层（选学）

到此为止，程序里的「一个学生」都是用字典装的：{'姓名': '张三', '语文': 88, ...}。字典够用，但有个隐患——字段名是字符串，手一抖写成 row['数學']，写入的时候一声不吭，要等到取值运算那一刻才炸。学完《30-面向对象编程》之后，可以做得更好：把「一个学生」升级成一个 Student 对象，让数据和对数据的操作住进同一个类。

总分、平均分不再是散落在外的普通函数，而是 Student 自带的能力——这正是第 30 篇说的封装。现在把前面「读进来 → 排名 → 打印」的主流程用类重写一遍：

import csv

class Student:
    def __init__(self, name, chinese, math, english):
        self.name = name
        self.chinese = chinese
        self.math = math
        self.english = english

    def total(self):
        return self.chinese + self.math + self.english

    def average(self):
        return self.total() / 3

    def __str__(self):
        return f'{self.name}\t{self.total()}\t{self.average():.1f}'

# 造一份成绩单（真实使用时它已经在磁盘上）
open('scores.csv', 'w', encoding='utf-8').write(
    '姓名,语文,数学,英语\n张三,88,92,79\n李四,76,72,78\n'
    '王五,95,88,84\n赵六,60,72,68\n钱七,100,96,92\n孙八,55,61,58\n')

students = []
with open('scores.csv', encoding='utf-8') as f:
    for row in csv.DictReader(f):
        students.append(Student(row['姓名'], int(row['语文']),
                                int(row['数学']), int(row['英语'])))

students.sort(key=lambda st: st.total(), reverse=True)
for i, st in enumerate(students, 1):

两种写法跑出来的排名完全一致——类没有改变程序做什么，只是把代码摆得更整齐：「一个学生」的身份数据和它的算法（总分、平均分）从此住在一起，主流程里剩下的全是「管一群人」的活儿。

什么时候不必用类？字段只有两三个、写完就丢的一次性脚本，字典照样轻快。当字段越来越多、每个字段都要配算法（算平均、判及格、评等级），或者同一个「学生」要在好几个函数之间传来传去时，类的收益才真正显出来。
类版还有个实用的小好处：字典的键打错了，编辑器毫无反应；而对象的属性打错了，TraeCode 当场就画红线（第 4 篇的 AI 助手也能一眼看出来）。错误暴露得越早，越好找。

十六、常见问题

Q：为什么非要拆成这么多函数？一个 main() 从头写到尾不行吗？
能跑，但改起来痛苦。拆开之后，「平均分算法变了」只动 average()，「报表要加一列」只动 COLS 和 row_line()。更实际的好处是：每个函数都能单独测——你可以在同一文件里随手写 print(total({'语文':88,'数学':92,'英语':79})) 验证它是 259，不用先读一遍文件。

Q：scores.csv 有三四十个学生、还有缺考的，怎么改？

1用 csv.reader 读出来的成绩，想拿去做加法，必须先做什么？

2sorted(students, key=total, reverse=True) 里的 key=total 为什么不能写成 key=total()？

  • A. 两者完全一样，写哪个都行
  • B. key 要的是函数本身；加了括号会立刻调用并因缺参数报错
  • C. total() 会返回一个新列表，没法排序
  • D. 只有 sorted 有这个限制，list.sort 没
答案：B。sorted 会拿着每个元素去调用你给的函数，所以传的是函数本身。写成 total() 是在定义时就调用它，此时没有 stu 参数，直接 TypeError。要传参数就用 key=lambda s: s['数学']。

答案：C。不写 start=1 时 enumerate 给的编号从 0 开始，名次就会是 0、1、2…… 排序不变，只是编号的起算点变了。

  • C. 把 g 的值设成 0
  • D. 取不到 g 这个键时返回默认值 0，避免 KeyError
答案：D。第一次遇到某个等级时字典里还没有这个键，直接 counter[g] += 1 会抛 KeyError；get(g, 0) 在键不存在时给个 0，正好当计数器用。
