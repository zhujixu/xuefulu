一、程序的骨架：输入 → 处理 → 输出

写程序，其实就是在重复做三件事：拿到数据 → 算一算 → 把结果说出来。这套思路有个名字叫 IPO。

字母英文中文Python 里靠谁
IInput输入：拿到数据input()，问用户要
PProcess处理：算一算变量、运算、判断、循环
OOutput输出：把结果说出来print()，打印到屏幕

像一家小工厂：输入是原材料，处理是加工，输出是成品。

Python
12345678
# 输入：问用户要一个名字
name = input("请输入你的名字：")

# 处理：在名字后面接一句问候
greeting = "你好，" + name + "！"

# 输出：把结果打印出来
print(greeting)

运行效果（“张三”是你自己敲进去的）：

输出
12
请输入你的名字：张三
你好，张三！
这一篇只讲两头的 I 和 O。中间那个 P（处理），等你学了运算、条件、循环再慢慢补上。

二、输出：print() 的三招

print() 的作用只有一个：把东西打印到屏幕上。括号里放什么，屏幕上就出现什么。

第一招：打印一段文字

文字要用引号包起来，单引号、双引号都行。

Python
12
print("Hello Python")
print('你好，Python')      # 用单引号也一样
输出
12
Hello Python
你好，Python

第二招：一次打印好几个内容

用逗号隔开就行。注意一个细节：逗号会自动变成一个空格。

Python
1
print("姓名：", "李四", "年龄：", 28)
输出
1
姓名： 李四 年龄： 28
看到 姓名： 后面多出来的那个空格了吗？那是逗号带来的。想换成别的分隔符，就要用下一节讲的 sep。

第三招：打印变量和数字

变量不用加引号；数字也不用。

Python
12345
score = 95.5
print("你的考试分数是：", score)

print(100)          # 数字直接写，不加引号
print(3 + 5)        # 还能让它先算再打印
输出
123
你的考试分数是： 95.5
100
8
记一个区别：print("100") 和 print(100) 在屏幕上看着一模一样，但前者是文字、后者是数字。现在看不出差别，等它要参与计算时就分家了。

三、输出的两个小开关：sep 和 end

print() 有两个可以调的“开关”。写法都是“名字 = 值”，放在括号的最后面。

开关一：sep —— 管逗号之间用什么隔开

默认是一个空格，可以换成别的。sep 是 separator（分隔符）的缩写。

Python
12345
print("苹果", "香蕉", "橙子")               # 默认：空格分隔
print("苹果", "香蕉", "橙子", sep=", ")      # 用逗号加空格
print("2026", "09", "20", sep="-")           # 用短横线
print("www", "python", "org", sep=".")       # 用点，拼出网址
print("abc", "def", sep="")                  # 什么都不加，直接连起来
输出
12345
苹果 香蕉 橙子
苹果, 香蕉, 橙子
2026-09-20
www.python.org
abcdef

开关二：end —— 管这一行末尾加什么

默认是 end="\n"，也就是打印完自动换到下一行（\n 就是“换行”的意思）。把 end 改掉，就能让它不换行。

Python
123456789
print("第一句", end=" ")        # 末尾换成空格，不换行
print("第二句跟在后面")

print("今天天气不错", end="！\n")
print("适合出门散步")

for i in range(1, 5):
    print(i, end=", ")           # 数字连着打印，用逗号隔开
print()                          # 最后补一个换行
输出
1234
第一句 第二句跟在后面
今天天气不错！
适合出门散步
1, 2, 3, 4,
两个开关可以一起用：print("a", "b", sep="-", end="。\n") 会输出 a-b。。顺序不影响结果，但习惯上把 sep 写在 end 前面，读起来更顺。

四、把变量填进句子里：f-string

前面写 print("你的考试分数是：", score)，多出来的空格有点难看。如果想把变量直接塞进一句话中间，就要用 f-string。

怎么写

在引号前面加一个小写字母 f，然后用大括号 {} 把变量圈起来。f 是 format（格式化）的缩写。

Python
123
name = "王五"
age = 30
print(f"我的名字是{name}，今年{age}岁")
输出
1
我的名字是王五，今年30岁
两个细节别忘：① 引号前面必须有那个 f，漏了的话 {name} 会原样打印出来；② 大括号里的名字要和变量名一模一样，大小写都不能差。

大括号里还能直接算

Python
12345678
height = 1.75
print(f"明年我的身高可能是{height + 0.05}米")
print(f"3 加 5 等于 {3 + 5}")

item = "笔记本"
price = 12.5
count = 3
print(f"{item} {count} 本，一共 {price * count} 元")
输出
123
明年我的身高可能是1.8米
3 加 5 等于 8
笔记本 3 本，一共 37.5 元

控制小数位数

算出来的小数经常长得难看：10 / 3 会得到 3.3333333333333335。用 :.数字f 就能规定留几位。

Python
123456
print(f"{10 / 3:.1f}")      # 保留 1 位小数
print(f"{10 / 3:.2f}")      # 保留 2 位小数
print(f"{10 / 3:.0f}")      # 不留小数（会四舍五入）

price = 5.9
print(f"价格：{price:.2f} 元")
输出
1234
3.3
3.33
3
价格：5.90 元
记法：: 后面写 .1f 就是“小数点后 1 位”。注意它写在大括号里面，紧跟在变量后面，别写到括号外面去。
顺便认一下 r 前缀：加在引号前面表示“原样显示，别翻译转义符”，写 Windows 路径时特别有用。print(r"C:\new\temp") 会老老实实输出 C:\new\temp；不加 r 的话，\n 会被当成换行、\t 会被当成制表符。两个前缀还能合用，写成 fr"C:\Users\{name}\a.txt"。

五、两种老写法（看懂就行）

f-string 是现在最推荐的方式。但你在别人的代码里还会碰到另外两种，认识一下就好——自己写的时候优先用 f-string。

写法长什么样特点
f-string（推荐）print(f"名字：{name}")变量就写在它出现的位置，最直观
% 格式化（老写法）print("分数：%.1f" % score)要在句尾用 % 接上值，位数写在前面的占位符里
format()print("姓名：{}".format(name))句尾挂一串 .format(...)，变量一多就容易数错顺序
Python
123456
score = 88.5
name = "赵六"

print(f"分数：{score:.1f}")                          # 推荐
print("分数：%.1f" % score)                           # 老写法
print("姓名：{}，分数：{:.1f}".format(name, score))    # format()
输出
123
分数：88.5
分数：88.5
姓名：赵六，分数：88.5
三种写法结果完全一样。选 f-string 的理由很实在：变量就写在它出现的位置，一眼就能看出这句话最后会变成什么样。

六、输入：input() 收进来的都是文字

input() 的作用是停下来等用户打字。用户敲完按回车，程序才继续往下走。

Python
12
name = input("请输入你的姓名：")
print("你输入的姓名是：", name)
输出
12
请输入你的姓名：张三
你输入的姓名是： 张三

括号里那句话叫“提示语”，会显示在屏幕上，告诉用户该输什么。也可以什么都不写：

Python
12
s = input()        # 屏幕上什么都不显示，就停在那儿等
print("你输入了：", s)

最关键的一点：input() 拿到的一律是文字

不管你敲的是 25 还是 1.75，input() 拿到的都是文字（字符串），不是数字。用 type() 一看就知道：

Python
123
age = input("请输入你的年龄：")
print(age)
print(type(age))        # 看看它到底是什么类型
输出
123
请输入你的年龄：25
25
<class 'str'>

str 就是字符串，也就是文字。这会带来一个很常见的意外：

Python
123
a = input("第一个数：")
b = input("第二个数：")
print(a + b)
输出
123
第一个数：5
第二个数：3
53
为什么结果是 53 而不是 8？因为两段文字“5”和“3”加在一起，变成了“53”——这叫拼接，不是加法。想真正做加法，得先把它变成数字，这正是下一节要讲的。

七、输入的转换：int / float / eval

解决办法只有一个动作：把 input(...) 整个套进转换函数的括号里。

Python
123

a = input("请输入：")            # 拿到的是文字，不能算
b = int(input("请输入："))        # 拿到的是整数，可以算

最常用的三个

写法变成什么适合输入什么例子
int(input("..."))整数年龄、人数、个数输入 25 → 得到整数 25
float(input("..."))小数身高、体重、价格输入 1.75 → 得到小数 1.75
eval(input("..."))自动判断不确定用户会输整数还是小数输入 25 得整数，输入 1.75 得小数

# 要小数：套 float()

print(f"你的身高是 {height} 米")
print(type(height))     # <class 'float'>

eval() 会自己判断，但有个坑

eval() 不用你纠结用 int 还是 float，它自己看着办：

Python
12
x = eval(input("请输入一个数："))
print(x, type(x))
输出
1234
请输入一个数：25

请输入一个数：1.75

建议：初学阶段尽量用 int() 或 float()，少用 eval()。eval() 会把用户输入的内容当成代码去执行，用户万一输错东西，程序可能有意料之外的反应。要整数就写 int、要小数就写 float，更安全也更清楚。

转换失败长什么样

Python
12
int(input("请输入年龄："))     # 输入 18.5 → 报错，int 只认整数
int(input("请输入年龄："))     # 输入 十八  → 报错，文字变不成数字
要输入小数就用 float()；想让用户重输一遍，得用到后面才学的 try...except。现在只要记住一句话：转换函数和输入内容对不上，程序就会报 ValueError。

九、新手最容易踩的坑

下面这几条，几乎每个人都中过招。

  • 忘了转换，加法变成拼接。input() 拿到的是文字，"5" + "3" 得到 "53"。改法：写成 int(input(...))。
  • 要小数却用了 int()。输入 1.75 会报 ValueError——int 只认整数，小数要用 float。
  • 输入了文字却想转成数字。输入“十八”再套 int()，同样报 ValueError。转换函数只认它能看懂的写法。
  • f-string 前面忘了写 f。屏幕上会原样打出 我的名字是{name}。检查引号前面那个小写 f。
  • 大括号里的变量名拼错或大小写不对。会报 NameError。大括号里填的名字，必须和 = 左边那个一模一样。
  • 把 {bmi:.1f} 里的 :.1f 写到括号外面。位数格式必须在大括号里面，紧跟在变量名后面。
  • 整句话用字符串相加去拼。数字得先 str() 才能和文字相加，否则报 TypeError——碰到这种情况，直接改用 f-string 最省事。
一句话收尾：input 负责要数据、而且拿到的都是文字，int/float 负责把文字变成能算的数字，print 配合 f-string 负责把结果说清楚。

1print("姓名：", "李四") 里被逗号隔开的两个内容，输出时中间默认是什么？

8要读入身高 1.75 米这种小数，正确的写法是？

  • A. height = int(input("请输入身高："))

9关于 eval(input(...))，下面哪种说法是对的？

  • A. 它会自动判断输入的是整数还是小数
  • B. 它和 float() 完全等价
  • C. 它只用来输出结果，和 print 一样

答案：A。eval 会按内容自动判断类型（输入 25 得整数、输入 1.75 得小数）。但它会把输入当代码执行，初学阶段建议优先用 int 或 float 更安全。

10按 IPO 的思路，print(f"和是 {a + b}") 这一句属于哪一环？

  • A. Input（输入）
  • B. Process（处理）
  • C. Output（输出）
  • D. 都不属于
