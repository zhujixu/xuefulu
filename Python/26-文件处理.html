Python 文件处理：把数据存进本子点击此处可返回 Python 基础教程导航页

一、为什么要把数据存进文件

前面学的变量、列表，程序一关就没了。想让数据下次开机还在——比如全班的成绩、你写的日记、程序跑出来的日志——就得存进文件。

Python
123
# 变量存在内存里，程序关掉就消失
scores = [88, 72, 95, 60]
print('本次运行算好了，但关掉就没了')

把数据写进文件，就像把作业写进本子：合上本子，字迹还在。下次打开还能看。

存哪关掉程序后还在吗适合什么
变量 / 列表（内存）不在本次运行临时用
文件（硬盘）在要长期保存、下次还要用的数据
一句话记住：「这次用完就扔」放变量，「以后还要看」写文件。本课学的 open() 就是打开文件、读写内容的那把钥匙。

二、open() 打开文件

读写文件的第一步是 open()：把「文件名」交给它，它返回一个文件对象，后面读写都靠这个对象。

Python
12345
with open('scores.txt', 'w', encoding='utf-8') as f:
    f.write('88\n72\n95\n60\n')
f = open('scores.txt', 'r', encoding='utf-8')
print(type(f))
f.close()

输出 <class '_io.TextIOWrapper'>（不用背这个名字，知道它是「文件对象」就行）。读完记得 close() 关掉。

三个最常用的参数

参数含义例子
第 1 个文件名（或路径）'scores.txt'
第 2 个模式：'r' 读 / 'w' 写 / 'a' 追加'r'
encoding编码，中文几乎总是写 'utf-8'encoding='utf-8'

三种模式

模式作用文件不存在时已存在时
'r'只读报错原样读
'w'写入（会清空）自动新建原内容被清空
'a'追加到末尾自动新建在末尾接着写，不清空
中文文件一定要写 encoding='utf-8'。不写的话，Windows 上默认用 gbk，读你写的 utf-8 文件就可能乱码（详见第十节）。养成习惯：每次 open 都带 encoding。
模式可以组合，比如 'rb' 是「二进制读」、'w+' 是「读写」。起步阶段先把 'r' / 'w' / 'a' 三个用熟。

三、读文件的三种方式

拿到读模式（'r'）的文件对象后，有三种读法。

1. read()：一口气读完整篇

Python
12345
with open('scores.txt', 'w', encoding='utf-8') as f:
    f.write('88' + '\n' + '72' + '\n' + '95' + '\n' + '60' + '\n')
with open('scores.txt', 'r', encoding='utf-8') as f:
    content = f.read()
    print(content)

输出：

输出
1234
88
72
95
60

read() 返回一个字符串，包含所有内容（含换行符）。

2. readlines()：按行读成列表

Python
12345
with open('scores.txt', 'w', encoding='utf-8') as f:
    f.write('88' + '\n' + '72' + '\n' + '95' + '\n')
with open('scores.txt', 'r', encoding='utf-8') as f:
    lines = f.readlines()
    print(lines)

输出 ['88\n', '72\n', '95\n']。每行是列表里的一个元素，行尾的换行符也带着。

3. 逐行 for：一行一行处理

Python
12345
with open('scores.txt', 'w', encoding='utf-8') as f:
    f.write('88' + '\n' + '72' + '\n')
with open('scores.txt', 'r', encoding='utf-8') as f:
    for line in f:
        print(line.strip())   # strip() 去掉首尾空白和换行

输出：

输出
12
88
72
三选一怎么选？文件小、想整体处理用 read()；要数行数或按行取用 readlines()；文件很大、一行行处理用 for line in f（最省内存）。

四、写文件

写模式（'w'）用 write() 把字符串写进去。注意：write 只收字符串，不自动换行。

Python
123
with open('diary.txt', 'w', encoding='utf-8') as f:
    f.write('2026-09-21 今天学了 open()' + '\n')
print('写好了')

输出 写好了。文件里多了一行日记（' ' 是换行符，让每次写占一行）。

'w' 会清空原内容

同一个文件用 'w' 再开一次，里面的旧东西就没了：

Python
123456
with open('e.txt', 'w', encoding='utf-8') as f:
    f.write('旧内容')
with open('e.txt', 'w', encoding='utf-8') as f:   # 又一次 w，原内容被清空
    f.write('新内容')
with open('e.txt', 'r', encoding='utf-8') as f:
    print(f.read())

输出 新内容。第一次写的「旧内容」已经被第二次 'w' 冲掉了。

'a' 是追加，不清空

Python
123456
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('2026-09-21 登录' + '\n')
with open('log.txt', 'a', encoding='utf-8') as f:
    f.write('2026-09-21 退出' + '\n')
with open('log.txt', 'r', encoding='utf-8') as f:
    print(f.read())

输出：

输出
12
2026-09-21 登录
2026-09-21 退出

两次都用 'a'，内容叠在后面，不会互相覆盖。日志、记录类文件就用它。

想保留老内容又想加新的，千万别用 'w'，用 'a'。一个 'w' 下去，之前写的所有内容瞬间消失，且找不回来。

五、关文件与 with open

文件用完后要 close() 关掉，否则内容可能没真正写进硬盘（存在缓冲区里）。

老写法：手动 close

Python
123
f = open('a.txt', 'w', encoding='utf-8')
f.write('hello')
f.close()        # 必须记得关

推荐写法：with open（自动关）

Python
123
with open('a.txt', 'w', encoding='utf-8') as f:
    f.write('hello')
# 离开这个缩进块，文件自动关闭，不用写 close()

两种写法效果一样，但 with 会在代码块结束时自动关闭文件，就算中间出错了也会关。新手强烈推荐 with。

手动 closewith open
会不会忘关容易忘不会，自动关
中途报错可能没关上照样关好
代码量多一行 close少一行，更干净
记住这个最常用模板，直接抄：
with open('文件名', 'r', encoding='utf-8') as f:
内容 = f.read()
读和写都把操作写在缩进块里即可。

六、路径怎么写

open() 第一个参数是「文件在哪」。有两种写法：

写法含义例子
相对路径相对「你运行代码时的目录」'scores.txt'（当前目录）
绝对路径从根目录写全'/tmp/tut_demo/scores.txt'

相对路径最省事：写 'scores.txt'，文件就创建在你运行代码的那个文件夹里。本篇所有例子都用相对路径，方便你照抄。

Windows 上的反斜杠坑

Windows 路径用反斜杠 \，而反斜杠在 Python 字符串里是转义符。所以要写成两个反斜杠或原始字符串 r""：

Python
123
# 示意：Windows 上的正确写法
open('C:\\Users\\笔记\\data.txt')
open(r'C:\Users\笔记\data.txt')

在 Mac / Linux 上路径用正斜杠 /，不用操心这个。教学示例都在 /tmp/tut_demo/ 下验证，与系统无关。

在 Windows 上写 'C:\Users\name.txt' 只写一个反斜杠会报错或路径错乱——要么写两个 \\，要么在整个字符串前加 r 变成原始字符串。

七、文件不存在会怎样

用 'r' 读一个不存在的文件，Python 会直接报错：

Python
12
with open('不存在.txt', 'r', encoding='utf-8') as f:
    print(f.read())
报错
1
FileNotFoundError: [Errno 2] No such file or directory: '不存在.txt'

原因：要读的文件根本没创建过。先确认文件名、路径拼写对不对。

但 'w' 和 'a' 会帮你自动创建

写模式和追加模式很「友好」：文件不在，它直接帮你建一个。

Python
12345
import os
print(os.path.exists('newf.txt'))
with open('newf.txt', 'w', encoding='utf-8') as f:
    f.write('创建我')
print(os.path.exists('newf.txt'))

输出：

输出
12
False
True

第一次打印 False（还不存在），写完再打印就 True 了。

判断文件在不在，用 os.path.exists('文件名')（别忘了先 import os）。读之前先判断，能避免一大半的 FileNotFoundError。

八、配合异常处理读文件

第七节的报错可以用 try...except 接住，让程序「文件不在就提示，而不是直接崩」：

Python
12345
try:
    with open('config.txt', 'r', encoding='utf-8') as f:
        print(f.read())
except FileNotFoundError:
    print('配置文件不存在，使用默认设置')

把 config.txt 换成不存在的文件运行，输出就是 配置文件不存在，使用默认设置，程序稳稳继续。

场景不处理用 try...except 处理
读不存在的文件程序崩溃报错给出友好提示，继续运行
读用户指定的文件用户手滑就崩提示「文件不存在」让用户重来
读「别人给的、可能不存在」的文件时，套一层 try...except FileNotFoundError 是好习惯。异常处理的完整讲法见《25-异常处理》，这里先会用这一种。

十、常见坑

坑 1：忘了 close（或没用 with）

不用 with 又忘写 close()，写进去的内容可能卡在缓冲区、没真正落盘。直接养成用 with 的习惯最保险。

坑 2：用 'w' 把原文件清空了

想追加却写成 'w'，老数据瞬间没了。要保留用 'a'。验证一下：

Python
123456
with open('e.txt', 'w', encoding='utf-8') as f:
    f.write('旧内容')
with open('e.txt', 'w', encoding='utf-8') as f:
    f.write('新内容')
with open('e.txt', 'r', encoding='utf-8') as f:
    print(f.read())

输出 新内容——「旧内容」已被覆盖。

坑 3：编码不一致，读出乱码

写的时候用一种编码、读的时候用另一种，屏幕就会出现看不懂的符号：

Python
1234
with open('g.txt', 'w', encoding='gbk') as f:
    f.write('中文')
with open('g.txt', 'r', encoding='latin-1') as f:
    print(f.read())

输出 ÖÐÎÄ——这就是「乱码」的样子。两边编码对不上，同样的字节被解读成了别的字。

杜绝乱码的办法就一句：写和读都用同一个编码，统一 encoding='utf-8'。在 Mac / Linux 上默认就是 utf-8；在 Windows 上尤其要显式写上，否则很容易踩。

坑 4：read() 调了两次，第二次是空

文件对象有个「读指针」，read() 读完后指针到了末尾，再读就什么都没有：

Python
12345
with open('t.txt', 'w', encoding='utf-8') as f:
    f.write('hello')
with open('t.txt', 'r', encoding='utf-8') as f:
    print(f.read())
    print(f.read())

输出：

输出
1
hello

第一次打印 hello，第二次打印一个空行。想再读，要么重新 open，要么先 f.seek(0) 把指针拉回开头。

坑 5：write() 直接写数字

write() 只收字符串，传数字进去会报错：

Python
12
with open('num.txt', 'w', encoding='utf-8') as f:
    f.write(100)        # 报错：write 只收字符串
报错
1
TypeError: write() argument must be str, not int

原因：数字要先 str(100) 转成字符串再写。比如 f.write(str(总分))。

五个坑一句话记：用 with 自动关、追加用 a 别用 w、编码统一 utf-8、read 第二次是空、写之前 str() 转字符串。

十二、文件操作小结

把前面所有要点压缩成一张「操作清单」，写文件前扫一遍：

要做的事怎么写提醒
读文件open('x.txt', 'r', encoding='utf-8')文件要有

8对同一个文件对象连续调用两次 f.read()，第二次会怎样？

  • B. 从头再读
  • C. 得到一个空字符串
  • D. 直接报错
答案：A。文件对象有「读指针」，第一次 read() 读完指针到了末尾，第二次读到的就是空字符串。要重读得重新 open 或 f.seek(0)。
