四、表格格式：csv、tsv 与 xlsx

如果数据本来就是「一张表」，每行一条记录、每列一个字段，那 CSV（逗号分隔值）最合适。它的好处是：纯文本、体积小、Excel 双击就能打开、几乎所有数据分析工具都认。

一个 CSV 文件用记事本打开，长这样（三个字段、两条记录）：

Python

import csv, pathlib, tempfile

work = pathlib.Path(tempfile.mkdtemp())
f = work / 'scores.csv'
rows = [['姓名', '分数'], ['小满', 92], ['阿禾', 78]]

# 写：newline='' 一定不能少
with open(f, 'w', encoding='utf-8', newline='') as fp:
    csv.writer(fp).writerows(rows)

# 读：用 DictReader，按字段名取值
with open(f, 'r', encoding='utf-8', newline='') as fp:
    for row in csv.DictReader(fp):
        print(row['姓名'], '的分数是', row['分数'], '（类型：' + type(row['分数']).__name__ + '）')

输出

4.5 csv 之外，Excel 还能打开哪些格式

别再以为「Excel 文件」只有一种。同样是 Excel 能双击打开的表格，后缀不同，里面的东西差得很远：

后缀里面到底是什么标准库能读写吗什么时候用
.csv纯文本，字段之间用逗号隔开能，用 csv数据交换、导给别的软件——最通用
.txt / .tsv纯文本，字段之间用制表符隔开能，还是用 csv（换个分隔符）内容里本来就带逗号，或者习惯按 Tab 分列

w.writerow(['小满', 92])
w.writerow(['阿禾', 78])

输出

statistics 是标准库自带的「统计小工具」，专门算平均数、中位数、众数、标准差这些指标。做数据分析，第一步就是把数字算对——这一节把描述性统计常用的指标过一遍，能算的都算给你看。

6.1 四个最常用的指标

Python
12345678
import statistics

scores = [88, 92, 79, 95, 61]

print('平均分：', statistics.mean(scores))
print('中位数：', statistics.median(scores))
print('标准差：', round(statistics.stdev(scores), 2))
print('最高分：', max(scores))

输出
1234
平均分： 83
中位数： 88
标准差： 13.69

四个词的区别：mean 是全部加起来再平均；median 是从小到大排在正中间的那个；stdev 是标准差，衡量分数「散不散」，越小越整齐；mode 是出现次数最多的那个。

函数算什么什么时候用
statistics.mean(x)平均值大家都差不多时，最直观
statistics.median(x)中位数数据里有极端值（有人考 0 分、有人收入特别高）
statistics.mode(x)众数分类数据：哪种最受欢迎
statistics.stdev(x)标准差比较两队稳不稳定

6.2 描述性统计，看四类指标

「描述性统计」听着唬人，其实就是用几个数字把一堆数据的样子说清楚。这些数字分四类，各回答一个问题：

类别回答什么问题代表指标
集中趋势数据的「平均水平」在哪平均值、中位数、众数
离散程度数据散不散、稳不稳定极差、方差、标准差、变异系数
分布位置数据从哪到哪、怎么分布最小值、最大值、四分位数、四分位距
变量间关系两组数据有没有一起变相关系数、回归直线

下面按这个顺序一个一个试。所有例子用的都是同一组十位同学的分数，方便前后对照。

6.3 集中趋势：平均数不止一种

十个数是偶数个，「正中间」落在第 5 个（84）和第 6 个（88）之间：median 取两者的平均 86.0，median_low 取靠下的 84，median_high 取靠上的 88。要求「结果本身就在数据里」（比如「中位数同学考了多少分」），就用 low / high。

还有两种平均数专门对付特殊场景。看增长率用几何平均；看速度、单价这种「每段总量相同」的用调和平均：

最常见的一种是加权平均：期末总评 = 平时分 30% + 期末考 70%，权重不一样，就不能简单平均。标准库用 fmean() 的 weights 参数：

final = [80, 95, 70]

for i, (u, f) in enumerate(zip(usual, final), 1):
    total = round(statistics.fmean([u, f], weights=[0.3, 0.7]), 1)

第 2 位同学总评： 93.5

6.5 离散程度：数据散不散

两个班平均分都是 80：一个班人人 75~85，另一个班一半 100 一半 60——「水平」一样，「整齐程度」差远了。衡量「散不散」的指标有好几个：

Python
12345678910
import statistics

scores = [88, 92, 79, 95, 61, 84, 90, 73, 100, 0]

print('极差（最大减最小）：', max(scores) - min(scores))
print('样本方差：', round(statistics.variance(scores), 2))
print('总体方差：', round(statistics.pvariance(scores), 2))
print('样本标准差：', round(statistics.stdev(scores), 2))
print('总体标准差：', round(statistics.pstdev(scores), 2))
print('变异系数：', round(statistics.stdev(scores) / statistics.mean(scores), 4))

输出：

输出
123456
极差（最大减最小）： 100
样本方差： 846.18
总体方差： 761.56
样本标准差： 29.09
总体标准差： 27.6
变异系数： 0.3817
指标怎么算什么时候用
极差最大值 − 最小值最快看一眼「跨度多大」，但中间的人差多少完全看不出来
方差每个数离平均值的差，平方后再平均数学上最常用，可单位是「平方分」，不好解释
标准差方差开平方和原数据同单位，「平均偏离多少分」，最好解释
变异系数标准差 ÷ 平均值两组数据量级不同时，比谁更「散」

为什么会有「样本 / 总体」两套？手上这组数就是全部（比如全班就这十个人）→ 用带 p 的那套；只是从更大的一群里抽出来的样本 → 用不带 p 的那套。样本方差 846.18 比总体方差 761.56 大一点，就是因为它分母上除以 n-1 而不是 n。数据越少，两者差得越明显。

6.6 分布位置：分位数与五数概括

只看最大值最小值太粗糙——中间的人过得怎么样？把数据排好队、切成几段来看，就是分位数：

Python
12345678910
import statistics

scores = [88, 92, 79, 95, 61, 84, 90, 73, 100, 0]

q1, q2, q3 = statistics.quantiles(scores, n=4)
print('Q1 下四分位：', q1)
print('Q2 中位数：', q2)
print('Q3 上四分位：', q3)
print('四分位距 IQR：', round(q3 - q1, 2))
print('五数概括：', min(scores), '/', q1, '/', q2, '/', q3, '/', max(scores))

输出：

输出
12345
Q1 下四分位： 70.0
Q2 中位数： 86.0
Q3 上四分位： 92.75
四分位距 IQR： 22.75
五数概括： 0 / 70.0 / 86.0 / 92.75 / 100

n=4 表示切成四段，返回三个切点。Q2 永远等于中位数，可以拿它自检。Q1 = 70 读作「约 25% 的人低于 70 分」，Q3 = 92.75 读作「约 75% 的人低于 92.75 分」。

Q3 − Q1 叫四分位距（IQR），它只看中间那 50% 的人，所以完全不受极端值影响——上面这组的极差是 100（有个 0 分），听着吓人；四分位距只有 22.75，说明「大部分同学的差距」其实没那么夸张。最小、Q1、中位数、Q3、最大这五个数合起来叫五数概括，画箱线图用的就是它。

6.7 变量之间的关系：相关与回归

前面都在描述「一组数据」，最后看「两组数据之间有没有关系」。比如：平时练得多的同学，期末是不是考得更好？

Python
1234567891011
import statistics

# 平时练习次数 vs 期末成绩
practice = [2, 3, 5, 6, 8, 9, 11, 12]
final = [55, 61, 68, 70, 78, 82, 88, 95]

print('相关系数 r：', round(statistics.correlation(practice, final), 3))

slope, intercept = statistics.linear_regression(practice, final)
print('回归直线：成绩 =', round(slope, 2), '× 练习次数 +', round(intercept, 2))
print('照这条线，练 10 次大概能考：', round(slope * 10 + intercept, 1))

输出：

输出
123
相关系数 r： 0.996
回归直线：成绩 = 3.74 × 练习次数 + 48.45
照这条线，练 10 次大概能考： 85.8

correlation() 给的是相关系数 r，永远落在 -1 到 1 之间：

r 的值怎么读
接近 1一个变大，另一个也跟着变大（正相关）
接近 -1一个变大，另一个反而变小（负相关）
接近 0看不出线性关系

0.996 已经非常接近「一条直线」，说明这 8 个人里，练习次数和成绩几乎同步变化。

linear_regression() 返回斜率和截距，也就是那条最贴合的直线。斜率 3.74 读作「多练一次，成绩平均提高约 3.74 分」。

两个新手最容易踩的坑：
① 相关不等于因果。r 高只说明「一起变」，不说明「因为练了所以考好」——也可能两者都是「学习态度好」的结果。
② 别往外推。这条线是用 2~12 次的数据拟合出来的，拿它预测「练 100 次能考 422 分」就荒唐了（满分才 100）。回归线只在数据的范围内用才靠谱。

6.8 指标速查表

把上面所有指标收成四张表，忘了就回来查。左边三个字母开头的 p，都表示「这组数就是全体」。

① 集中趋势（数据水平在哪）

指标函数一句话说明
算术平均mean(x)总和 ÷ 个数，最常用
算术平均（更快）fmean(x)总是返回小数；数据多时更快
加权平均fmean(x, weights=w)「平时分 30% + 期末 70%」这种
中位数median(x)排队后正中间那个，抗极端值
下 / 上中位数median_low(x) / median_high(x)偶数个数据时，取靠下 / 靠上的那一个
分组中位数median_grouped(x)数据本来就是分组区间时用
众数mode(x) / multimode(x)出现次数最多 / 并列最多的全部
几何平均geometric_mean(x)连乘场景：增长率、比率
调和平均harmonic_mean(x)平均速度、平均单价这类「每份总量相同」的场合

② 离散程度（数据散不散）

指标函数一句话说明
极差max(x) - min(x)最大减最小，最粗的「散不散」
样本方差variance(x)偏离平均值的平方的平均（除以 n-1）
总体方差pvariance(x)同上，但这组数就是全体（除以 n）
样本标准差stdev(x)方差开方，和原数据同单位，最好解释
总体标准差pstdev(x)同上，数据就是全体时用
变异系数stdev(x) / mean(x)量级不同的两组数据比离散程度

③ 分布位置（数据从哪到哪）

指标函数一句话说明
最小 / 最大min(x) / max(x)数据的两个端点
分位数quantiles(x, n=4)切成 n 段的切点；n=4 是四分位，n=10 是十分位
四分位距 IQRq3 - q1中间 50% 的人跨多大，抗极端值

④ 变量间关系（两组数据一起变吗）

指标函数一句话说明
相关系数correlation(x, y)-1 到 1，两条数据一起变的程度
回归直线linear_regression(x, y)返回（斜率, 截距），用来做预测
协方差covariance(x, y)相关的「未标准化版」，单位跟着数据走
偏度标准库没有数据往哪边歪 → 用 pandas 的 Series.skew()
峰度标准库没有数据尖不尖、尾巴厚不厚 → 用 pandas 的 Series.kurt()
想画分布、算正态概率，statistics 里还有 NormalDist（正态分布）和 kde（核密度），已经属于概率的范畴，等用到再翻。
statistics 只吃数字：拿空列表求平均会报 StatisticsError: mean requires at least one data point，只有一个数求标准差会报 StatisticsError: stdev requires at least two data points。算之前先确认「手里有几个数」。

课程思政｜诚实与批判性思维 · 别只挑一个对自己有利的数

同一份数据，换个指标就能讲出不一样的故事：想说「我们班考得好」就报中位数，想说「我们班退步了」就报平均分。指标本身没有对错，只报一个、不说明口径，才是问题。将来你写报告、做汇报，数字怎么算、为什么这么算，都要经得起别人追问一句「这个数是怎么来的」。

12345

random.seed(7)

八、time：时间戳与给代码计时

time 在《12-time库与random库》里讲过让程序等一下（sleep）和格式化日期。做数据分析时，它还常用来干两件事：给数据盖上时间戳、给代码计时。

8.1 时间戳：给数据记上「什么时候存的」

注意 gmtime() 按 UTC（零时区）换算，比北京时间少 8 小时：这个时间戳对应的北京时间是 2025-01-01 08:00。想要手机上的本地时间，把 gmtime 换成 time.localtime() 就行，时间戳本身不变。

时间戳就是「从 1970-01-01 00:00 起过了多少秒」，本质是一个数字。存数据时一律存时间戳，要给人看时再用 strftime 转成日期——这样跨时区、换电脑都不会乱。

8.2 给代码计时：用 perf_counter()

Python
12345678
import time

t0 = time.perf_counter()
total = sum(range(1000001))
t1 = time.perf_counter()

print('1 加到 100 万：', total)
print('耗时不到 1 秒：', t1 - t0 < 1)

输出：

Python
12
1 加到 100 万： 500000500000
耗时不到 1 秒： True

套路就三步：开始前记一次 t0、干完活记一次 t1、两个一减就是耗时。为什么用它而不是 time()？perf_counter() 精度更高，也不受「系统时间被人调过」的影响。数据多到跑不动时，就靠它找出到底是哪一段慢。

具体秒数每次跑都不一样（换台电脑差得更多），所以上面那段只判断「有没有超过 1 秒」，页面里也就不写具体数字。计时结果别当作固定结论写进报告，真要写就写「约 0.0x 秒」，并注明是在什么机器上测的。
常用函数管什么
time.time()现在的时间戳（浮点数，单位秒）
time.perf_counter()高精度计时器，专门用来量「跑了多久」
time.sleep(秒)让程序停一会儿（做倒计时、控制请求频率）
time.gmtime(时间戳)把时间戳拆成年月日时分秒
time.strftime(格式, 时间)格式化成能看懂的日期字符串

九、collections 与 itertools：数数、分组、组合

最后两个「顺手工具」。它们不是非用不可，但用上之后，很多绕来绕去的循环会短一大截。

9.1 Counter：自动数谁出现得最多

Python
1234567891011
from collections import Counter, defaultdict

orders = ['珍珠奶茶', '椰果奶茶', '珍珠奶茶', '柠檬茶', '珍珠奶茶']

print('点单排行：', Counter(orders).most_common())

# defaultdict(int)：分类累加时不用先问「这个键在不在」
spend = defaultdict(int)
for item, price in [('奶茶', 12), ('奶茶', 15), ('炸鸡', 25)]:
    spend[item] += price
print('分类合计：', dict(spend))

输出：

输出
12
点单排行： [('珍珠奶茶', 3), ('椰果奶茶', 1), ('柠檬茶', 1)]
分类合计： {'奶茶': 27, '炸鸡': 25}

Counter 是「会自动数数的字典」：塞进去一串东西，它直接告诉你每样出现了几次，most_common() 还会按次数从多到少排好——词频统计、投票、点单排行都是它。defaultdict(int) 则是「分类累加」的省事写法：不用先判断键在不在，直接 spend[item] += price。第 26 篇《文件处理》的词频案例用的就是 Counter。

# 文件：save_scores.py
import csv, json
from datetime import datetime
from pathlib import Path

def save(folder, scores):
    folder = Path(folder)
    folder.mkdir(parents=True, exist_ok=True)

    # 1) 明细存成 csv，Excel 能直接打开
    csv_path = folder / 'scores.csv'
    with open(csv_path, 'w', encoding='utf-8-sig', newline='') as fp:
        w = csv.writer(fp)
        w.writerow(['姓名', '分数'])
        w.writerows(scores)

    # 2) 汇总存成 json，带生成时间
    total = sum(s for _, s in scores)
    summary = {
        '生成时间': datetime.now().strftime('%Y-%m-%d %H:%M'),
        '人数': len(scores),
        '平均分': round(total / len(scores), 1),
    }
    json_path = folder / 'summary.json'
    json_path.write_text(
        json.dumps(summary, ensure_ascii=False, indent=2), encoding='utf-8')

    return csv_path, json_path

十五、常见问题

Q：os.path 和 pathlib 到底用哪个？
新写的代码用 pathlib：写法更短、跨系统更稳、有 / 可以拼路径。但老代码和老教程里全是 os.path，必须看得懂。两个混着用也可以，因为 Path() 能接字符串、str(路径) 也能变回字符串。

Q：数据存 csv 还是 json？
一句话判断：长得像一张表（每行同几个字段）→ csv；长得像一棵树（字典套列表、层层嵌套）→ json。要给人用 Excel 打开，选 csv。

Q：为什么我的 csv 用 Excel 打开中文乱码？
Excel 默认按本地编码猜。解决：写文件时用 encoding='utf-8-sig'（多了 BOM 标记，Excel 一看就知道是 UTF-8）。

Q：json.dumps 和 json.dump 我总是记混？
只记一点：带 s 的那个 s = string（字符串）。所以 dumps 返回字符串、loads 吃字符串；不带的就直接对着文件对象。四个函数按这个规律一拆就清楚。

Q：datetime.now() 每次结果都不一样，怎么测试？
这正是要小心的地方。写测试或写教程时，用固定时间 datetime(2026, 10, 4)；真实程序里用 now()。别把 now() 的结果写进需要可重复比对的输出里。

Q：这几个库要不要背？
不用。这一篇的作用是知道「有这些东西、能解决什么问题」，具体函数名忘了就查：dir(模块) 看有什么，help(函数) 看怎么用（第 27 篇《模块与包》第四节讲过）。真正需要背下来的只有「json.dumps 带 s 是转字符串」「csv 要写 newline=''」这类会踩坑的点。

Q：算平均分，该用 statistics 还是自己写循环？
都行，但优先用 statistics：一行写完、还顺带算标准差和中位数；自己写循环容易漏掉「空列表」「字符串没转数字」这两种情况。只有一件事必须自己判断——用平均还是用中位数，这不是工具问题，是口径问题。

Q：numpy / pandas 要不要现在就学？
先把标准库这一套用顺再学。判断标准很简单：数据小到能一眼看完（几十行），标准库够用；数据大到要滚动条才能看完，或者要画图，才值得上 pandas。工具是跟着需求长的，先有需求再学，不容易忘。

Q：随机抽样的结果能写进实验报告吗？
能，但要把种子一起写上：写「用 random.seed(2026) 固定种子，随机抽了 3 人」，别人才能复现。只写「随机抽了 3 人」，别人跑出来是另一批人，这份报告就没法验证。

Q：csv 和 xlsx 到底该用哪个？
一句话：要「交换」用 csv，要「交付」用 xlsx。csv 是纯文本，谁的 Python 都能直接读，出问题用记事本当场就能看一眼；xlsx 能存格式、公式、多个工作表，但读它必须先装库，而且它本质是个压缩包，出问题肉眼看不出来。给人传数据、喂给别的程序——csv；交一份带表头样式、多张工作表的正式报表——xlsx。

Q：描述性统计要报哪几个指标？
至少三个：一个「中心」（平均数 ＋ 中位数一起报）、一个「离散」（标准差）、一个「范围」（最小 / 最大）。只报平均数是最常见的偷懒——同一份数据换个指标就能讲出另一个故事。数据里有明显极端值，或者要和别人比「谁更整齐」，再把四分位距和变异系数补上。

Q：pandas.read_excel() 提示缺 openpyxl，怎么办？
照提示装：pip install openpyxl。pandas 自己不解析 Excel，它只负责指挥，真正干活的是 openpyxl（读 .xlsx）或 xlrd（读老的 .xls）。装完还报，多半是装到了别的 Python 环境——和 ModuleNotFoundError: No module named 'numpy' 是同一类问题。
