一、字符串是什么

字符串就是一段文字。只要用引号包起来，不管是中文、英文、数字还是符号，都算字符串。

它是我们打交道最多的一种类型——网页上的内容、表格里的数据、用户输入的东西，拿到手里几乎都是字符串。

1.1 三种引号，随便挑

Python
1234
a = "小明"          # 双引号
b = '小明'          # 单引号，和双引号完全一样
c = "他说：'你好'"   # 里面是单引号，外面就用双引号
d = '他说："你好"'   # 里面是双引号，外面就用单引号

第三种情况很常见：文字里面本来就有引号时，外用另一种引号就行，不用操心转义。

还有第三种：三引号，专门用来写跨好几行的文字。

Python
12345678
e = """第一行
第二行
第三行"""
print(e)
# 输出：
# 第一行
# 第二行
# 第三行
单引号和双引号没有区别，挑一个用着顺手的一直用就好。三引号的主要用途是写多行文字，或者在代码里写一段说明（第 5 篇《语法规范》里讲过的文档字符串）。

1.2 数一数有几个字：len()

Python
123
print(len("Python"))      # 6
print(len("你好世界"))     # 4     一个汉字算 1 个字符
print(len("  ab  "))      # 6     空格也算一个字符
len() 数的是字符个数，不是字节数。一个汉字算 1 个，所以“你好世界”是 4 而不是 8。这一点在检查输入长度时会用到。

1.3 问一句“里面有没有”：in

Python
12345
s = "Python编程"
print("thon" in s)      # True    包含这一段
print("Java" in s)      # False   不包含
print("Py" not in s)    # False   反过来问“不包含”
print("p" in s)         # False   注意大小写敏感：小写 p 不在里面
in 是判断连着的几个字符有没有出现，不只是单个字。"thon" in "Python" 也是 True。要特别注意它是区分大小写的。

1.4 字符串改不了（很重要）

字符串属于不可变类型：创建出来之后，里面任何一个字符都不能单独修改。

Python
123
s = "hello"
s[0] = "H"
# 报错：TypeError: 'str' object does not support item assignment

想改只能重新拼一个新字符串，再让变量指向它：

Python
123
s = "hello"
s = "H" + s[1:]     # 取第 1 个到最后，前面接个 H
print(s)            # Hello
这一条会引出一个很实用的结论：字符串的方法都不会改动原字符串，而是返回一个新的。s.upper() 写完 s 本身没变，想用结果得接住——s2 = s.upper()。后面第六、七节的方法全都遵守这条。

二、引号与转义字符

有些字符没法直接打出来，比如“换行”“制表符”；还有些字符在字符串里有特殊身份，比如引号本身。这时候就要用反斜杠 \ 加一个字母来表示它，这叫转义字符。

写法名字作用实际效果
\n换行从这里换到下一行相当于按一次回车
\t制表符空出一段，用来对齐相当于按一次 Tab
\\反斜杠表示一个反斜杠本身显示为 \
\"双引号表示一个双引号本身显示为 "
\'单引号表示一个单引号本身显示为 '
Python
1234
print("第一行\n第二行")      # \n 在这里换行
print("姓名\t年龄")          # \t 空一段，用来对齐
print("C:\\Users\\笔记")     # \\ 表示一个反斜杠
print("他说：\"你好\"")       # \" 表示引号本身

运行结果：

输出
12345
第一行
第二行
姓名    年龄          ← 这里是一个 Tab（制表符），不是一串空格
C:\Users\笔记
他说："你好"
前两行看着简单，但“看不见”的字符最容易惹麻烦。比如你想打印一个 Windows 路径 "C:\new\test"，里面的 \n 会被当成“换行”、\t 会被当成“Tab”，结果路径被切得乱七八糟。
Python
1234
print("C:\new\test")
# 实际输出（已经不是你想要的路径了）：
# C:
# ew    est

这个问题有个更省事的解法：在引号前面加个 r，让反斜杠恢复成普通字符。这是第 11 节的内容，先记住有这么回事。

课程思政｜工匠精神与严谨求实 · 看不见的字符最惹麻烦

反斜杠加一个字母，就变成了「换行」「制表」这些看不见的角色。打印一个 C:\new\test 路径，\n、\t 会悄悄把路径切得七零八落，程序还不报错。越是看不见的地方，越要盯紧；出了怪结果先怀疑这些隐身的字符，是程序员该有的警觉。

三、索引：取出一个字符

字符串是一串排好队的字符，每个字符都有一个位置编号。用 方括号 + 编号 就能把它单独取出来，这叫索引。

编号规则只有两条：从左往右从 0 开始，从右往左从 -1 开始。

字符Python
从左数（正索引）012345
从右数（负索引）-6-5-4-3-2-1

上表是 s = "Python" 的编号表，建议自己拿笔抄一遍——记不住从 0 开始，是新手最常犯的错。

Python
1234567
s = "Python"

print(s[0])      # P    第 0 个（也就是第一个）
print(s[1])      # y    第 1 个
print(s[5])      # n    最后 1 个（一共 6 个字符，编号到 5 为止）
print(s[-1])     # n    从右数第 1 个，也就是最后一个
print(s[-2])     # o    倒数第二个
s[-1] 是“取最后一个字符”的标准写法，非常好用——字符串多长都不用管。取第 6 个字符就写 s[6]、取最后一个就写 s[-1]，别看元素总数。

3.1 越界会报错

编号超出范围就会报错：

Python
123
s = "Python"
print(s[6])
# 报错：IndexError: string index out of range
IndexError 的意思是“编号超出范围了”。"Python" 只有 6 个字符、编号是 0~5，写 s[6] 就多了一位。看到这个报错，先数一遍字符个数，再看看是不是把“从 1 开始”的直觉带进来了。

四、切片：取出一段

索引一次只能取一个字符。想取一串，就用切片。写法是在方括号里用冒号分开三个数字：

输出
1
字符串[起始位置 : 结束位置 : 步长]

最重要的一条规则：含头不含尾。起始位置要，结束位置不要。

4.1 先记住“含头不含尾”

Python
12345
data = "0123456789"

print(data[2:5])    # 234     取编号 2、3、4，不含 5
print(data[0:3])    # 012     取编号 0、1、2，不含 3
print(data[-3:])    # 789     取最后三个
用一句话记：“写 2 到 5，取到 4 就停”。或者记成“右边那个数字是刹车，刹车的位置取不到”。这条规则字符串、列表、元组全都一样。

4.2 三种省略写法

写法含义例子结果
s[start:end]从 start 取到 end（不含 end）"0123456789"[2:5]234
s[:end]从头取到 end（不含 end）"0123456789"[:3]012
s[start:]从 start 一直取到最后"0123456789"[7:]789
s[:]整段照抄一份"0123456789"[:]0123456789
记法很直观：哪边没写数字，就是从哪边“到头”。前面不写＝从头开始，后面不写＝一直到尾。

4.3 步长：隔几个取一个

第三个数字是步长，默认是 1（一个一个取）。改成 2 就是每隔一个取一个：

Python
12345
s = "0123456789"

print(s[::2])     # 02468   从头到尾，隔一个取一个
print(s[1::2])    # 13579   从 1 开始，隔一个取一个
print(s[1:8:2])   # 1357    从 1 取到 7，隔一个取一个
步长不写就是 1，所以 s[2:5] 和 s[2:5:1] 完全一样。日常用得最多的是 [::2]（隔一个取）和下面的 [::-1]（反转）。

4.4 反转：把整串倒过来

步长写成 -1，就是从后往前一个一个取，等于把字符串倒过来。这是 Python 里最简洁的反转写法：

Python
1234
s = "Python"

print(s[::-1])    # nohtyP    整个倒过来
print(s[::-2])    # nhy       倒着取，隔一个取一个
判断一个词是不是回文（正着读反着读一样，比如 "上海自来水来自海上"），一行就够：
Python
12
word = "上海自来水来自海上"
print(word == word[::-1])     # True
这个 [::-1] 对列表也管用，第 8 篇里反转列表用的就是它。

五、连接与重复

两个动作最常用：加号 + 把两段接起来，乘号 * 把一段重复几遍。

Python
12345
print("张" + "三")                # 张三       接起来
print("Hello" + ", " + "World")   # Hello, World
print("-" * 10)                   # ----------  重复 10 遍
print("哈" * 3)                   # 哈哈哈
print("Ab" * 4)                   # AbAbAbAb

5.1 想拼数字，必须先转成字符串

Python
1234567
age = 18

print("我今年" + age + "岁")
# 报错：TypeError: can only concatenate str (not "int") to str

print("我今年" + str(age) + "岁")      # 我今年18岁   ✓ 先转换
print(f"我今年{age}岁")                # 我今年18岁   ✓ 更好的办法
str() 把别的东西变成字符串，这是最直接的解法。但如果要拼的内容比较多，用 f 字符串（第九节）会清爽得多，也不用一个个 str()，建议养成习惯。

5.2 一个容易误会的地方：print 里的逗号

有些人看到 print 里用逗号也能把几样东西连起来，就以为逗号是“字符串拼接”。不是的。逗号是 print 的分隔符，它只是在输出时把几样东西依次打印、中间自动加个空格：

写法本质是什么结果
print("我今年", 18, "岁")print 收到 3 个参数，依次打印、中间加空格我今年 18 岁
print("我今年" + str(18) + "岁")先用 + 拼成一个字符串，再交给 print我今年18岁
区别在结果上能看出来：逗号版本多了一个空格，加号版本没有。而且逗号版本不能存进变量——msg = "我今年", 18 得到的是元组不是字符串。想存下来、想精确控制格式，就用 + 或 f 字符串。

5.3 相邻的字符串会自动拼起来

还有一个语法小特性：两个字符串字面量挨着写，Python 会自动把它们拼成一个。

Python
12
msg = "Py" "thon"
print(msg)       # Python
这个特性知道就行，实际写代码不要故意这么用——容易看漏中间少了个逗号。"a" "b"（拼成 "ab"）和 "a", "b"（元组）就差一个逗号，意思完全不同。

课程思政｜诚信与职业操守 · 一段一段拼，才拼得完整

加号能把两段文字接起来，乘号能把一段重复几遍，拼的时候还得先把数字转成字符串。团队做一份报告也是这样，各写各的一段，格式和口径统一了才接得上。谁也别图省事省掉自己那一段，一个人的疏漏，整份材料都得返工。

六、常用方法之一：大小写与清理

方法是“跟着字符串后面用点叫出来”的功能，写法是 字符串.方法名(参数)。下面这些是日常用得最多的。

先看改大小写的四个：

方法作用例子结果
lower()全部变小写"Hello PY".lower()hello py
upper()全部变大写"hello py".upper()HELLO PY
capitalize()整个句子的首字母大写"hello python".capitalize()Hello python
title()每个单词的首字母都大写"hello python".title()Hello Python

再看清理两端空白的三个。名字里的 l 是 left（左），r 是 right（右）：

方法清掉哪儿例子（原串带前后空格）结果
strip()两端都清" hi ".strip()"hi"
lstrip()只清左边" hi ".lstrip()"hi "
rstrip()只清右边" hi ".rstrip()" hi"
Python
12345678
s = "  Hello World  "

print(s.lower())        # "  hello world  "
print(s.upper())        # "  HELLO WORLD  "
print(s.strip())        # "Hello World"        两端空格没了
print(s.lstrip())       # "Hello World  "      只清左边
print(s.rstrip())       # "  Hello World"      只清右边
print(s.title())        # "  Hello World  "    每个单词首字母大写
⚠️ 再强调一次：这些方法都不会改动原来的 s，只是返回一个新字符串。s.strip() 写完 s 还是带空格的，必须写 s = s.strip() 才会真的生效——这是新手最容易漏的一步。
strip() 在处理用户输入时是必备的。用户在 input() 里很容易多打一个空格，不清理就会影响后面的比较和转换：
Python
1
name = input("请输入姓名：").strip()      # 顺手清掉两端的空格
注意只能这样连着写，不能先 input().strip() 再指望原变量变了。

七、常用方法之二：查找、替换、分割、合并

7.1 找位置：find() 和 count()

Python
12345
t = "苹果,香蕉,苹果,橙子"

print(t.find("香蕉"))     # 3     返回它从第几个字符开始
print(t.find("西瓜"))     # -1    找不到返回 -1（不会报错）
print(t.count("苹果"))    # 2     出现过几次
方法作用找不到时
find(x)返回 x 第一次出现的位置编号返回 -1，不报错
index(x)同上报 ValueError 让程序中断
count(x)数一数 x 出现了几次返回 0
x in s判断有没有 x返回 False
不确定找的东西一定在，用 find() 更安全——找不到给你个 -1，程序还能往下走。index() 找不到直接崩，除非你确定它一定存在，否则别用。

7.2 换内容：replace()

Python
123
t = "苹果,香蕉,苹果,橙子"
print(t.replace("苹果", "葡萄"))     # 葡萄,香蕉,葡萄,橙子
print(t.replace("苹果", "葡萄", 1))  # 葡萄,香蕉,苹果,橙子   只换第 1 处
replace() 默认全换；加上第三个参数可以限制只换前几处。它同样是返回新字符串，原串不动。

7.3 分割：split()

把一个字符串按某个符号切开，变成列表。这是处理表格数据的第一步。

Python
12345
line = "name,age,city"
print(line.split(","))      # ['name', 'age', 'city']

data = "2026-09-20"
print(data.split("-"))      # ['2026', '09', '20']
写法含义结果
"a,b,c".split(",")按逗号切['a', 'b', 'c']
"a b c".split()不写参数：按空白切，并自动去掉连续空格['a', 'b', 'c']
" a b ".split()不写参数时，两端空白自动丢掉['a', 'b']
"a,b,,c".split(",")中间是空的，也会留下一项空字符串['a', 'b', '', 'c']
"a-b-c".split("-", 1)限制只切 1 次['a', 'b-c']
不写参数和写参数差别很大。split() 按任意空白切、还顺手把多余空格吃掉，处理用户输入最省事；split(",") 是严格按逗号切，逗号之间是空的就是空字符串。看见结果里出现空字符串 ''，通常是数据里多打了分隔符。

7.4 合起来：join()

join() 是 split() 的反动作：把一个列表用某个分隔符合成一个字符串。

Python
1234567
words = ["Python", "is", "fun"]
print(" ".join(words))      # Python is fun     用空格连

nums = ["2026", "09", "20"]
print("-".join(nums))       # 2026-09-20        用横线连

print("".join(["a", "b"]))  # ab                不用分隔符就直接贴
⚠️ join() 的写法容易记反：分隔符在前、列表在后。是 "-".join(列表)，不是 列表.join("-")。另外，列表里的元素必须全是字符串，装的是数字会报错，要先用 str() 转一遍。
Python
1234
print("-".join([1, 2, 3]))
# 报错：TypeError: sequence item 0: expected str instance, int found

print("-".join(str(n) for n in [1, 2, 3]))     # 1-2-3   ✓ 先转成字符串
split() 和 join() 是一对，合起来能干很多活。比如把 "2026-09-20" 换成斜杠格式：
Python
12
d = "2026-09-20"
print("/".join(d.split("-")))     # 2026/09/20
先切开、再用新符号拼回去。

八、常用方法之三：判断类

这一类方法的共同点是：返回值是 True 或 False，专门用来检查字符串“符不符合某种样子”。常配合 if 使用。

方法它问的是是 True 的例子是 False 的例子
isdigit()是不是全是数字"12345""abc123"、"12.5"
isalpha()是不是全是字母"abc""abc123"、"ab c"
isalnum()是不是字母或数字（都行）"abc123""ab c"、"a-b"
isspace()是不是全是空白" ""a "
startswith(x)是不是以 x 开头"hello".startswith("he")"hello".startswith("lo")
endswith(x)是不是以 x 结尾"hello".endswith("lo")"hello".endswith("he")
Python
1234567
print("12345".isdigit())            # True    全是数字
print("abc123".isdigit())           # False   有字母
print("12.5".isdigit())             # False   有小数点！
print("abc123".isalpha())           # False   有数字
print("abc123".isalnum())           # True    字母数字都有，算通过
print("hello".startswith("he"))     # True
print("hello".endswith("lo"))       # True
⚠️ "12.5".isdigit() 是 False，这是最坑的一条。因为它带小数点，而小数点不是“数字字符”。同样，带负号的 "-5".isdigit() 也是 False。所以别用 isdigit() 去验证“是不是合法的小数”——那种情况应该直接 try 一下能不能转成 float。
判断用户输入是不是整数，isdigit() 很好用：
Python
123456
age_text = input("请输入年龄：").strip()
if age_text.isdigit():
    age = int(age_text)
    print(f"明年你 {age + 1} 岁")
else:
    print("请输入纯数字，不要带小数点和符号")
这段先判断再转换，就不会因为用户乱输而让程序崩掉。

九、格式化：f 字符串（重点）

把变量塞进一句话里，最方便的办法就是在引号前面加一个 f，然后在句子里用花括号 {} 把它圈起来。这就是 f 字符串（f 是 format 的缩写）。

Python
12345

十一、r：原始字符串

回到第二节留下的问题：写文件路径时，路径里的 \n、\t 会被当成转义符，把路径搞得面目全非。

Python
1234

# 你以为会打印路径，实际打印出：
# C:
# ew_folder	temp

解决的第一个办法是把每个反斜杠都写成两个（\\），但这又长又容易漏。

更省事的办法是在引号前面加一个 r。加了 r 之后，字符串里的反斜杠就变回普通字符，什么转义都不认了——这就是原始字符串（r 是 raw 的缩写）。

写法代码打印出来
不加 r"C:\new\temp"被吃掉了，变成换行和 Tab
加 rr"C:\new\temp"C:\new\temp ✓ 原样显示
手动双反斜杠"C:\\new\\temp"C:\new\temp ✓ 但要写一倍的多，容易漏
Python
123456
# 加了 r，\n 和 \t 就是普通的两个字符
print(r"C:\new_folder\temp")       # C:\new_folder\temp

# 写文件路径：直接原样抄路径就行，不用一个个加反斜杠
path = r"C:\Users\小明\Desktop\笔记.txt"
print(path)                        # C:\Users\小明\Desktop\笔记.txt
凡是 Windows 路径，养成习惯加 r。直接从“地址栏”或者“复制文件路径”里粘过来，前面补个 r 就完事，不用管里面有几个 \、也不用担心哪个字母组合会被当转义符。

11.1 r 也有管不到的地方

有一条限制：原始字符串不能以单个反斜杠结尾，因为那个反斜杠会把结尾的引号“挡住”，Python 就不知道字符串在哪结束了。

Python
123

# 解决办法：单独拼一个反斜杠，或者干脆不加 r 用双反斜杠
p = r"C:\Users" + "\\"
这种情况很少遇到，记住“r 字符串的结尾别是单个反斜杠”就行，真碰到就把它拆成两段拼起来。

11.2 r 还常用在哪儿

另一个高频场景是正则表达式——里面全是反斜杠，不加 r 会疯掉。不过正则属于进阶内容，这里知道“r 是为大量反斜杠准备的”就够了。

Python

# ['20260920']

十二、f 和 r 一起用（fr）

两个前缀解决的问题不一样：f 管“能不能嵌变量”，r 管“反斜杠要不要转义”。它们可以叠着写，写成 fr"..." 或 rf"..."，两种顺序都行。

前缀解决的问题路径里的反斜杠{} 能嵌变量吗

f能嵌入变量和表达式仍然会被转义能
r反斜杠不转义原样保留不能
fr / rf两个都要原样保留能

13.1 处理一行表格数据

  • C. r"C:\data\{name}.csv"
  • D. f"C:\\data\\{name}.csv"
答案：A。fr 把两个前缀的好处合起来：f 让 {} 能嵌入变量，r 让反斜杠不被转义。B 只加 f，路径里的 \d、\t 可能出问题；C 只加 r，{} 不会被替换成变量值；D 要手写双反斜杠，容易漏。
