Python IDLE 如何新建 Python 文件并运行

一、先认识 IDLE：它是什么，怎么打开

IDLE 是 Python 自带的编辑器，装完 Python 就有了，不用另外下载。 它专门给刚开始学的人用：界面简单、能边写边试。IDLE 这个名字来自 IDE 的谐音（集成开发与学习环境）。

1. 先分清 IDLE 的两种窗口

窗口长什么样用来干什么
交互窗口（Shell）带 >>> 提示符，一行一行地敲随手试一两行代码、立刻看结果，不能保存成文件
编辑器窗口空白纸，没有 >>>，可以写很多行写完整程序，保存成 .py 文件后再运行

一句话记住：带 >>> 的是「试验台」，不带的是「草稿纸」。 写作业、写完整程序用编辑器窗口；只想算一下、试一下，用交互窗口。

2. 怎么打开 IDLE

  • Windows：点开始菜单 → 搜索 IDLE → 打开；也可以在命令行窗口里输入 idle 回车。
  • Mac：打开「访达」→ 应用程序 → 找到名字以 Python 3. 开头的文件夹（后面跟的就是你自己装的小版本号）→ 双击里面的 IDLE；或者在「终端」里输入 idle3 回车。

3. 顺手确认 Python 装好了

打开命令行窗口（Windows 是 cmd，Mac 是「终端」），输入下面这条命令并回车：

命令
1
python --version

屏幕上出现类似下面的字样，就说明装好了。3. 后面是你的小版本号，每台电脑装到的可能都不一样：

输出
1
Python 3.<小版本号>
只要能打印出一个 Python 3 开头的版本号就算装好了，用不着和这里完全一致。如果提示「不是内部或外部命令」，说明安装时没勾选 Add python.exe to PATH，重新安装一次并把这个勾打上即可。

二、交互窗口（Shell）：随手试代码

打开 IDLE 后第一个出现的就是交互窗口，它每一行开头都有一个 >>>。 在它后面输入内容、按回车，Python 会立刻把结果写在下一行。

1. 它就是一台随叫随到的计算器

在提示符后面输入下面这些式子，回车就能看到结果：

你在 >>> 后面输入Python 的回答
2 + 35
10 / 42.5
(2 + 3) * 420

没有提示符的那一行是 Python 算出来给你的答案，不是你敲进去的，别把它们弄混。

2. 打印一句话

输入 print("你好，Python") 回车，下一行就会显示 你好，Python。 注意：要打印的文字必须用引号 "..." 或 '...' 包起来，中文、英文都行。

3. 交互窗口的三个小用法

  • 翻历史：按 Alt + P 回到上一条命令，Alt + N 往下走，不用重新敲。
  • 补全：输入一半按 Tab，IDLE 会帮你补全名字。
  • 退出：输入 exit() 回车，或按 Ctrl + D。

4. 名字没定义过，会当场报错

想打印变量 message，却把名字打成了 mesage，回车后会立刻看到一段报错。 它中间那行 NameError 就是答案：

  • 报错的第一行是 Traceback (most recent call last):，意思是「调用出错，详情如下」；
  • 中间会指出出错的位置（交互窗口里显示的是 <pyshell#0>，表示这是你在提示符下敲的那一行）；
  • 最后一行才是关键：NameError: name 'mesage' is not defined，意思是「mesage 这个名字没有定义过」。
交互窗口里的报错只影响这一行，改掉重敲就行。关于怎么读这种报错，第六节会专门讲。

三、新建 Python 文件

写完整程序要在编辑器窗口里写，新建一个文件只要两步：

  1. 在 IDLE 菜单栏点 File → New File；
  2. 或者按快捷键 Ctrl + N（Mac 是 Cmd + N）。

这时会弹出一个空白的编辑器窗口，上面没有 >>>。 它就是一张干净的草稿纸，想写多少行都可以。先写一行最简单的代码试试：

Python
1
print("Hello, World!")

写完之后先别急着运行——这个文件还没有名字，也还没存到硬盘上。下一步就是保存。

如果新弹出的窗口里带着 >>>，说明你开的是交互窗口，不是编辑器窗口。关掉它，重新点 File → New File 即可。

四、保存文件：起好名字，选对编码

点 File → Save（或按 Ctrl + S）会弹出保存对话框。这里有三个容易踩的坑。

1. 文件名一定要以 .py 结尾

文件名能不能运行说明
hello.py✅ 可以标准写法，Python 文件都是 .py 结尾
hello.py.txt❌ 不行Windows 默认隐藏扩展名，一不小心就存成这样，按 F5 没反应
hello.txt❌ 不行.txt 是纯文本，Python 不认
hello❌ 不行没有扩展名，系统不知道这是 Python 文件

怎么避免存成 hello.py.txt？Windows 的资源管理器里， 点菜单「查看 → 文件扩展名」把它打开，就能看见真实的后缀了。

2. 存到一个好找的文件夹

建议先在桌面建一个文件夹，比如叫 python_study，以后所有练习都存进去。 文件名用英文小写字母加数字，不要用中文、空格和特殊符号，例如 hello_1.py、practice_2.py。

3. 编码选 UTF-8

保存对话框里如果能看到编码选项，选 UTF-8，这样中文才不会变成乱码。 万一还是乱码，在文件第一行加上这句：

Python
1
# -*- coding: utf-8 -*-
文件保存过之后，标题栏会显示文件名。标题栏上没有星号，就说明改动都存好了。

五、运行文件：F5 一按就出结果

文件保存好之后就可以运行了，有两种等价的办法：

方式操作
菜单运行点 Run → Run Module
快捷键按 F5

按下去之后，IDLE 会自动跳回交互窗口，并在那里执行刚保存的文件。 文件里其实就一句代码：

Python
1
print("Hello, World!")

它先打出一行 RESTART 提示（后面跟着你的文件路径），表示「我把这个文件重新跑了一遍」， 紧接着才是程序真正的输出：

输出
1
Hello, World!

那行 RESTART 只是提示，不是程序打印的内容——print 真正输出的就一句 Hello, World!。

改完代码要再按一次 F5

IDLE 不会自动重跑。改完代码、存盘（Ctrl + S）、再按 F5，才会看到新结果。 看到的还是旧输出，多半就是忘了再按一次 F5。

没保存就按 F5 会怎样？IDLE 会弹出对话框，让你先给文件起名字保存，然后才运行。所以「先保存、后运行」是固定动作。

六、程序报错了怎么读（Traceback）

报错不是坏事，它是 Python 在告诉你「哪里不对、为什么不对」。学会读它，比自己盯着代码发呆快得多。

1. 语法错：括号没配对

下面这行漏了一个右括号：

Python
1
print("Hello, World!"

按 F5 后，交互窗口里会出现：

报错
1234
  File "/Users/你的用户名/python_study/hello.py", line 1
    print("Hello, World!"
         ^
SyntaxError: '(' was never closed

意思就是「左括号 ( 一直没有闭合」。那个 ^ 指的位置，就是 Python 认为出问题的地方。

2. 名字错：变量名写错了

Python
12
mesage = "你好"
print(mesage2)

明明定义了 mesage，打印时却多写了一个 2，于是：

报错
12345
Traceback (most recent call last):
  File "/Users/你的用户名/python_study/hello.py", line 2, in <module>
    print(mesage2)
          ^^^^^^^
NameError: name 'mesage2' is not defined. Did you mean: 'mesage'?

最后那句 Did you mean: 'mesage'? 是 Python 的贴心提示——它猜你想写的是 mesage。

3. 报错要倒着读，三步就够

  1. 先看最后一行：那是错误类型和原因，例如 NameError: name 'mesage2' is not defined。
  2. 再看 File "…", line N：它告诉你出问题的是第几行。
  3. 最后看中间那行代码：也就是第 N 行的原文，错通常就在那里。

4. 几个最常见的错误类型

报错类型中文意思最常见的原因
SyntaxError语法错误括号 / 引号没配对、漏了冒号，或用了中文标点
IndentationError缩进错误该缩进的地方没缩进，或同一层缩进不一致
NameError名字未定义变量名拼错、大小写不对，或用之前忘了先定义
ZeroDivisionError除数为零拿一个数去除以 0
TypeError类型错误把不能拼在一起的东西硬拼，例如字符串直接和数字相加
报错里那串长长的文件路径可以忽略，重点永远是最后一行加报的是第几行。把最后一行复制去问 AI 或搜索，往往一句话就能解决。

七、常用快捷键一览

下面这些够用了，不用一次记全，用几次就熟。Mac 电脑把 Ctrl 换成 Cmd（F5 不变）。

快捷键作用
Ctrl + N新建文件
Ctrl + S保存文件
F5运行当前文件
Ctrl + Z撤销上一步
Ctrl + A全选
Ctrl + F查找文字
Alt + 3把选中的行注释掉
Alt + 4取消选中行的注释
Tab补全名字（在交互窗口里尤其好用）
Alt + P / Alt + N在交互窗口里翻上一条 / 下一条历史命令

记不住也没关系：菜单栏里的 File、Run 就有对应命令，命令右边通常还写着快捷键——看菜单，是学快捷键最省事的办法。

八、常见问题

  • 按 F5 提示要先保存：新文件还没有名字，先按 Ctrl + S 存成 .py 文件再运行。
  • 运行了却看不到输出：输出不会出现在编辑器窗口，去看带 >>> 的交互窗口。
  • 双击 .py 文件窗口一闪而过：说明系统是用命令行跑的，跑完就关了。正确的做法是用 IDLE 打开再按 F5； 如果一定要双击运行，可以在程序末尾加一行 input("按回车键退出") 让它停一下。
  • 中文变成乱码：保存时选 UTF-8 编码；仍不行就在第一行加 # -*- coding: utf-8 -*-。
  • 提示 'python' 不是内部或外部命令：安装 Python 时没勾选 Add python.exe to PATH，重装一次并勾上。
  • 电脑上装了不止一个 Python：以能正常打开 IDLE 的那个为准；若命令行里 python --version 显示的版本和 IDLE 不一致，说明装了两份。
  • 明明有中文却说「无效字符」：多半是把英文的 : ( , 写成了中文的 ： （ ，，改回英文即可。

九、小技巧

  • 想快速打开最近写过的文件，用 File → Recent Files。
  • 想单步看程序怎么走，点 Debug → Debugger 打开调试器。
  • 在交互窗口里输入变量名再回车，可以查看它当前的值，调试时很顺手。
  • 字太小看不清，用 Options → Configure IDLE 调字号和配色。
  • 不确定某个函数怎么用，在交互窗口输入 help(函数名)，Python 会把说明书打给你。
  • 写完一个文件就存一个名字（hello.py、practice_2.py…），练习多了也好翻。

  • A. 电脑内存不够
  • B. mesage2 这个名字没有被定义过，多半是变量名写错或拼错了
  • C. 文件没有保存

8下面哪种情况最容易导致 SyntaxError（语法错误）？

答案：A。中文标点（，：（））是语法错的重灾区，Python 只认英文标点。另外括号、引号没配对也常报 SyntaxError。

答案：B。IDLE 不会自动重跑。改完要存盘、再按一次 F5，才会看到新的输出。
