Python 基本数据类型：七种类型一次认清

一、数据类型是什么

写程序的时候，我们往变量里放的东西五花八门：有的是数字（18），有的是文字（"小明"），有的是一串东西（["苹果", "香蕉"]）。

Python 会给每一样东西都贴上一个类型标签，告诉你“这是哪一类东西”。这个标签就是数据类型。

打个比方：厨房里有杯子、有桶、有保鲜盒。杯子装水，桶装米，保鲜盒装剩菜。不同的东西要放进不同的容器，数据类型就是这个“容器”。

1.1 为什么一定要区分类型

因为类型决定了这个东西能怎么用。同样是加号：

Python
12
print(5 + 3)        # 8      数字 + 数字 = 加法
print("5" + "3")    # 53     文字 + 文字 = 首尾拼起来

一个是数学加法，一个是文字拼接，结果完全不一样。如果搞混了，程序就直接报错：

Python
12
print("5" + 3)
# 报错：TypeError: can only concatenate str (not "int") to str

报错里出现 TypeError，意思就是“类型不对”。新手看到这个错，第一反应就该是：这两个东西的类型是不是不一样？

1.2 用 type() 看一眼类型

不确定一个值是什么类型，用 type() 套一下，它会直接告诉你答案：

Python
12345678
print(type(10))         # <class 'int'>
print(type(3.14))       # <class 'float'>
print(type("hello"))    # <class 'str'>
print(type([1, 2]))     # <class 'list'>
print(type((1, 2)))     # <class 'tuple'>
print(type({1, 2}))     # <class 'set'>
print(type({"a": 1}))   # <class 'dict'>
print(type(True))       # <class 'bool'>

下面这张表把八种类型对上号。这一整份教程，就是把这八行一行一行讲清楚。

值长什么样类型名中文名一句话说明
10 / 3.14int / float整数 / 浮点数数字，可做加减乘除
"hello"str字符串文字，用引号包起来
[1, 2, 3]list列表一串东西，能增能删
(1, 2, 3)tuple元组一串东西，定了就不能改
{"a": 1}dict字典成对的“名字→内容”
{1, 2, 3}set集合不重复的一堆东西

遇到类型问题，先问 type()。把 type(你的变量) 打印出来看一眼，十次有八次问题
本篇是「点名册」，只求混个脸熟。八种类型各点一次名就行，不必背、更不必全懂——字符串第 8 篇讲、列表第 14 篇讲、元组第 15 篇讲、字典第 18 篇讲、集合第 19 篇讲，到时候每样都有一整篇细细掰开。
当场就明白了。

二、数字（int / float / complex）

数字是用来算数的，日常用到的其实只有两种：没小数点的叫整数（int），有小数点的叫浮点数（float）。

Python
1234567
age = 18            # 整数 int
price = 9.9         # 浮点数 float
score = -15         # 负数也是整数
big = 2 ** 100      # Python 的整数可以非常大，不会溢出

print(type(age))    # <class 'int'>
print(type(price))  # <class 'float'>

2.1 能做的运算

加减乘除和数学里一样。有四个地方和数学课本不太一样，记住就行：

运算符名字例子结果要注意
/除法7 / 23.5结果一定是小数，哪怕整除了也是 2.0
//整除7 // 23只留整数部分，把小数点后面砍掉
%取余7 % 21算“剩下多少”，最常用来判断奇偶
**幂2 ** 101024就是 2 的 10 次方
Python
12345
print(7 / 2)      # 3.5    真除法
print(4 / 2)      # 2.0   ← 注意：是 2.0 不是 2
print(7 // 2)     # 3      整除
print(7 % 2)      # 1      取余，结果是 1 说明 7 是奇数
print(2 ** 10)    # 1024   2 的 10 次方
判断一个数是奇数还是偶数，标准写法是看余数：n % 2 == 0 就是偶数，n % 2 == 1 就是奇数。

2.2 复数和下划线（了解即可）

Python 还有一种复数，虚部后面带个 j。初学者基本用不上，知道有这么个东西就行：

Python
123
z = 2 + 3j
print(z)         # (2+3j)
print(type(z))   # <class 'complex'>

另外，数字很大时可以用下划线分开，纯粹为了方便眼睛看，程序里完全一样：

Python
12
print(1_000_000)        # 1000000
print(1_000_000 == 1000000)   # True
一个新手必踩的坑：小数算不准。计算机用二进制存小数，有些十进制小数存不精确：
Python
12
print(0.1 + 0.2)              # 0.30000000000000004
print(0.1 + 0.2 == 0.3)       # False  ← 别用 == 直接比小数！
这不是 Python 的毛病，所有编程语言都这样。要比较小数，写成 abs(a - b) < 0.000001；要保留两位小数，用 round(0.1 + 0.2, 2) 得到 0.3。

三、字符串（str）

字符串就是一段文字。只要用引号包起来，不管是中文、英文、还是数字，都算字符串。

Python
12345
name = "小明"              # 双引号
city = '广州'              # 单引号，效果一样
message = "今年18岁"       # 数字在引号里也算文字
long_text = """第一行
第二行"""                  # 三引号可以跨行
单引号和双引号没有区别，挑一个用着顺手的一直用就行。三引号专门用来写多行文字。

3.1 拼接和重复

Python
123
print("Python" + "编程")    # Python编程    加号＝首尾接起来
print("哈哈" * 3)           # 哈哈哈哈哈哈   乘号＝重复几遍
print("-" * 20)             # --------------------  常用来画分隔线
想让数字和文字拼在一起，必须先把数字转成字符串，否则报错：
Python
12
print("年龄：" + 18)              # 报错 TypeError
print("年龄：" + str(18))         # 年龄：18   ✓
更省事的办法是用上一篇里的 f 字符串：f"年龄：{18}"。

3.2 索引和切片

字符串里的每个字符都有自己的位置编号，从 0 开始数：

Python
1234567
s = "Hello, World!"

print(s[0])      # H    第 0 个（也就是第一个）
print(s[-1])     # !    最后一个（负数从右边数）
print(s[0:5])    # Hello    从 0 取到 5（不含 5）
print(s[7:])     # World!   从 7 一直取到最后
print(len(s))    # 13   一共几个字符
写法含义结果
s[0]第 0 个字符（第一个）H
s[-1]最后 1 个字符!
s[0:5]第 0 到第 4 个（不含第 5 个）Hello
s[7:]第 7 个到最后World!
s[:5]开头到第 4 个Hello
s[0:5] 取到的是 5 个字符，不是 6 个——“含头不含尾”，写 0 到 5 就取 0、1、2、3、4。这是新手错得最多的一条。

3.3 字符串不能改（很重要）

字符串属于不可变类型：一旦写好，里面任何一个字符都不能单独修改。

Python
123
s = "hello"
s[0] = "H"
# 报错：TypeError: 'str' object does not support item assignment

想改只能重新拼一个新字符串：

Python
123
s = "hello"
s = "H" + s[1:]      # 取第 1 个到最后，前面接个 H
print(s)             # Hello
注意区分这两件事：不能改里面的字符，但可以让变量指向一个新字符串。前者不允许，后者随便用。

3.4 常用的几个操作

Python
1234567
s = "Hello, World!"

print(s.upper())                # HELLO, WORLD!   全变大写
print(s.lower())                # hello, world!   全变小写
print(s.replace("World", "Python"))   # Hello, Python!  替换文字
print("World" in s)             # True   有没有这个词
print(len(s))                   # 13     长度
s.upper() 这类方法不会改动原字符串，而是返回一个新的给你。写 s.upper() 之后 s 还是原来的样子，想用结果得接住：s2 = s.upper()。

四、列表（list）

列表是一串排好队的东西，用方括号 [] 包起来，中间用逗号隔开。

它有三个特点：有序（每个元素有固定位置）、可变（能加能删能改）、可重复（同一个值可以出现多次）。

Python
1234
fruits = ["苹果", "香蕉", "橙子"]
scores = [85, 92, 78]
mixed = [1, "苹果", 3.14, True]     # 一个列表里可以放不同类型
empty = []                          # 空列表
列表最大的优点就是能装不同类型的东西，这一点是很多语言做不到的。

4.1 取出元素

和字符串一样，用方括号加位置编号（索引），从 0 开始数：

Python
123456
fruits = ["苹果", "香蕉", "橙子"]

print(fruits[0])    # 苹果   第 0 个
print(fruits[1])    # 香蕉
print(fruits[-1])   # 橙子   最后一个
print(len(fruits))  # 3      一共几个
记不住从 0 开始？就想成“第一个的编号是 0”，后面的顺次加一。-1 永远指最后一个，取最后一个元素用它最保险。

4.2 增、删、改

这是列表最常用的三个动作，对照着记：

想干什么怎么写说明
在末尾加一个fruits.append("葡萄")最常用，永远加到最后
在指定位置插入fruits.insert(1, "芒果")插到第 1 个位置，原来后面的都往后挪
修改某个元素fruits[0] = "西瓜"把第 0 个换掉
删除指定的值fruits.remove("香蕉")按内容删，找不到会报错
删除指定位置fruits.pop()不写参数删最后一个，也可以写 pop(0)
看有几个元素len(fruits)长度
Python
1234567891011121314
shopping = ["苹果", "香蕉", "牛奶"]

shopping.append("鸡蛋")          # 末尾加
print(shopping)   # ['苹果', '香蕉', '牛奶', '鸡蛋']

shopping[1] = "芒果"             # 改第 1 个
print(shopping)   # ['苹果', '芒果', '牛奶', '鸡蛋']

shopping.remove("牛奶")          # 按值删
print(shopping)   # ['苹果', '芒果', '鸡蛋']

last = shopping.pop()            # 弹出最后一个
print(last)                      # 鸡蛋
print(shopping)   # ['苹果', '芒果']

4.3 切片：一次取一串

Python
123456
nums = [10, 20, 30, 40, 50]

print(nums[0:3])    # [10, 20, 30]   取前三个（不含第 3 个）
print(nums[:2])     # [10, 20]       从头取两个
print(nums[2:])     # [30, 40, 50]   从第 2 个取到最后
print(nums[-2:])    # [40, 50]       最后两个
切片的规则和字符串完全一样（含头不含尾），学会一个两个都会。切片取出来的是新列表，改它不会影响原来的。

五、元组（tuple）

元组长得和列表很像，区别是把方括号换成圆括号 ()，但有个关键不同：元组一旦创建就不能修改。

列表 list元组 tuple
符号[]()
能不能改能增能删能改定了就改不了
取值方式索引、切片索引、切片（一样）
适合放什么会变的数据固定不变的数据
生活中的样子购物车（随时加东西）身份证号、坐标（不能变）
Python
12345678
point = (10, 20)             # 一个坐标
rgb = (255, 128, 0)          # 一个颜色
weekdays = ("周一", "周二", "周三")

print(point[0])     # 10   取值和列表一样
print(point[-1])    # 20
print(len(rgb))     # 3
print(rgb[0:2])     # (255, 128)   也能切片

5.1 不能改，硬改就报错

Python
123
point = (10, 20)
point[0] = 5
# 报错：TypeError: 'tuple' object does not support item assignment
报错信息里的关键词是 does not support item assignment，意思是“不支持给元素赋值”。看到它，就知道你在改一个不允许改的东西（元组或字符串）。

5.2 只有一个元素时，必须加逗号

这是元组最容易踩的坑。想表示“只有一个元素的元组”，必须在元素后面加个逗号：

Python
12345
a = (5)      # 这不是元组！括号只是普通括号，a 是整数
b = (5,)     # 这才是元组，注意那个逗号

print(type(a))   # <class 'int'>
print(type(b))   # <class 'tuple'>
空元组写 () 就可以。单个元素的元组一定要带逗号——这个逗号不是排版习惯，是语法要求。

5.3 一个好用的特性：解包

元组可以一次性把里面的值分给几个变量，这在处理坐标、成对数据时特别方便：

Python
123456789
point = (10, 20)
x, y = point            # 一次分开
print(x)    # 10
print(y)    # 20

# 交换两个变量的值，Python 里一行就够
a, b = 1, 2
a, b = b, a
print(a, b)   # 2 1
这里的 a, b = 1, 2 其实右边就是一个元组 (1, 2)，只是括号可以省略。

六、字典（dict）

字典存的是成对的数据：一个“名字”，对应一个“内容”。用花括号 {} 包起来，写成 {键: 值}。

前面的名字叫键（key），后面的内容叫值（value）。就像查字典：给一个词（键），查它的解释（值）。

Python
123456
user = {
    "name": "小明",
    "age": 18,
    "gender": "男",
}
print(user)              # {'name': '小明', 'age': 18, 'gender': '男'}
键和值之间是冒号，每对之间用逗号。这两处最容易写错，写错就报语法错误。

6.1 取值、改值、加新值

Python
12345678
user = {"name": "小明", "age": 18}

print(user["name"])     # 小明     用键取值，不是用位置编号
user["age"] = 19        # 改：键已存在就是修改
print(user["age"])      # 19
user["height"] = 175    # 加：键不存在就是新增
print(user)
# {'name': '小明', 'age': 19, 'height': 175}
字典用键取值，不用编号。user[0] 是错的（除非你正好有个键叫 0）。这是从列表转过来最容易搞混的地方。

6.2 取不到键怎么办：用 get()

直接写 user["score"]，如果字典里没有这个键，程序会直接报错中断：

Python
123
user = {"name": "小明"}
print(user["score"])
# 报错：KeyError: 'score'

KeyError 是新手最常见的报错之一。稳妥的写法是用 get()，取不到不会崩，只会给你一个 None：

写法键存在键不存在
user["score"]返回值报 KeyError，程序中断
user.get("score")返回值返回 None，程序继续跑
user.get("score", 0)返回值返回你指定的默认值 0
不确定键一定存在，就用 get()。尤其是键来自用户输入或者其他程序的时候，用 get() 能少写很多防错代码。

6.3 两条规则

  1. 键必须唯一。后面写的同名键会覆盖前面的值。
  2. 键必须是不可变的类型，通常是字符串或数字。列表不能做键（会报 TypeError: unhashable type: 'list'），因为列表能改。
Python
123456
d = {"a": 1, "a": 2}
print(d)        # {'a': 2}   同名键，后面的覆盖前面

good = {"name": "小明"}       # 字符串做键 ✓
ok = {100: "满分"}            # 数字做键 ✓
# bad = {[1, 2]: "x"}         # 列表做键 ✗ 报错

6.4 把字典里的内容一个个拿出来

Python
123456789
user = {"name": "小明", "age": 18}

print(list(user.keys()))      # ['name', 'age']        所有键
print(list(user.values()))    # ['小明', 18]           所有值

for k, v in user.items():     # 一次拿到键和值
    print(k, "=", v)
# name = 小明
# age = 18
较新的 Python 3 版本 里，字典会记住你放进去的顺序，打印出来和写的顺序一致。但记住一点：取值永远靠键，不靠顺序——别写“第 0 个键”这种代码。

七、集合（set）

集合也是用花括号 {}，但它只存“不一样的东西”：重复的自动去掉，而且没有顺序。

Python
12345
nums = {1, 2, 3, 3, 4}
print(nums)          # {1, 2, 3, 4}   重复的 3 只剩一个

fruits = set(["苹果", "香蕉", "苹果"])
print(fruits)        # {'苹果', '香蕉'}
集合最拿手的活就是去重。一批名单里有重复的，套一层 set() 就干净了：
Python
12
names = ["张三", "李四", "张三", "王五"]
print(set(names))    # {'张三', '李四', '王五'}
反过来想“有几种不同的东西”，也用它：len(set(names)) 就是种类数。

7.1 不能按位置取，只能问“在不在”

集合没有顺序，所以不能用 nums[0] 这种写法：

Python
123
nums = {1, 2, 3}
print(nums[0])
# 报错：TypeError: 'set' object is not subscriptable

想知道某个东西在不在，用 in：

Python
123
nums = {1, 2, 3}
print(3 in nums)      # True
print(9 in nums)      # False
报错里的 not subscriptable 意思是“不能用方括号下标取”。看到它就检查：是不是对集合用了 [0]？

7.2 添加和删除

Python
123456
nums = {1, 2, 3}
nums.add(4)          # 加一个
print(nums)          # {1, 2, 3, 4}

nums.discard(1)      # 删一个（不存在也不报错）
print(nums)          # {2, 3, 4}
注意名字不一样：集合用 add()，列表用 append()。写混了会提示“没有这个属性”。

7.3 集合运算（它的另一个强项）

数学里的交、并、差，集合直接支持，写起来非常短：

运算符号例子结果含义
并集|{1,2,3} | {3,4,5}{1, 2, 3, 4, 5}两边合起来，重复的只算一个
交集&{1,2,3} & {3,4,5}{3}两边都有的
差集-{1,2,3} - {3,4,5}{1, 2}左边有、右边没有的
对称差^{1,2,3} ^ {3,4,5}{1, 2, 4, 5}只在一方出现过的
别把 & 和 and 搞混：这里 & 是集合求交集，and 是逻辑判断；就像 | 是求并集，or 是逻辑判断，它们作用在完全不同的东西上。

7.4 空集合的写法是个例外

Python
12345
a = {}          # 这是空字典，不是空集合！
b = set()       # 这才是空集合

print(type(a))  # <class 'dict'>
print(type(b))  # <class 'set'>
空集合只能用 set()。因为 {} 被字典先占用了。非空的集合可以写 {1, 2, 3}，这没有问题。

八、布尔（bool）

布尔是最简单也最重要的类型，它只有两个值：True（真）和 False（假）。

写的时候首字母必须大写，true 和 false 都是错的。它主要用在判断上：程序要不要走这一步，就看这个值是真是假。

Python
1234567
is_student = True
is_empty = False

print(5 > 3)      # True     比较的结果就是布尔值
print(5 == 5)     # True
print(5 < 3)      # False
print(type(True)) # <class 'bool'>

8.1 哪些东西算“假”

这一点掌握了能省很多事。Python 里下面这些值，在判断时都当假处理：

类型假值长什么样说明
数字0、0.0零就是假
字符串""空字符串是假
列表[]空列表是假
元组()空元组是假
字典 / 集合{}、set()空的都是假
特殊值None表示“什么都没有”

除了上面这些，其他都是真。有两处新手最容易看错，专门点一下：

判断一个列表是不是空的，不用写 len(lst) == 0，直接 if lst: 就行——空列表自动当假。这是 Python 的地道写法。

九、七种类型总览与选择建议

把前面讲的七种类型放在一张表里对照，先看符号、再看能不能改，最后看有没有重复：

十、可变与不可变（最容易栽的地方）

前面反复出现“可变 / 不可变”，这是数据类型里最需要真正理解的一点。先记住分组：

有哪些特点
可变（能改）list、dict、set原地就能改，改完还是同一个东西
不可变（改不了）int、float、str、tuple、bool想“改”只能造一个新的

10.1 一个必须知道的陷阱

看下面这段代码，先猜猜 a 最后是什么：

Python
123456
a = [1, 2]
b = a          # 注意这一行
b.append(3)

print(a)       # [1, 2, 3]   ← a 也变了！
print(b)       # [1, 2, 3]

很多人以为 b = a 是“把 a 复制一份给 b”，不是的。它的意思是“让 b 也指向同一个列表”，就像给同一个盒子又贴了一张标签。改盒子里的东西，两张标签看到的都一样。

想让两个互不影响，得真的复制一份：

Python
123456
a = [1, 2]
b = a.copy()       # 复制一份，互相独立
b.append(3)

print(a)           # [1, 2]      没受影响
print(b)           # [1, 2, 3]
字符串不会遇到这个问题（因为它不可变）。列表、字典、集合赋值给别人之前，先想一下：我是想共用，还是想各留一份？想各留一份就写 .copy()。

10.2 不可变的东西“改”的时候发生了什么

Python
12345
s = "ab"
s = s + "c"        # 这一步不是原地改，而是造了个新字符串 "abc" 再让 s 指向它

t = (1, 2)
# t[0] = 9         # 元组连这个都做不到，直接报错

所以“不可变”不是“变量不能重新赋值”，而是“这个东西本身不能被改动”。变量随时可以指向别的东西。

10.3 一个例外：元组里放列表

元组保证的是它自己那一层不能改。如果里面装的是列表，那列表还是能改的：

Python
123
t = (1, [2, 3])
t[1].append(4)      # 改的是里面的列表，元组本身没动
print(t)            # (1, [2, 3, 4])
这个现象知道就好。做作业时别故意这么写——看起来是“不可变的元组”，实际里面还能变，容易把自己绕进去。

10.4 为什么要设计成不可变的

  1. 更安全。坐标、身份证号这类不该变的东西，用元组就不会被别的代码不小心改掉。
  2. 能当字典的键。只有不可变的东西才能做键，所以字符串和数字能当键，列表不行。
  3. 更快。Python 内部处理不可变对象效率更高（这个了解即可）。
一句话总结：要变用 list，不变用 tuple。名字、成绩这种会改的用列表；坐标、日期这种固定的用元组。
