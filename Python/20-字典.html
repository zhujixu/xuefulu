一、为什么需要字典（按名字找值）

列表按顺序存东西，靠位置（第 0 个、第 1 个）找。但生活里很多信息不是靠「排第几」来找的，而是靠名字。

比如查一个同学的手机号，你是想「按名字查」而不是「记住他排第几」。这种「名字 → 值」的对应关系，就是字典。

字典里每一对叫一个键值对：键（key）是名字，值（value）是对应内容。键和值之间用冒号 : 分开，对与对之间用逗号分开，外面用花括号 {} 包住。

Python
12
phone = {'小明': '138001', '小红': '139002', '小刚': '137003'}
print('小明的手机号:', phone['小明'])

输出：

输出
1
小明的手机号: 138001

一句人话总结：列表是「第几个」，字典是「叫什么」。

什么时候用字典？当你想「按名字查东西」时用它：电话簿、成绩表、配置项、商品库存……凡是「键 → 值」的对应关系，字典最合适。

三、取值（d[k] 与 get，KeyError）

想拿某个键对应的值，用方括号写上键名：

Python
123
books = {'title': 'Python入门', 'author': 'Eric', 'year': 2015}
print(books['title'])
print(books['author'])

输出：

输出
12
Python入门
Eric

键不存在：直接取下标会报错

用 d['不存在的键'] 会抛 KeyError：

Python
12
books = {'title': 'Python入门'}
print(books['genre'])

运行后会报错（逐字照抄解释器）：

报错
1
KeyError: 'genre'

更安全的取法：get()

get() 在键不存在时，不会报错，而是返回 None（或者你指定的默认值）：

Python
123
books = {'title': 'Python入门'}
print(books.get('genre'))
print(books.get('genre', '未知类别'))

输出：

输出
12
None
未知类别
取「可能不存在」的键时，优先用 get(键, 默认值)。直接写 d[键] 虽然快，但键一旦不存在就整个程序崩在 KeyError 上。
口诀：确定键一定在，用 d[k]；拿不准在不在，用 d.get(k)。get 的第二个参数是「找不到时返回什么」。

四、添加与修改（d[k]=v、update）

添加：直接给一个新键赋值

Python
123
car = {'brand': 'Toyota', 'model': 'Corolla'}
car['color'] = 'Blue'
print(car)

输出：

输出
1
{'brand': 'Toyota', 'model': 'Corolla', 'color': 'Blue'}

修改：键已存在，再赋值就覆盖

Python
123
car = {'brand': 'Toyota', 'model': 'Corolla'}
car['model'] = 'Camry'
print(car)

输出：

输出
1
{'brand': 'Toyota', 'model': 'Camry'}

批量更新：update()

一次加或改多个键值对：

Python
12345
car = {'brand': 'Toyota', 'model': 'Corolla'}
car.update({'year': 2020, 'price': 20000})
print(car)
car.update({'model': 'Camry'})
print(car)

输出：

输出
12
{'brand': 'Toyota', 'model': 'Corolla', 'year': 2020, 'price': 20000}
{'brand': 'Toyota', 'model': 'Camry', 'year': 2020, 'price': 20000}

注意：update 里如果键已经存在，会更新对应的值；不存在才新增。

记住「d[键] = 值」这一个写法就够用了：键不在就是加，键在就是改。要一次加很多，再用 update()。

五、删除（del / pop / popitem / clear）

del：按键删掉一对

Python
123
animals = {'cat': 'mammal', 'bird': 'avian', 'fish': 'aquatic'}
del animals['bird']
print(animals)

输出：

输出
1
{'cat': 'mammal', 'fish': 'aquatic'}

pop：按鍵删，还会把「值」还给你

Python
1234
animals = {'cat': 'mammal', 'bird': 'avian', 'fish': 'aquatic'}
val = animals.pop('fish')
print("被删的值:", val)
print(animals)

输出：

输出
12
被删的值: aquatic
{'cat': 'mammal', 'bird': 'avian'}

popitem：删掉并返回「最后插入」的那一对

Python
1234
animals = {'cat': 'mammal', 'bird': 'avian', 'fish': 'aquatic'}
last = animals.popitem()
print(last)
print(animals)

输出：

输出
12
('fish', 'aquatic')
{'cat': 'mammal', 'bird': 'avian'}

clear：一键清空

Python
123
colors = {'red': '#FF0000', 'green': '#00FF00'}
colors.clear()
print(colors)

输出：

输出
1
{}
写法按什么删还能拿回值吗
del d[键]键不能
d.pop(键)键能，返回被删的值
d.popitem()最后插入的一对能，返回 (键, 值)
d.clear()全部不能，直接变空
想「删掉某个键并且还要用它的内容」，用 pop(键)；想清空重来，用 clear()。删不存在的键会报 KeyError，不确定在不在就先用 in 判断。

七、in 判断的是键不是值

in 用在字典上，判断的是键在不在，不是值在不在：

Python
123
d = {'name': '小明', 'age': 18}
print('name' in d)
print('小明' in d)

输出：

输出
12
True
False

'name' in d 是 True（name 是键）；'小明' in d 是 False（小明是值，不是键）。

新手常以为 in 会同时查键和值。在字典上它只认键。要判断值在不在这，用 值 in d.values()。
Python
12
d = {'name': '小明', 'age': 18}
print('小明' in d.values())

输出：

输出
1
True
想知道「某个值有没有出现」，就显式写 值 in d.values()；想知道「某个键在不在」，直接 键 in d。

八、字典的三条规矩（键唯一、键必须不可变、保留插入顺序）

规矩 1：同一个字典里，键不能重复

如果写重复的键，后面的会覆盖前面的，不会报错：

Python
12
d = {'a': 1, 'a': 2, 'b': 3}
print(d)

输出：

输出
1
{'a': 2, 'b': 3}

规矩 2：键必须「不可变」（可哈希）

键可以是数字、字符串、元组，但不能是列表、字典这种可变的：

Python
1
d = {[1, 2]: 3}

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: unhashable type: 'list'

规矩 3：字典保留「插入顺序」

老教材常说「字典无序」，那是以往的说法。较新的 Python 3 版本 里，字典会记住你添加键的先后顺序：

Python
12
d = {'b': 2, 'a': 1, 'c': 3}
print(list(d.keys()))

输出：

输出
1
['b', 'a', 'c']

输出顺序和写入顺序一致（b、a、c）。所以前面 popitem() 删掉的才是「最后插入」的那一对。

规矩说明反例后果
键唯一重复键后者覆盖前者不会报错，但前面的丢了
键不可变键得是数字/字符串/元组用列表当键报 unhashable
保留插入顺序按添加先后记住顺序老教材说无序，现已过时
如果教材或旧资料写「字典是无序的」，按现在的事实写：字典保留插入顺序。但别依赖这个顺序做重要判断——它只是恰好保持，不是「自动排序」。
三条规矩里最易踩的是第二条：想用「组合」当键（比如坐标），用元组 (x, y) 而不是列表，因为元组不可变、能当键。

打开任意 AI 对话工具（网页版或 App 都可以），试试这样问：为什么字典的键必须是不可变类型？用「列表当键会报错」的例子讲清楚背后的 hash 概念，要初中生能听懂

九、嵌套字典（一张学生信息表）

字典的值可以是任何东西，包括另一个字典。这样就能表示「表里有表」的结构，比如一张学生信息表：

Python
123456
students = {
    's01': {'name': '小明', 'score': 90, 'city': '北京'},
    's02': {'name': '小红', 'score': 85, 'city': '上海'},
}
print(students['s01']['name'])
print(students['s02']['score'])

输出：

输出
12
小明
85

读取时一层层往下点：students['s01'] 先拿到小明的那本小字典，再 ['name'] 拿到名字。

Python
123456
students = {
    's01': {'name': '小明', 'score': 90, 'city': '北京'},
    's02': {'name': '小红', 'score': 85, 'city': '上海'},
}
students['s01']['score'] = 95
print(students['s01'])

输出：

输出
1
{'name': '小明', 'score': 95, 'city': '北京'}
嵌套字典就像文件夹里套文件夹。访问越深的层，就多写一层方括号。处理真实表格数据（JSON、接口返回）时这种模式非常常见。

十、字典推导式

列表有列表推导式，字典也有字典推导式：一行就能从别的数据造出一个字典。写法就是把方括号换成花括号，里面写成 键: 值。

Python
12
{键: 值 for 变量 in 可迭代对象}
{键: 值 for 变量 in 可迭代对象 if 条件}

由浅入深看四种常见用法。

1. 用 range 造一批「数字 → 平方」

Python
1
print({x: x * x for x in range(1, 6)})

输出：

输出
1
{1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

2. 把两个列表「拉链」成一个字典

Python
1234
names = ['小明', '小红', '小刚']
scores = [92, 76, 85]
d = {name: score for name, score in zip(names, scores)}
print(d)

输出：

输出
1
{'小明': 92, '小红': 76, '小刚': 85}

3. 带条件：只保留想要的

Python
12
scores = {'小明': 92, '小红': 76, '小刚': 85}
print({k: v for k, v in scores.items() if v >= 85})

输出：

输出
1
{'小明': 92, '小刚': 85}

4. 把原来的值统一改一改

Python
12
prices = {'苹果': 5, '香蕉': 3}
print({k: v * 2 for k, v in prices.items()})

输出：

输出
1
{'苹果': 10, '香蕉': 6}

它和列表推导式的区别只有两点：外面是花括号，里面要写成 键: 值。

想要的结果写法
列表[表达式 for 变量 in 数据]
集合{表达式 for 变量 in 数据}
字典{键: 值 for 变量 in 数据}
带筛选（三种都能加）末尾加 if 条件
字典的键不能重复。如果推导式算出来的键有重复，后面的会悄悄覆盖前面的，只剩最后一个——写之前先想清楚「键到底是什么」。
Python
12
words = ['aa', 'ab', 'ba']
print({w[0]: w for w in words})    # 键 a 出现两次，只剩最后一个

输出：

输出
1
{'a': 'ab', 'b': 'ba'}
字典推导式最适合这三件事：两个列表配成对、按条件筛一部分、把所有的值统一加工。一时写不出来，就先用普通 for 循环写一遍，再翻译成推导式。

十二、常见坑（KeyError、列表当键 unhashable、遍历时改字典 RuntimeError、字典不能比大小）

坑 1：用 [] 取不存在的键直接崩

Python
12
d = {'a': 1}
print(d['b'])

运行后会报错（逐字照抄解释器）：

报错
1
KeyError: 'b'

会抛 KeyError。拿不准在不在，用 d.get('b')（返回 None 也不崩）。

坑 2：用列表当键

Python
1
d = {[1, 2]: 3}

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: unhashable type: 'list'

列表可变，不能当键，会报 unhashable type: 'list'。换成元组 (1, 2) 就行。

坑 3：遍历字典时删元素

Python
123
d = {'a': 1, 'b': 2}
for k in d:
    del d[k]

运行后会报错（逐字照抄解释器）：

报错
1
RuntimeError: dictionary changed size during iteration

一边遍历一边改字典大小，会报 RuntimeError: dictionary changed size during iteration。正确做法：先收集要删的键，遍历完再删，或遍历 list(d.keys()) 的副本。

坑 4：字典之间不能比大小

Python
1
print({'a': 1} >= {'a': 1})

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: '>=' not supported between instances of 'dict' and 'dict'

字典只支持 == 和 != 判断相不相等，>、<、>=、<= 都会报 TypeError。两个字典谁「大」没有意义，别写。

坑 5：键重复，前面的被悄悄覆盖

Python
12
d = {'a': 1, 'a': 2}
print(d)

输出：

输出
1
{'a': 2}

坑 6：in 判断的是键不是值

Python
123
d = {'name': '小明'}
print('小明' in d)
print('小明' in d.values())

输出：

输出
12
False
True
坑 3 和坑 4 是最容易在考试/作业里栽的：遍历时改字典要删「副本」，字典之间别用大小比较。另外「字典无序」是旧说法，现在的 Python 3 已经保留插入顺序了。

1字典最适合下面哪种使用场景？

  • A. 存一串有顺序的数字
  • B. 按名字（键）快速查到对应的值
  • C. 只存 True / False
  • D. 反复做数学运算
答案：B。字典是「键 → 值」的映射，按名字查东西最快：电话簿、成绩表、配置项都是它的主场。存一串有序数字用列表更合适。

2下面哪一行能正确创建一个空字典？

  • A. d = ()
  • B. d = []
  • C. d = {}
  • D. d = ""
答案：C。空字典用花括号 {}。() 是空元组，[] 是空列表，"" 是空字符串。

3d = {'a': 1}，执行 print(d['x']) 会发生什么？

  • A. 返回 None
  • B. 返回 0
  • C. 报 KeyError
  • D. 返回空字符串
答案：C。用方括号直接取一个不存在的键会抛 KeyError: 'x'。想不报错就用 d.get('x')，它返回 None。

4d = {'a': 1}，执行 print(d.get('x')) 返回什么？

  • A. None
  • B. 'x'
  • C. 报错
  • D. 1
答案：A。get() 在键不存在时返回 None 而不报错。如果写 d.get('x', '缺省')，不存在时就返回你给的默认值。

5d = {'a': 1}，执行 print(1 in d) 返回什么？

  • A. True
  • B. False
  • C. 报错
  • D. 'a'
答案：B。字典上的 in 只检查键在不在，1 是值不是键，所以是 False。要判断值在不在要写 1 in d.values()。

6d = {'a': 1}，执行 d['b'] = 2 之后，d 变成？

  • A. 报错
  • B. {'a': 1, 'b': 2}
  • C. {'a': 1}
  • D. 把 'a' 删掉了
答案：B。d['b'] = 2 给新键 'b' 赋值，字典变成 {'a':1,'b':2}。这个写法「键在就改、键不在就加」，非常常用。

7d = {'a': 1, 'b': 2}，执行 print(d.pop('a')) 会删掉并返回什么？

  • A. 'b'
  • B. 2
  • C. ('a', 1)
  • D. 1
答案：D。pop(键) 删掉该键并把对应的值返回，所以返回 1，字典剩下 {'b': 2}。要拿「键+值」pair 用 popitem()。

8遍历字典 for k in d: 时，循环变量 k 取到的是？

  • A. 键
  • B. 值
  • C. 键值对
  • D. 索引序号
答案：A。直接遍历字典默认拿到键。想同时拿键和值用 for k, v in d.items():；只拿值用 for v in d.values():。

9较新的 Python 3 版本 里，d = {'b':2, 'a':1, 'c':3} 后 list(d.keys()) 的顺序是？

  • A. ['a', 'b', 'c']
  • B. ['c', 'b', 'a']
  • C. ['b', 'a', 'c']
  • D. 随机，每次不一样
答案：C。现在的字典保留插入顺序，按写入先后输出，所以是 ['b','a','c']。老的「字典无序」说法已过时。

10下面哪个能合法地当作字典的键？

  • A. [1, 2]
  • B. {1: 2}
  • C. (1, [2, 3])
  • D. (1, 2)
答案：D。键必须不可变（可哈希）。列表 [1,2]、字典、以及含列表的元组 (1,[2,3]) 都不可哈希会报错；(1,2) 是不可变元组，能当键。

11{x: x * x for x in range(1, 4)} 的结果是？

  • A. {1: 1, 2: 4, 3: 9}
  • B. [1, 4, 9]
  • C. {1, 4, 9}
  • D. (1, 4, 9)
答案：A。字典推导式外面是花括号、里面写成 键: 值，所以得到的是字典。只想要一串值，用列表推导式 [x * x for x in range(1, 4)]。

12想从字典 d 里筛出「值大于 60」的键值对，下面哪一句对？

  • A. {k for k, v in d.items() if v > 60}
  • B. [k for k in d if v > 60]
  • C. {k: v for k in d if v > 60}
  • D. {k: v for k, v in d.items() if v > 60}
答案：D。要同时拿到键和值，必须遍历 d.items() 并解包成 k, v，条件写在 if 后面。只写 for k in d 拿不到值 v，会报 NameError。
