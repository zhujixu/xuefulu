Python 选择结构：让程序学会做判断点击此处可返回 Python 基础教程导航页

一、什么是选择结构

先看三句生活里的话：

  • 如果下雨，我就带伞（不下雨就不带）；
  • 体温超过 38 度，就去医院（没超过就不去）；
  • 分数 90 以上是 A，80 以上是 B，60 以上是 C，否则不及格。

这三句话有同一个套路：先问一句「是不是」，再决定做哪件事。程序里的选择结构就是把这种套路翻译成代码。

前面几篇里的代码都是「一条道走到黑」——写几行就从上到下执行几行。从这一篇开始，程序会看着办了：条件成立走这条路，不成立走那条路。

Python 的选择结构，常见的长相就下面这几种：

类型长相一句话解释本篇第几节
单分支if 条件:条件成立就做，不成立就跳过第三节
双分支if 条件: … else: …两条路里挑一条走第四节
多分支if 条件1: … elif 条件2: … else: …多条岔路里挑一条走第五、六节
match 分支match 值: … case 值1: … case _: …拿一个值去和一堆候选值比，命中一个就停第七节

另外还有几个「加料」的玩法：match 语句（拿一个值去挑分支，第七节）、嵌套（分支里面再放分支，第八节）和跳转表（用字典代替一大串 elif，第十节）。

这一篇一共准备了 20 多个能直接跑的基础案例，从「判断成年」到「快递费计算」，都贴生活、都只有几行。建议的学习方法：先自己猜输出，再敲进 Python 跑一遍看对不对。
条件本身怎么写（比较、and/or/not、什么算真什么算假），在《13-条件表达式》里已经讲透了。这一篇第九节只给一张速查表，不重复展开。

二、if 语句的四个零件

单分支的骨架只有两行。下面是「长相」示意图，把 条件 换成真实判断（比如 age >= 18）才能运行：

Python
123
# 示意：把「条件」换成真实判断，例如 age >= 18
if 条件:
    条件成立时要执行的代码

看着简单，但它有四个零件，缺一个都跑不起来：

零件例子里的样子要求
① 关键字 ifif全小写，不能写成 If 或 IF
② 条件age >= 18一句结果是 True 或 False 的话
③ 冒号:必须是英文半角冒号，中文的 ： 会报错
④ 缩进行首 4 个空格告诉 Python「这一行属于上面那个 if」

把零件装上，就是一个完整的例子：

Python
123
age = 20
if age >= 18:
    print('您已成年，可以进入！')

运行结果：

输出
1
您已成年，可以进入！

缩进是「分组」的意思

缩进不是为了让代码好看，而是在划范围：缩进相同的几行，算同一组。

Python
12345
age = 20
if age >= 18:
    print('第一句')        # 属于 if 这一组
    print('第二句')        # 也属于 if 这一组
print('这句永远执行')      # 缩回去了，已经跑出 if 的范围

运行结果：

输出
123
第一句
第二句
这句永远执行
Python 对缩进是严格执法：该缩进不缩进、不该缩进却缩进、同一组里空格数不一样，都会直接报错（见第十三节）。新手 90% 的报错都在这里。
在 IDLE 里，if …: 那一行按回车后，编辑器会自动帮你缩进 4 格。想提前结束这一组，按一下退格键（或者 Shift + Tab）让光标退回来就行。缩进统一用 4 个空格，不要一半用 Tab 一半用空格。

三、单分支：条件成立才做事

单分支是最简单的选择结构：条件成立就做那件事，不成立就跳过，什么都不发生（不会报错，也不会提示）。

1

四、双分支：二选一

把两条路都写出来，就是双分支（同样是示意，不是能直接跑的真代码）：

Python
12345
# 示意：把「条件」和两边的「要做的事」换成自己的内容
if 条件:
    条件成立时走这里
else:
    条件不成立时走这里
注意两个细节：else 那一行后面只跟一个冒号，不能写条件。写 else score < 60: 会直接报错。else 的意思就是「剩下的所有情况」。

案例 1：奇数还是偶数

Python
12345

if num % 2 == 0:
    print(f'{num} 是偶数')
else:
    print(f'{num} 是奇数')
输出
1
7 是奇数

% 是取余数，num % 2 就是「除以 2 剩多少」：剩 0 是偶数，剩 1 是奇数。

五、多分支：多个岔路

岔路超过两个，就用 elif（它是 else if 的缩写）继续往下接（下面是示意）：

示意
123456789
# 示意：岔路多了，就一路 elif 接下去
if 条件1:
    条件1成立时做的事
elif 条件2:
    条件1不成立、条件2成立时做的事
elif 条件3:
    前面都不成立、条件3成立时做的事
else:
    上面全都不成立时做的事（这一节可以省略）
Python 里没有 else if 这种写法，一定要写成一个词 elif。写成 else if 会报语法错误。

案例 1：成绩等级 A / B / C / D / F

Python
1234567891011
score = 85
if score >= 90:
    print('成绩等级为 A')
elif score >= 80:
    print('成绩等级为 B')
elif score >= 70:
    print('成绩等级为 C')
elif score >= 60:
    print('成绩等级为 D')
else:
    print('成绩等级为 F')
输出
1
成绩等级为 B

85 分从第一条往下一路问下来：90 以上吗？不是；80 以上吗？是——于是打印 B，后面的条件根本不会再问。

六、elif 的三条铁律

多分支能跑起来不难，难的是写对顺序。这三条一定要记住。

铁律一：从上往下一句句问

程序不是「同时看所有条件」，而是从第一个 if 开始，一句一句往下问。

铁律二：命中一个就停下

只要有一个条件成立，执行完它那一组代码，整个 if / elif 链就结束了，后面的条件连看都不看。

铁律三：顺序不能乱，宽的条件要往下放

看这个写错的例子：

Python
12345
score = 95
if score >= 60:
    print('及格')
elif score >= 90:
    print('优秀')
输出
1
及格

95 分明明是优秀，却打印了「及格」！因为 score >= 60 先被问到、又正好成立，程序打印完就掉头走了，永远轮不到 score >= 90。把两条换个位置就对了：

Python
12345
score = 95
if score >= 90:
    print('优秀')
elif score >= 60:
    print('及格')
输出
1
优秀
写多分支时的口诀：条件越「严」的越往上放，越「宽」的越往下放。像 >= 60 这种最宽的条件，放到最后当 else 的前一步，绝不会出错。

顺带弄清：两个独立的 if 和 if / elif 有什么区别？

这是新手最容易混淆的一处。两个独立的 if 会各问各的，可能同时命中；if / elif 只会命中一个。

Python
1234567891011
score = 95
print('--- 两个独立的 if ---')
if score >= 90:
    print('优秀')
if score >= 60:
    print('及格')
print('--- if / elif ---')
if score >= 90:
    print('优秀')
elif score >= 60:
    print('及格')
输出
12345
--- 两个独立的 if ---
优秀
及格
--- if / elif ---
优秀

同样是 95 分：两个独立 if 打印了两行，if / elif 只打印了一行。用哪个，取决于你的需求——「只挑一条路」用 elif，「每条规则都要独立检查」才用两个 if。

七、match 语句：多分支的新写法

较新的 Python 3 版本 里，选择结构还多了一个新成员——match 语句。它长得有点像其他语言里的 switch / case，专门处理一种很常见的多分支：拿一个值，去和一堆候选值挨个比一比，跟谁对得上就走谁。

先看长相。下面是示意图，把「值」和「候选值」换成真实内容才能跑：

示意
12345678
# 示意：把「值」换成要判断的变量，把「候选值」换成真实的值
match 值:
    case 候选值1:
        命中候选值1时要做的事，可以写好几行
    case 候选值2:
        命中候选值2时要做的事
    case _:
        前面都没命中时要做的事

三个零件，格式要求和 if 一样严格：

零件样子要求
① matchmatch 值:要判断的那个值，后面跟英文冒号
② casecase 候选值:一个候选写一行，有几行就有几个候选，后面也要冒号
③ case _:case _:兜底：上面全都没命中时走这里，相当于 else
和 if 一样，冒号必须是英文半角，case 下面的代码要缩进 4 格，同一个 match 里的所有 case 要对齐。漏冒号、乱缩进，报的错和 if 一模一样。
case _: 里的下划线 _ 是「随便什么都行」的意思，作用等于 if 里的 else。建议每个 match 都留一个 case _: 兜底，免得输入了意料之外的值、程序一声不吭。

案例 1：数字转星期几

第五节的案例 4 是用七个 elif 写的，这里换成 match 再写一遍，对比着看：

Python
123456789101112131415161718
day = 3
match day:
    case 1:
        print('星期一')
    case 2:
        print('星期二')
    case 3:
        print('星期三')
    case 4:
        print('星期四')
    case 5:
        print('星期五')
    case 6:
        print('星期六')
    case 7:
        print('星期日')
    case _:
        print('输入的数字不在 1-7 范围内')
输出
1
星期三

「一个数字对应一个星期几」这种一对一的多分支，用 match 一眼就能看出对应关系，改起来也方便——想加一条规则，直接加一个 case 就行。

案例 2：命令菜单

平时写的小工具经常要认命令，这种「字符串对字符串」的匹配正是 match 的拿手戏：

Python
12345678910
command = 'quit'
match command:
    case 'start':
        print('正在启动...')
    case 'pause':
        print('已暂停')
    case 'quit':
        print('退出程序')
    case _:
        print('未知命令，请重新输入')
输出
1
退出程序

案例 3：case 后面再加一个 if（守卫）

case 后面跟的是一个值，不是一句条件——所以不能直接写 case >= 90:（那是语法错误）。想按范围判断，要在值后面再接一个 if，这个 if 叫守卫：

Python
12345678
score = 85
match score:
    case s if s >= 90:
        print('优秀')
    case s if s >= 60:
        print('及格')
    case _:
        print('不及格')
输出
1
及格

这里的 case s 意思是「先把命中的值收进变量 s」，后面 if s >= 60 再拿 s 去问一句。

带守卫的 case，排序规则和第六节的 elif 铁律一模一样：越「宽」的条件越往下放。要是把 case s if s >= 60: 放到前面，85 分就会被它先拦住，永远轮不到「优秀」。

案例 4：一次匹配好几个值（用 |）

| 读作「或者」，能把几个候选并进同一个 case：

Python
12345678
answer = 'Y'
match answer:
    case 'y' | 'Y':
        print('你选择了「是」')
    case 'n' | 'N':
        print('你选择了「否」')
    case _:
        print('请输入 y 或 n')
输出
1
你选择了「是」

case 'y' | 'Y': 相当于 if 里写 answer == 'y' or answer == 'Y'，但更短、更整齐。

案例 5：匹配「结构」（进阶，了解即可）

match 比一般的 switch 更强的地方，是它还能比结构——比如「两个数组成的元组」，顺便把每个位置上的数取出来用：

Python
12345678910
point = (0, 5)
match point:
    case (0, 0):
        print('原点')
    case (0, y):
        print(f'在 y 轴上，y = {y}')
    case (x, 0):
        print(f'在 x 轴上，x = {x}')
    case (x, y):
        print(f'普通点 ({x}, {y})')
输出
1
在 y 轴上，y = 5

这一段用到元组和 f-string，如果还没学到，跳过完全没问题，知道「match 还能按结构拆着匹配」就够了。

那到底用 match 还是 if / elif？

要判断的情况推荐写法
一个值 vs 一堆固定候选（都是「等于」）match，或者第十节的跳转表
条件里有大小比较（>=、<、一个范围）if / elif
几个不同变量一起判断，或者判断真假if / elif
要顺便把结构里的值取出来用match（案例 5）
match 是较新的 Python 3 版本 才加入的语法。如果版本太老，运行到 match 那一行会报 SyntaxError: invalid syntax。用 python --version 看一下自己的版本——装官网最新的 Python 3 就完全支持。
match 只是多了一种写法，不是 if 的替代品：判「等于某个值」用它清爽；判大小、判真假、几个变量一起判断，还是 if / elif 更直接。基础阶段先把 if 用熟，match 当锦上添花就好。

八、嵌套：分支里再放分支

嵌套就是在一个分支里面，再写一整套分支。语法上没有任何新东西，只是缩进多一层（每进一层加 4 个空格）。

案例 1：先分正负，再分奇偶

Python
1234567891011
num = -8
if num > 0:
    if num % 2 == 0:
        print(f'{num} 是正偶数')
    else:
        print(f'{num} 是正奇数')
else:
    if num % 2 == 0:
        print(f'{num} 是负偶数')
    else:
        print(f'{num} 是负奇数')
输出
1
-8 是负偶数

读代码的窍门：先看缩进最浅的那一层。这里最外层只有一个 if / else（分正负），每个分支里又各自藏了一套小 if / else（分奇偶）。

案例 2：某年某月有几天

十、跳转表：岔路特别多时用字典

如果多分支长成这样——每个条件都是「某个值等于某个数 / 某某字符串」，一写就是七八个 elif——那它其实可以换一种更清爽的写法：把「值 → 结果」做成一张字典表，直接查表。这张表就叫跳转表。

写法长得像适合的场景
if / elif 链一连串 elif day == 1: … elif day == 2: …条件里有大小比较（>=、<、范围）
跳转表codes = {'red': '#FF0000', …} 然后 codes[name]条件都是「等于某个值」，一对一查表

1. = 和 ==

两者都能做二选一，但一个产出值、一个是语句：

现象原因

11关于 match 语句，下面说法正确的是？

  • A. 它是较新的 Python 3 版本 才加入的；从上往下一路比，命中一个 case 就结束
  • B. case 后面可以直接写 >= 90 这样的比较
  • C. 有了 match 之后就不能再用 if / elif 了
  • D. match 里的 case 一行都不能少，必须把每种情况都写全
答案：A。match 是较新的 Python 3 版本 新增的语法，脾气和 elif 一样：从上往下一路比、命中一条就停。B 错在 case 后面写的是值不是条件，写 case >= 90: 会报 SyntaxError，要按范围判断得用守卫 case s if s >= 90:；C 错在两者是并列关系，判大小照样用 if / elif；D 错在不需要写全，没匹配到的值直接跳过（想要兜底就补一个 case _:）。

12match 语句里，想表示「上面所有 case 都没命中时走这里」，应该怎么写？

  • A. default:
  • B. else:
  • C. case '':
  • D. case _:
答案：D。match 用 case _: 兜底，下划线 _ 表示「随便什么都行」，作用相当于 if 里的 else。A 的 default: 和 B 的 else: 都不是 match 的语法，会报 SyntaxError；C 只会匹配「空字符串」这一个具体的值，接不住其他情况。
