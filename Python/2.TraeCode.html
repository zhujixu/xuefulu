TraeCode 基础操作指南

一、先认识 TraeCode 的界面

TraeCode 是一个带 AI 助手的代码编辑器：左边管理文件，中间写代码，右边随时能问 AI。 第一次打开会觉得东西有点多，其实只要认清下面四个区域，就够用了。

区域位置作用
活动栏最左侧一竖条图标切换资源管理器、搜索、源代码管理等面板
文件资源管理器左侧面板以文件夹为单位展示项目里的所有文件
编辑区中间大片区域写代码、改代码的地方，可以同时开多个标签页
AI 对话区右侧（按 Ctrl + U 打开）向 AI 提问、让它生成或修改代码

底部还有一块终端（Terminal），是直接给电脑下命令的地方， 运行脚本、安装库都在这里，第五节会讲怎么打开它。

界面上的中文/英文可以在设置里切换。找不到某个面板时，先去最左侧的活动栏点一圈，绝大多数面板都是在那里开关的。

二、打开文件夹：TraeCode 以项目为单位

TraeCode 不像 IDLE 那样一次只开一个文件，它是以文件夹为单位工作的： 打开一个文件夹，就等于打开一个项目，左侧文件树里显示的就是这个文件夹里的全部内容。

  1. 点菜单 文件 → 打开文件夹；
  2. 在弹出的窗口里选中你要用的文件夹（例如桌面上新建的 python_study）；
  3. 左侧文件资源管理器里就会出现这个文件夹里的文件，可以逐层展开。
建议每做一个新练习就建一个新文件夹，一个项目一个文件夹。这样 AI 能看到的上下文更干净，文件也不会混在一起。

三、新建并运行 .py 文件

1. 新建文件

在左侧文件资源管理器里，右键目标文件夹 → 选 新建文件， 然后输入文件名，以 .py 结尾，例如 hello.py。

2. 写一行代码

Python
1
print("Hello, TraeCode!")

写完后按 Ctrl + S 保存（文件名后面的小圆点消失，就说明存好了）。

3. 运行它

最省事的办法是点编辑区右上角的 ▷ 运行按钮；也可以打开终端，敲命令运行。

运行成功后，输出会显示在下方终端或输出面板里：

输出
1
Hello, TraeCode!

用终端运行，就是先进入文件所在的文件夹，再用 python 加上文件名：

命令
1
python hello.py
运行方式操作适合什么时候用
右上角运行按钮点编辑区右上角的 ▷快速试一下当前文件
终端命令在终端里敲 python hello.py想看完整报错、或需要带参数运行
如果终端提示 python 不是内部或外部命令，说明装 Python 时没勾选 Add python.exe to PATH，重装一次并勾上即可。另外记得确认右下角选的解释器是你安装的那个 Python。

四、新建 .ipynb 文件

.ipynb 是 Jupyter Notebook 格式，它把代码切成一个个单元格， 可以逐格运行、逐格看结果，非常适合做数据分析和分步调试。

  1. 同样在左侧资源管理器中右键目标文件夹；
  2. 选 新建文件，文件名以 .ipynb 结尾，例如 analysis.ipynb；
  3. TraeCode 会自动把它识别为 Notebook，以单元格形式打开。

每个单元格单独运行：写完一格，按 Shift + Enter 运行它并跳到下一格。

第一次打开 Notebook 时，记得先在右下角选择 Python 解释器，否则运行单元格会提示找不到内核（kernel）。

五、高频快捷键一览

TraeCode 用的快捷键和 VS Code 是同一套。下面这些键位不是凭印象写的， 都是从本机安装的 TraeCode 键盘映射表里逐条核对过的。 想看全部，点「文件 → 首选项 → 键盘快捷方式」就能打开完整清单。

1. 先记住这四个

快捷键作用
Ctrl + U打开 / 关闭侧边 AI 对话框（较完整的任务沟通）
Ctrl + I打开行内 AI 对话框（不离开编辑器，围绕当前代码提问）

Ctrl + 反引号键打开 / 关闭底部终端（反引号在键盘左上角 Esc 下面）

2. 注释与缩进（写 Python 每天都用）

这一组是新手最容易漏掉、却最省时间的。Python 靠缩进表示代码层级， 所以「整块缩进 / 取消缩进」和「整块注释」几乎天天要用。

快捷键作用
Ctrl + /注释 / 取消注释当前行；选中多行就整块一起切换。写完一段想先跑通，用它把几行暂时「关掉」最方便
Tab光标停在行首时＝整行右移一级缩进；选中多行再按，整块一起缩进
Shift + Tab反方向：整行或选中多行左移一级，用来取消缩进
Ctrl + ]增加缩进（右方括号键，光标不必停在行首）
Ctrl + [减少缩进（左方括号键）
Shift + Alt + F一键格式化整份文件：缩进乱了、空格多了，按它自动排整齐
Shift + Alt + A加整块注释（/* ... */ 那种）。Python 里一般用不上，写网页时会用到
按 Tab 时，TraeCode 默认插入的是 4 个空格而不是制表符——这正是 Python 推荐的做法。最怕的是同一份文件里一会儿用 Tab、一会儿用空格，报错时会提示 TabError 或 IndentationError。真遇到了，用 Shift + Alt + F 格式化一遍就能自动统一。

Ctrl + Enter在下方插入一个空行，光标直接跳过去
Ctrl + Shift + Enter在上方插入一个空行

4. 多光标：一次改很多处

用它改同名的变量特别快，比一个个找省太多时间。

快捷键作用

Ctrl + Alt + ↓在下一行同一列加一个光标（备用键：Ctrl + Shift + ↓）
Ctrl + Alt + ↑在上一行同一列加一个光标（备用键：Ctrl + Shift + ↑）

六、把文件或代码添加到对话

想让 AI 看懂你正在处理的代码，最直接的办法就是「添加到对话」。它有两种常用方式。

方式一：选中代码添加

  1. 在编辑器中选中一段代码；
  2. 点悬浮菜单里的 添加到对话 按钮；
  3. 所选内容会出现在 AI 对话框底部的输入框里，还带着文件名和行号。

比如选中这段：

Python
12
def add(a, b):
    return a + b

方式二：用 # 符号添加

在 AI 对话框的输入框里输入 #，会弹出上下文选择面板， 可以挂上文件、文件夹、整个代码仓库，比复制粘贴更准确。

加了「文件名 + 行号」之后，AI 的答复会更精准，也方便你对照着看是哪一行被改了。

七、用 AI 给代码加注释

代码能跑通，但过两天自己都看不懂——这时让 AI 补注释最快。它有两种方式。

方式一：行内对话（推荐）

  1. 选中需要加注释的代码；
  2. 按 Ctrl + I 打开行内对话；
  3. 输入 「为这段代码添加注释」；
  4. AI 会在原地生成带注释的版本，你可以选择接受或继续修改。

方式二：侧边对话

  1. 选中代码 → 点 添加到对话；
  2. 在侧边对话框里输入 「为选中的代码生成行间注释」；
  3. AI 会返回一份带注释的代码，你复制回去即可。

加注释之前：

Python
12
def calc(x, y):
    return x * y + 10

加注释之后（AI 生成的注释会以 # 开头）：

Python
123
def calc(x, y):
    # 先算出 x 与 y 的乘积，再加上 10 作为固定补偿
    return x * y + 10
AI 写的注释偶尔会理解偏。加完注释扫一眼，跟代码对不上的地方自己改一下，别直接照抄。

八、用 AI 解释代码

遇到看不懂的代码，不用先自己硬啃——让 AI 讲一遍是最快的路径。

  1. 选中要解释的代码片段；
  2. 按 Ctrl + I 打开行内对话；
  3. 输入 「解释这段代码的作用」 或 「这段代码在做什么」；
  4. AI 会逐行或逐段把逻辑讲清楚。

比如这段：

Python
123
scores = [88, 92, 75, 60]
total = sum(scores)
print(f"总分: {total}, 平均分: {total / len(scores):.1f}")

运行结果是：

输出
1
总分: 315, 平均分: 78.8

让 AI 解释，它会告诉你：sum() 把列表里的数加起来、len() 数出有几个数、 f"..." 是格式化字符串、:.1f 表示保留一位小数。

想让解释更贴合你的水平，可以在提问里加一句限定，例如「我是刚开始学的，用最简单的话讲」。

九、用 AI 帮你排查报错

程序报错时，不要只把代码丢给 AI——把报错原文一起贴上，AI 才能对症下药。

假设你少写了一个右括号：

Python
1
print("你好，TraeCode"

运行后终端里会出现：

报错
1234
  File "/Users/你的用户名/python_study/hello.py", line 1
    print("你好，TraeCode"
         ^
SyntaxError: '(' was never closed

正确的问法是：先选中报错的代码，按 Ctrl + I，然后把报错的最后一行也贴进去。比如可以这样问：

建议的提问模板：
运行这段代码时报错：
SyntaxError: '(' was never closed
请告诉我哪里错了，并给出修改后的代码。

AI 会直接指出「左括号 ( 没有对应的右括号」，并把补好的代码给你。

贴给 AI 什么作用
报错的最后一行这是最关键的，写明了错误类型和原因
出错的代码让 AI 能定位到具体哪一句
你的意图（想做什么）AI 才能给出符合你本意的改法，而不是随便凑一个能跑的版本
AI 给的代码一定要自己跑一遍再交作业。看懂它改了什么、为什么这样改，才算真的学会；直接抄等于把问题留到考试。

十、常见问题

  • 左侧文件树不见了：点最左侧活动栏的资源管理器图标即可展开，不用重装。
  • 按 Ctrl + U 没有反应：快捷键要先让 TraeCode 窗口处于激活状态（先点一下编辑区）； Mac 上是 Cmd + U。
  • AI 的回答牛头不对马嘴：多半是它没看到你的代码。先选中代码 → 添加到对话再提问。
  • 运行按钮点了没反应：先确认文件已保存、且右下角选的 Python 解释器是正确的那一个。
  • 终端里 python 不认识：安装 Python 时没勾 Add python.exe to PATH，重装并勾上。
  • .ipynb 单元格跑不起来：右下角还没选解释器（内核），选好就能运行。
  • 文件的图标变成灰色：只是扩展名不认识，不影响内容；把后缀改成 .py 或 .ipynb 即可。

  • D. Ctrl + S
答案：B。选中多行后按 Tab，整块右移一级缩进（默认一级 4 个空格）；按 Shift + Tab 则整块左移，用来取消缩进。光标停在行首时，只按 Tab 也能缩进当前这一行。

16想把一个变量名在文件里出现的多处一次改掉，最省事的做法是？

  • A. 用 Ctrl + F 逐个找到，再一个个手改
  • B. 删掉整个文件重新写一遍
  • C. 把变量名改短一点
  • D. 把光标放在变量名上，连按 Ctrl + D 选中所有同名处，再一起改
答案：D。光标放在词上按 Ctrl + D 会选中这个词，连按可以接着选中下一个相同的词，多光标同时输入，一次改完。另一个办法是按 F2 直接重命名，文件里同名的地方一起改。
