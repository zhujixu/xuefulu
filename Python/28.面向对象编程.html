Python 面向对象编程：自己动手造一个「类型」

一、为什么需要「类」（把数据和操作打包）

前面学过列表、字典、函数。真写一个「学生成绩管理」的小程序，你多半会这样描述一个学生：

Python
1
student = {'姓名': '小明', '年龄': 18, '成绩': 92}

一个学生没问题。可当你有 30 个学生，还要给每个人「打招呼」「算等级」时，就会发现一件别扭的事：数据（姓名、成绩）装在字典里，处理数据的函数却散落在外面。

Python
12345
def 打招呼(学生):
    print('大家好，我是', 学生['姓名'])

def 算等级(学生):
    return '优秀' if 学生['成绩'] >= 90 else '及格'

这么写能跑，但有两个隐患：① 字典的键全靠字符串，写成 学生['性名'] 要等到运行时才报错；② 数据和操作它的函数没有绑在一起，谁都能随手改，代码一长就乱。

类（class）要解决的正是这件事：把「这一类东西有哪些数据」和「它们能做什么」打包成一个整体，然后像用模具一样，造出一个一个具体的对象。

说法英文一句话
类class模具／图纸，描述「这类东西长什么样、能做什么」
对象（实例）object / instance用模具造出来的一块，各自装着不同的数据
属性attribute对象身上存的数据，如 name、age
方法method写在类里的函数，专门处理这类对象

打个比方：类＝月饼模具，对象＝压出来的一块块月饼。模具只有一个，月饼可以压很多块；每块月饼的馅儿（属性值）还能各不相同。

什么时候该用类？当你要反复描述「一类有共同特征的东西」时——学生、图书、银行账户、游戏角色。如果只是临时存几个数，列表和字典就够了，不必硬套类。

二、定义类与创建对象（class、__init__、self）

定义类的关键字是 class，类名习惯用「大驼峰」写法（每个单词首字母大写，如 BankAccount）。

Python
1234
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

短短四行，拆开看是三件事：

  1. class Student: —— 声明「我要定义一类叫 Student 的东西」，后面缩进的都归它管。
  2. def __init__(self, name, age): —— 初始化方法（init 前后各两个下划线）。创建对象时会自动执行，用来把初始数据装进去。
  3. self.name = name —— 把传进来的值，存到这个对象自己身上，名字叫 name。

创建对象不用 new，直接写「类名(参数)」就行：

Python
12345678
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

s = Student('小明', 18)
print(s.name)
print(s.age)

输出：

输出
12
小明
18

注意 Student('小明', 18) 只传了两个参数，但 __init__ 明明收了三个——因为第一个 self 由 Python 自动填上，不需要你手动传。

写法含义
class Student:定义类
def __init__(self, ...)创建对象时自动调用的初始化方法
self.name = name把值存到这个对象的属性上
Student('小明', 18)按类造一个对象（会自动调用 __init__）
s.name读取对象的属性
一个类里可以有很多方法，但 __init__ 只有一个，它负责「一造出来就有哪些属性」。如果某个属性人人都有，就写在 __init__ 里；用的时候再给的，可以不写。

三、实例属性与方法（self 到底是什么）

对象的属性（数据）和方法（行为）是绑在一起的。方法就是写在类里的函数，第一个参数固定是 self。

Python
123456789101112
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def say_hello(self):
        print('大家好，我是', self.name)

    def level(self):
        if self.score >= 90:
            return '优秀'
        return '及格'

self 就是「当前正在操作的这个对象」。在方法里想拿到自己的数据，一律写 self.属性名：

Python
12345678910111213141516171819
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def say_hello(self):
        print('大家好，我是', self.name)

    def level(self):
        if self.score >= 90:
            return '优秀'
        return '及格'

a = Student('小明', 92)
b = Student('小红', 76)
a.say_hello()
b.say_hello()
print(a.name, '的等级：', a.level())
print(b.name, '的等级：', b.level())

输出：

输出
1234
大家好，我是 小明
大家好，我是 小红
小明 的等级： 优秀
小红 的等级： 及格

同一个类造出的两个对象，各存各的数据、互不干扰：a.name 是「小明」，b.name 是「小红」。方法里的 self 会分别指向调用它的那个对象。

顺序写法说明
①self.属性 = 值给对象存一个属性
②self.属性读取对象自己的属性
③self.方法()调用对象自己的另一个方法
④对象.属性 / 对象.方法()在类外面用「点」访问
在类外面访问属性和方法都用「点」：a.name、a.say_hello()。方法后面的括号别忘——写 a.say_hello 只是拿到函数本身，不会执行。

四、类属性 vs 实例属性（最容易踩的坑）

属性其实分两种，位置不一样，含义也不一样：

  • 实例属性：写在 __init__ 里，self.xxx = ...。每个对象各有一份。
  • 类属性：直接写在类里面、方法外面。所有对象共享同一份。
Python
12345678910
class Dog:
    species = '犬科'        # 类属性：所有狗共享

    def __init__(self, name):
        self.name = name    # 实例属性：每只狗自己的

a = Dog('旺财')
b = Dog('小黑')
print(a.name, b.name)
print(a.species, b.species)

输出：

输出
12
旺财 小黑
犬科 犬科

类属性适合放「这类东西共同的、基本不变的值」，比如所有狗的物种都是犬科。但下面这个坑一定要避开：

Python
1234567891011
class Team:
    members = []            # 类属性：一个列表，所有对象共享！

    def add(self, name):
        self.members.append(name)

t1 = Team()
t2 = Team()
t1.add('小明')
print('t1:', t1.members)
print('t2:', t2.members)   # t2 也多了人！

输出：

Python
12
t1: ['小明']
t2: ['小明']

t1 加的人，t2 也「看到了」，因为它们共用同一个列表。正确做法是把列表放到 __init__ 里，让每个对象各有一个：

Python
123456789101112
class Team:
    def __init__(self):
        self.members = []   # 实例属性：每个对象各一个

    def add(self, name):
        self.members.append(name)

t1 = Team()
t2 = Team()
t1.add('小明')
print('t1:', t1.members)
print('t2:', t2.members)

输出：

Python
12
t1: ['小明']
t2: []
类属性实例属性
写在哪类里、方法外__init__ 里用 self.
属于谁整个类共享一份每个对象各一份
适合放共同常量，如 species = '犬科'每个对象不同的数据
可变对象（列表/字典）危险，会被所有对象共享安全，各用各的
拿不准放哪儿时，一律放实例属性（写进 __init__）。类属性只在「所有对象都一样的固定值」时才用。

五、封装：_ 与 __ 两种「私有」约定

封装的意思是：把不想让外面随便碰的数据藏起来，只留几个「正规入口」给外面用。Python 没有强制的访问控制，靠的是两条约定。

单下划线 _name：内部使用，请勿乱碰

一个下划线开头，是给同行的「暗号」：这是内部用的，别在外面直接改。它只是约定，实际仍能访问。

双下划线 __name：改个名藏起来

两个下划线开头的属性，Python 会自动把它改名（叫名称改写），外面用原来的名字就找不到了：

Python
123456
class Account:
    def __init__(self, balance):
        self.__balance = balance

a = Account(100)
print(a.__balance)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'Account' object has no attribute '__balance'

想读余额，就由类自己提供一个方法当正规入口，顺便还能做检查：

Python
123456789101112131415161718
class Account:
    def __init__(self, balance):
        self.__balance = balance

    def get_balance(self):
        return self.__balance

    def save(self, amount):
        if amount <= 0:
            print('金额必须大于 0')
            return
        self.__balance += amount

a = Account(100)
a.save(50)
print('余额：', a.get_balance())
a.save(-30)
print('余额：', a.get_balance())

输出：

输出
123
余额： 150
金额必须大于 0
余额： 150
写法含义外面能直接访问吗
name公开属性，随便用能
_name内部用（约定）能，但不建议
__name改名藏起来（名称改写）不能（换名字了）
__name__两边都有下划线的是系统预留能，但别自己造
注意：__name（两个下划线开头、末尾没有下划线）才会被改名。像 __init__ 这种前后都有下划线的，是 Python 自己的特殊方法，不会改名，也不要自己乱起这种名字。

六、继承：子类白拿父类的功能

继承让一个类可以「站在另一个类的肩膀上」：把公共的部分写在父类里，子类自动就有，只需再补上自己特有的部分。写法是在类名后面的括号里写上父类名。

Python
12345678910
class Animal:              # 父类
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(self.name, '在吃东西')

class Dog(Animal):         # 子类：括号里写父类
    def bark(self):
        print(self.name, '汪汪叫')

Dog 只写了 bark，但没有写 __init__ 和 eat——它们都从 Animal 继承过来了：

Python
1234567891011121314
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(self.name, '在吃东西')

class Dog(Animal):
    def bark(self):
        print(self.name, '汪汪叫')

d = Dog('旺财')
d.eat()
d.bark()

输出：

输出
12
旺财 在吃东西
旺财 汪汪叫

父类 / 基类Animal被继承的那一个
子类 / 派生类Dog继承别人的那一个
isinstance(对象, 类)isinstance(d, Animal)判断对象属不属于某个类（含父类）
issubclass(子, 父)issubclass(Dog, Animal)判断类之间的继承关系
Python

        self.name = name

    pass

继承的收益是「公共代码只写一遍」。如果两个类有一批一模一样的属性和方法，就该把公共部分提出来当父类。别为了继承而继承——没有共同点的两个类硬拉成父子，只会更乱。

七、方法重写与 super()

父类的方法，子类如果想要不一样的版本，可以重写：在子类里定义一个同名方法，用的时候就会用子类这一版。

Python
123456789101112131415
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(self.name, '发出了声音')

class Cat(Animal):
    def speak(self):          # 重写父类的 speak
        print(self.name, '喵喵叫')

a = Animal('某种动物')
a.speak()
c = Cat('小白')
c.speak()

输出：

输出
12
某种动物 发出了声音
小白 喵喵叫

重写往往还要「在父类的基础上加点东西」，这时用 super() 调用父类的版本。最常见的是子类有自己的初始化，但公共部分仍交给父类做：

Python
1234567891011121314
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 先把 name 交给父类存好
        self.breed = breed       # 再存子类特有的

    def show(self):
        print(self.name, '是一只', self.breed)

d = Dog('旺财', '金毛')
d.show()

输出：

输出
1
旺财 是一只 金毛

如果子类定义了 __init__ 却忘了调用 super().__init__(...)，父类该存的属性就不会被创建，后面一用就报错：

Python
12345678910
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        self.breed = breed

d = Dog('旺财', '金毛')
print(d.name)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'Dog' object has no attribute 'name'
想做什么写法
完全换成新版本子类里定义同名方法即可
在父类版本上「加点料」方法里先调 super().方法名(...)，再写自己的
子类有 __init__第一行就 super().__init__(...)
口诀：「子类有自己的 __init__，第一句先 super().__init__(...)」。把父类该做的事让它自己做，子类只补自己的部分。

八、多态：同一句调用，不同表现

多态这个词听着唬人，其实就是一句话：同一句代码，作用在不同对象上，会各自做出不同的反应。

比如写一个 make_sound(animal)，里面只写 animal.speak()。传给狗就汪汪，传给猫就喵喵——函数本身一个字都不用改：

Python
1234567891011121314151617
class Dog:
    def speak(self):
        print('汪汪！')

class Cat:
    def speak(self):
        print('喵喵～')

class Duck:
    def speak(self):
        print('嘎嘎')

def make_sound(animal):
    animal.speak()

for a in [Dog(), Cat(), Duck()]:
    make_sound(a)

输出：

输出
123
汪汪！
喵喵～
嘎嘎

多态的好处是「加新类型不用改老代码」。明天再来一个 Pig，只要它也有 speak()，就能直接塞进上面的循环里，make_sound 一个字都不用动。

同一个父类的多态

Python
123456789101112131415161718192021
class Shape:
    def area(self):
        return 0

class Rect(Shape):
    def __init__(self, w, h):
        self.w = w
        self.h = h

    def area(self):
        return self.w * self.h

class Circle(Shape):
    def __init__(self, r):
        self.r = r

    def area(self):
        return round(3.14 * self.r * self.r, 2)

for s in [Rect(3, 4), Circle(2)]:
    print('面积：', s.area())

输出：

输出
12
面积： 12
面积： 12.56
概念一句话本例中的体现
封装数据和方法打包，内部细节藏起来self.w、area() 写在一个类里
继承子类复用父类的功能Rect(Shape) 白拿 Shape 的东西
多态同一句调用，不同对象不同表现循环里同一句 s.area()，矩形和圆算出不同的值
「三大特性」其实是一件事的三个方面：封装把东西装进类里，继承让类之间能复用，多态让上层代码不用关心具体是哪种对象。懂了这一条，面向对象就算学明白了。

九、常用魔术方法（__str__ / __len__ / __eq__…）

以 __ 开头、__ 结尾的方法叫魔术方法（也叫特殊方法）。你不用直接调用它们，它们是给 Python 的「暗号」——只要你写了，某些内置操作就会自动用上。

最常见的 __init__ 我们已经见过（创建对象时自动调用）。再看几个：

Python
1234567891011
class Book:
    def __init__(self, title, price):
        self.title = title
        self.price = price

    def __str__(self):
        return '《' + self.title + '》 ￥' + str(self.price)

b = Book('Python入门', 39)
print(b)              # 会自动调用 __str__
print(str(b))         # 一样的效果

输出：

输出
12
《Python入门》 ￥39
《Python入门》 ￥39

没写 __str__ 时，print(b) 会打出一串看不懂的地址。写了之后，打印就变成人话了。

再来两个最实用的：__len__ 让对象能 len()，__eq__ 让对象能用 == 比较「内容是否相等」。

Python
1234567891011121314
class Playlist:
    def __init__(self, songs):
        self.songs = songs

    def __len__(self):
        return len(self.songs)

    def __eq__(self, other):
        return self.songs == other.songs

p1 = Playlist(['a', 'b', 'c'])
p2 = Playlist(['a', 'b', 'c'])
print('歌单长度：', len(p1))
print('内容相同吗：', p1 == p2)

输出：

输出
12
歌单长度： 3
内容相同吗： True

如果不写 __eq__，两个对象默认比的是「是不是同一个对象」，p1 == p2 会是 False，哪怕内容一模一样。

魔术方法什么时候自动触发例子
__init__创建对象时Student('小明', 18)
__str__print() / str() 时print(b)
__len__len() 时len(p1)
__eq__用 == 比较时p1 == p2
__lt__用 < 比较时s1 < s2
新手只需先掌握 __init__ 和 __str__ 这两个就够了。写 __str__ 一定要 return 一个字符串，写成 print(...) 会打出 None。

十、@property 与 staticmethod / classmethod

最后认识三个「装饰器」写法，它们能让类的用法更顺。

@property：把方法当属性用

有些「属性」其实是算出来的，比如长方形的面积。用 @property 装饰后，调用时不用写括号，看起来就像在读一个属性：

Python
1234567891011
class Rect:
    def __init__(self, w, h):
        self.w = w
        self.h = h

    @property
    def area(self):
        return self.w * self.h

r = Rect(3, 4)
print(r.area)      # 注意：没有括号

输出：

输出
1
12

@staticmethod：不需要对象的工具方法

有些方法只是「顺手借个地方放」，和具体对象无关（不碰 self），可以标成静态方法，照样用「类名.方法()」调用：

Python
1234567
class MathTool:
    @staticmethod
    def is_even(n):
        return n % 2 == 0

print(MathTool.is_even(4))
print(MathTool.is_even(7))

输出：

输出
12
True
False

@classmethod：第一个参数是类本身

类方法的第一个参数是 cls（代表类本身），常用来写「换一种方式创建对象」的辅助方法：

Python
123456789101112
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    @classmethod
    def from_string(cls, text):
        name, age = text.split('-')
        return cls(name, int(age))

s = Student.from_string('小明-18')
print(s.name, s.age)

输出：

输出
1
小明 18
写法第一个参数怎么用典型场景
普通方法self对象.方法()操作这个对象的属性
@staticmethod没有类名.方法()与对象无关的小工具

十二、常见坑

坑 1：方法忘了写 self

方法定义时第一个参数必须是 self，调用时又不用你传。如果定义时漏了，调用时 Python 会把你传的东西当成多余参数：

Python
123456

    def bark():
        print('汪汪')

d.bark()

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: Dog.bark() takes 0 positional arguments but 1 was given

坑 2：访问了没创建的属性

属性只有在被赋值之后才存在。忘了在 __init__ 里初始化，一用就报错：

Python
123456

    def __init__(self, name):
        self.name = name

print(s.score)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'Student' object has no attribute 'score'

坑 3：把可变对象写成类属性

类属性是所有对象共享的。如果它是个列表，一个对象改了，全部对象都跟着变（见第四节）。列表、字典这类会变的东西，一律放进 __init__。

    box = []            # 错：大家共用这一个

        pass

坑 4：忘了调用 super().__init__()

子类定义了自己的 __init__，却忘了先让父类初始化，父类那些属性就不存在（见第七节）。

s.show 只是「拿到这个方法」，不会执行；要执行得写 s.show()。忘了括号时不会报错，只是什么都没发生——最容易查半天。

1下面关于「类」和「对象」的说法，正确的是？

  • A. 类是模具／图纸，对象是用它造出来的具体东西
  • B. 类是造出来的东西，对象是图纸
  • C. 类和对象是同义词
  • D. 一个类只能造一个对象
答案：A。类是「模具」，描述这类东西有什么数据、能做什么；对象是用模具造出来的「一块」，可以造很多个，每个的数据还能不同。

2class Student: 里 __init__ 方法的作用是？

  • A. 给类起名字
  • B. 创建对象时自动执行，用来装初始数据
  • C. 删除对象
  • D. 把类变成函数
答案：B。__init__ 是初始化方法，写 Student('小明', 18) 创建对象时会被自动调用，用来把初始数据存到 self 上。

3在类的方法里，self 指的是？

  • A. 类本身
  • B. 一个必须手写的参数名，可以随便省略
  • C. 当前正在操作的这个对象
  • D. Python 的保留字，不能改
答案：C。self 就是「当前这个对象」。调用方法时 Python 自动填上，不用你手动传；但定义方法时第一个参数一定要写。

4下面哪种情况会「一个对象改了、其他对象也跟着变」？

  • A. 属性写在 __init__ 里
  • B. 方法里用了 self
  • C. 用 @property 装饰方法
  • D. 把一个空列表写成类属性，然后往里面 append
答案：D。类属性是所有对象共享一份的。列表、字典这种会变的对象写成类属性，一个对象改了其他的都受影响。要各用各的，就放进 __init__。

5子类 Dog(Animal) 里没有定义 eat 方法，写 Dog('旺财').eat() 会怎样？

  • A. 自动去调用父类 Animal 的 eat
  • B. 报错，子类没有这个方法
  • C. 返回 None
  • D. 自动创建一个空方法
答案：A。子类会继承父类的方法，没被重写就能直接用。这正是继承省代码的地方——公共方法只在父类写一遍。

6子类定义了自己的 __init__，想让父类也完成初始化，应该怎么做？

  • A. 什么都不用做，Python 自动调用
  • B. 第一行写 super().__init__(...)
  • C. 把父类的 __init__ 复制过来
  • D. 写 self.__init__(...)
答案：B。子类一旦自己写了 __init__，父类的就不会自动执行了，要显式调用 super().__init__(...)。忘了写，父类该有的属性就不存在，后面一用就报 AttributeError。

7同一句 animal.speak()，传给狗输出「汪汪」、传给猫输出「喵喵」，这体现了哪个特性？

  • A. 封装
  • B. 继承
  • C. 多态
  • D. 重载
答案：C。这就是多态：同一句调用，作用在不同对象上各自做出不同反应。写代码的人不用关心具体是哪种动物，只管调 speak()。

8print(对象) 想打出好看的内容，应该给类写哪个方法？

  • A. __init__
  • B. __del__
  • C. __name__
  • D. __str__
答案：D。写 __str__ 并 return 一个字符串，print(对象) 就会打印它。一定要 return，不能写成 print，否则会打出 None。

9下面哪种写法能让 r.area 不带括号就能算出面积？
