Python 切片操作：一行取出序列的一段

一、切片是什么（取一段）

切片（slice）就是从一个序列里「切下一段」。比如有一串水果，你只想拿前三个，不用一个个写，用切片一句话搞定：

Python
123
fruits = ['apple', 'banana', 'cherry', 'date', 'elderberry']
first_three = fruits[0:3]
print(first_three)

输出：

输出
1
['apple', 'banana', 'cherry']

切片不只用于列表，字符串、元组一样能用。它最大的好处是：不用循环、不用数下标，一行就把「第几个到第几个」取出来。

你熟悉的写法切片写法
一个个赋值取前三个fruits[0:3]
循环打印字符串前 5 个字符word[:5]
把列表倒过来lst[::-1]
切片取出来的是一份新的序列，不会改原来的数据。后面「常见坑」一节会专门讲这一点。

二、三步写法 [起点:终点:步长]（含头不含尾）

切片用方括号，里面最多写三项，用冒号隔开：

输出
1
序列[起点:终点:步长]

三项分别是什么

位置名字默认值含义
第 1 项起点0（开头）从哪个下标开始取（包含）
第 2 项终点末尾取到哪个下标之前（不包含）
第 3 项步长1每次跳几格；正数往前、负数往后

最重要的规则：含头不含尾

fruits[0:3] 表示从下标 0 开始，取到下标 3 之前——也就是取下标 0、1、2，不取 3。

Python
12
nums = [10, 20, 30, 40, 50]
print(nums[1:4])

输出：

输出
1
[20, 30, 40]

下标 1 是 20、2 是 30、3 是 40，但终点 4 不含，所以取到 40 就停。取下标 1、2、3 三个元素。

「终点不包含」是切片最容易出错的地方。想取到第 n 个，终点就要写 n+1。比如取前 3 个写 [:3]，取前 5 个写 [:5]。
口诀：起点要，终点不要。写 [a:b] 心里默念「从 a 取到 b 前面一个」。

三、四种最常用写法

把三项省略成几种最常用的组合，记住这四种就够用了：

写法含义例子（对 [0,1,2,3,4,5]）
[:]从头到尾全部得到 [0,1,2,3,4,5]
[a:b]从 a 取到 b 前[1:4] → [1,2,3]
[:b]从头取到 b 前[:3] → [0,1,2]
[a:]从 a 取到末尾[3:] → [3,4,5]

挨个跑一遍

Python
12345
lst = [0, 1, 2, 3, 4, 5]
print(lst[:])
print(lst[1:4])
print(lst[:3])
print(lst[3:])

输出：

输出
1234
[0, 1, 2, 3, 4, 5]
[1, 2, 3]
[0, 1, 2]
[3, 4, 5]
省略起点代表「从头」、省略终点代表「到尾」。[:] 常用来复制一整个列表（拿到的是新的一份）。

四、负数下标

下标除了从 0 从左往右数，还能用负数从右往左数：-1 是最后一个，-2 是倒数第二个……

Python
123
animals = ['dog', 'cat', 'bird', 'fish', 'rabbit']
print(animals[-1])
print(animals[-2:])

输出：

输出
12
rabbit
['fish', 'rabbit']

animals[-2:] 表示从倒数第二个开始，取到末尾——正好是最后两个。

写法取到什么
[-1]最后一个元素
[-3:]最后三个元素
[:-1]除最后一个以外的全部
[-3:-1]倒数第三到倒数第二（不含最后一个）
Python
12
s = 'abcdef'
print(s[-4:-1])

输出：

输出
1
cde
负数下标不用去算「长度减几」，直接「从右边数第几个」就行，特别适合「拿最后几个」的场景。

五、步长（[::2]、[::-1] 反转）

第三项是步长：每隔几格取一个。写成 序列[起点:终点:步长]。

① 每隔一个取（步长 2）

Python
12
nums = [1, 2, 3, 4, 5, 6, 7, 8, 9]
print(nums[::2])

输出：

输出
1
[1, 3, 5, 7, 9]

② 反转序列（步长 -1）

Python
12
letters = ['a', 'b', 'c', 'd', 'e']
print(letters[::-1])

输出：

输出
1
['e', 'd', 'c', 'b', 'a']

③ 倒着每隔一个取（步长 -2）

Python
12
alphabets = ('a', 'b', 'c', 'd', 'e', 'f', 'g')
print(alphabets[::-2])

输出：

输出
1
('g', 'e', 'c', 'a')
步长效果
2每隔一个取，正着走
3每三个取一个
-1整个反转
-2反转后每隔一个取
步长为 0 是不允许的，会直接报错（详见「报错手册」）。想反转就写 -1，别写成 0。
记住 [::-1] 这个写法：它是 Python 里反转序列最常用的一招，字符串、列表、元组通吃。

六、超出范围不报错（和索引越界对比）

切片一个很友好的特点是：下标超出范围也不会报错，它会自动截到序列末尾。

Python
12
lst = [1, 2, 3]
print(lst[1:10])    # 终点 10 远超长度，只取到末尾

输出：

输出
1
[2, 3]

这和「单个下标」完全不同

写法结果
lst[1:10]（切片）不报错，返回 [2, 3]
lst[5]（单个下标）报错 IndexError

单个下标访问越界会崩，但切片越界只是「能拿多少拿多少」。这是因为切片本来就是为了「安全地取一段」。

Python
12
lst = [1, 2, 3]
print(lst[5])        # 下标 5 不存在
报错
1
IndexError: list index out of range
所以当你「不确定数据有多长、只想拿前面一段」时，切片比单个下标安全得多：data[:100] 即使不足 100 个也不会错。

七、字符串/列表/元组都通用（返回同类型）

切片的写法在字符串、列表、元组上完全一样，而且返回的类型和原来一致：字符串切片还是字符串，元组切片还是元组。

Python
123
# 字符串切片，结果仍是字符串
word = 'programming'
print(word[:3])

输出：

输出
1
pro

元组的例子（返回还是元组）

Python
12
numbers = (1, 2, 3, 4, 5, 6, 7)
print(numbers[2:5])

输出：

输出
1
(3, 4, 5)

字符串取中间一段

Python
12
long_string = 'abcdefghijklmnopqrstuvwxyz'
print(long_string[6:12])

输出：

输出
1
ghijkl
原类型切片结果类型例子
列表列表lst[1:3] → 列表
字符串字符串s[1:3] → 字符串
元组元组t[1:3] → 元组
「返回同类型」很关键：对字符串切片得到的是子串（还能继续当字符串用），对元组切片得到的是新元组（不能改，但能读）。

八、切片不改原对象，重新赋值才改（lst[1:3] = [...]）

用切片读取一段，原来的序列不会变，得到的是一份新的：

Python
12345
a = [1, 2, 3]
b = a[1:3]        # 切出一段
b[0] = 99         # 改 b
print('a =', a)
print('b =', b)

输出：

Python
12
a = [1, 2, 3]
b = [2, 3]

改了 b，a 纹丝不动。说明切片返回的是新的副本。

想改原列表，要「重新赋值」

Python
123
lst = [1, 2, 3, 4, 5]
lst[1:3] = [9, 9, 9]    # 用切片当「位置」做替换
print(lst)

输出：

输出
1
[1, 9, 9, 9, 4, 5]

这里把下标 1、2 两个位置，换成了三个新元素，所以列表反而变长了。注意：这是「赋值给切片」，和「读切片」是两回事。

区分两种写法：b = a[1:3] 是「读」，原列表不变；a[1:3] = [...] 是「写」，会改原列表。少写一个等号，意思差很多。
想复制整个列表用 new = old[:]。比起 new = old（两个变量指向同一个列表），[:] 才是一份真正独立的副本。

十、常见坑（步长 0、负数步长方向、浅复制）

坑 1：步长写成 0

Python
12
nums = [1, 2, 3]
print(nums[::0])
报错
1
ValueError: slice step cannot be zero

步长不能是 0（每跳 0 格永远停在原地，没意义）。想反转用 -1。

坑 2：负数步长的方向搞反

用负数步长时，起点要比终点大，否则什么都取不到：

Python
12
s = 'hello'
print(s[3:0:-1])     # 从 3 往回走到 1

输出：

输出
1
lle

s[3:0:-1]：从下标 3 开始，往回走（步长 -1），到下标 0 之前停，所以取 3、2、1，得到 'lle'。如果写成 s[0:3:-1] 反而取不到东西，因为起点 0 比终点 3 小、却又用负步长往回走，矛盾了。

坑 3：以为切片改了原对象

Python
1234
a = [1, 2, 3]
b = a[:]
b[0] = 99
print(a)        # a 没变

输出：

输出
1
[1, 2, 3]

用 a[:] 复制后改副本，原列表不受影响。只有 a[1:3] = ...（把切片写在等号左边）才会改原列表。

坑 4：切片是「浅」复制

Python
1234
a = [[1, 2], [3, 4]]
b = a[:]          # 复制外层列表
b[0][0] = 99      # 改内层列表的元素
print(a)

输出：

输出
1
[[99, 2], [3, 4]]

切片只复制了外层，里面嵌套的列表还是同一份。改了 b[0] 里的内容，a 也跟着变。嵌套结构要小心这点。

最容易混的是：lst[1:3]（读，返回新列表）和 lst[1:3] = [...]（写，改原列表）。写代码时盯一下等号在不在切片左边。

十一、报错手册

切片相关的报错不多，下面都是真跑出来的原文。

① 步长为 0

Python
12
nums = [1, 2, 3]
print(nums[::0])
报错
1
ValueError: slice step cannot be zero

原因：步长不能是 0。想反转用 -1，想隔一个用 2。

② 单个下标越界（注意：切片越界不报这个）

Python
12
lst = [1, 2, 3]
print(lst[5])
报错
1
IndexError: list index out of range

原因：用单个下标访问不存在的位置会崩。如果只想「尽量取一段」，用切片 lst[3:100] 就不会错。

③ 对象不支持切片

Python
12
n = 10
print(n[1:3])
报错
1
TypeError: 'int' object is not subscriptable

原因：只有序列（字符串/列表/元组等）才能切片，单个数字 10 不行。

④ 下标或步长不是整数

Python
12
lst = [1, 2, 3]
print(lst[1:3.0])
报错
1
TypeError: slice indices must be integers or None or have an __index__ method

原因：切片的起点、终点、步长都必须是整数，3.0 这种浮点数不行（哪怕它的值等于 3）。

1[1,2,3,4,5][1:4] 取到的是哪些下标对应的元素？

  • A. 下标 0、1、2
  • B. 下标 1、2、3
  • C. 下标 1、2、3、4
  • D. 下标 2、3、4
答案：B。切片含头不含尾：起点 1 取、终点 4 不取，所以取下标 1、2、3 三个元素，结果是 [2,3,4]。

2[10,20,30,40,50][2:5] 的结果是什么？

  • A. [20,30]
  • B. [20,30,40,50]
  • C. [30,40,50]
  • D. [40,50]
答案：C。起点 2（值 30）取，终点 5（不存在，视为末尾）不取，取到 30、40、50，结果 [30,40,50]。

3lst[:] 表示取什么？

  • A. 从头到尾整个序列
  • B. 一个空序列
  • C. 只有最后一个元素
  • D. 会报错
答案：A。省略起点和终点就是「从头到尾」。lst[:] 常用来复制整个列表，得到一份独立的新副本。

4nums[::2] 里的步长 2 是什么意思？

  • A. 只取前两个元素
  • B. 倒着取一遍
  • C. 每隔一个取一个
  • D. 只取第一个元素
答案：C。步长为 2 表示「每跳两格取一个」，对 [1,2,3,4,5] 会得到 [1,3,5]。想反转要写负步长 -1。

5想把列表 lst 反转，最常用的是？

  • A. lst[::2]
  • B. lst[::-1]
  • C. lst[-1::]
  • D. lst[:0:-1]
答案：B。[::-1] 是 Python 反转序列的标准写法：步长 -1 从尾走到头，字符串、列表、元组都能用。

6想取列表 lst 的最后两个元素，正确的是？

  • A. lst[:2]
  • B. lst[-2::]
  • C. lst[:-2]
  • D. lst[-2:]
答案：D。lst[-2:] 表示从倒数第二个取到末尾，正好是两个；[:-2] 反而是「除最后两个外全部」。

7切片时终点下标超出了序列长度，会发生什么？

  • A. 不报错，自动截到末尾
  • B. 报 IndexError
  • C. 返回 None
  • D. 只取到倒数第二个
答案：A。切片越界很友好，能拿多少拿多少、不会报错；但单个下标越界（如 lst[5]）才会报 IndexError。

8用单个下标访问 lst[5]，但列表只有 3 个元素，会怎样？

  • A. 返回 None
  • B. 返回最后一个元素
  • C. 不报错返回空
  • D. 报 IndexError
答案：D。单个下标访问不存在的位置会报 IndexError: list index out of range；想安全取一段要用切片 lst[3:100]。

9写 nums[::0]（步长为 0）会怎样？

  • A. 返回一个空列表
  • B. 报 ValueError: slice step cannot be zero
  • C. 返回原序列
  • D. 报 SyntaxError
答案：B。步长不能是 0（每跳 0 格没有意义），会报 ValueError。反转请写 -1，隔一个取写 2。

10用切片读取 b = a[1:3] 之后，再改 b，原列表 a 会怎样？

  • A. 也会被改
  • B. 报错
  • C. 不会被改，返回的是新对象
  • D. 两个都变成空
答案：C。读切片返回的是新的副本，改 b 不影响 a。只有把切片写在等号左边（a[1:3] = ...）才会改原列表。
