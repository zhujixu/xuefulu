Python 元组：写下来就不许改

一、什么是元组（写下来就不许改）

元组（tuple）和列表长得像，也是用一串方括号……不对，是圆括号把多个值装起来。但它有个铁规矩：一旦创建，里面的内容就不能改。

打个比方：列表像个水果篮，随时能往里加苹果、拿走香蕉；元组像一份固定套餐，下单之后菜就定死了，不能临时换。

Python
123
t = (1, 2, 3, 4, 5)
print(t)
print('长度是', len(t))

输出：

输出
12
(1, 2, 3, 4, 5)
长度是 5

表面看它和列表差不多，但「不可改」这个特性，让它在很多场合比列表更合适（后面第十节「元组的常见用途」会讲）。

记住一句话：元组是「写下来就不许改」的列表。当你有一组固定不变的数据（比如一年中 12 个月、RGB 三个颜色分量），就该用元组。

二、创建元组的四种方式

方式一：圆括号直接写

Python
12

print(t)

输出：

输出
1
(1, 2, 3)

方式二：单个元素——逗号不能少！

只写一个元素时，必须加逗号，否则会被当成普通括号里的表达式：

Python
1234

输出：

输出

b 的类型: <class 'tuple'>

(1) 只是给数字 1 套了层没用的括号，结果还是整数；(1,) 才是只有一个元素的元组。

方式三：用 tuple() 把别的序列转成元组

Python
12
t = tuple([4, 5, 6])
print(t)

输出：

输出
1
(4, 5, 6)

方式四：连括号都不写也行

用逗号隔开的一串值，Python 会自动当成元组：

Python
123
t = 1, 2, 3
print(t)
print('类型:', type(t))

输出：

输出
12
(1, 2, 3)
类型: <class 'tuple'>
写法结果说明
(1, 2, 3)元组最常用，圆括号
(1,)只有一个元素的元组逗号不能省
tuple([4,5,6])元组把列表等转成元组
1, 2, 3元组不写括号也行，逗号决定它是元组
单元素元组最容易写错：想表达「只有一个元素的元组」，一定要写 (1,)。漏掉逗号，(1) 只是整数 1，不是元组——后面传到需要元组的地方就会报错。
怎么确认一个东西是不是元组？用 type() 看一眼最稳妥：type((1,)) 得到 tuple，type((1)) 得到 int。

三、用索引和切片访问元素

元组和列表一样，靠索引取值，从 0 开始；负数从右边数。

Python
1234
t = (10, 20, 30)
print(t[0])
print(t[-1])
print(t[1])

输出：

输出
123
10
30
20

切片：一次拿一段

[起点:终点] 同样是含起点、不含终点：

Python
123
t = (10, 20, 30, 40, 50)
print(t[1:4])
print(t[::-1])

输出：

输出
12
(20, 30, 40)
(50, 40, 30, 20, 10)

t[::-1] 里的步长写 -1，表示「倒着、每隔一个取」，于是把整个元组反转过来。

元组的索引、切片写法和列表完全一样。如果你已经会了列表的访问，元组这部分的操作直接照搬就行。

Python

六、元组和列表的相同点

在「读取」这件事上，元组和列表几乎是一家人。下面这些操作两者都支持：

相同的能力例子效果
按索引取值t[0]拿第 1 个
负索引t[-1]拿最后一个
切片t[1:3]拿一段
求长度len(t)有几个元素
用 for 遍历for x in t逐个取出
用 in 判断在不在2 in t返回 True / False
Python
123
t = (1, 2, 3)
print(2 in t)
print(len(t))

输出：

输出
12
True
3

所以：凡是只看不改的场景，元组能完全替代列表。

判断该用元组还是列表，就看「这个数据创建后会不会变」。会变→列表；固定不变→元组。读取操作两者通用，不用纠结。

七、元组和列表的不同点（可变性 / 括号 / 性能 / 能不能当字典键）

真正的差别在「能不能改」以及由此带来的一些后果：

对比项列表 list元组 tuple
符号方括号 []圆括号 ()
能不能改元素能（append / 改 / 删）不能，改了就报错
性能稍慢一点稍快、占内存更少
能不能当字典的键不能（可变，不可哈希）能（不可变，可哈希）
典型用途一变再变的数据固定不变的数据
Python
1234
t = (1, 2, 3)
lst = [1, 2, 3]
print('元组能当字典键:', {t: 'ok'})
print('列表不能当字典键（下面会报错）')

输出：

输出
12
元组能当字典键: {(1, 2, 3): 'ok'}
列表不能当字典键（下面会报错）

关于「能不能当字典的键」：字典的键要求不可变，元组满足，列表不满足（列表那条会报错，见报错手册）。

性能那点差距对咱们的小练习可以忽略不计，真正影响选择的是「语义」：用元组=明摆着告诉读代码的人「这串数据不会变」，更安全、更好懂。

八、元组改不了，但可以「重造」（+ 拼接、* 重复、list 转换）

元组不能直接改，但你可以基于旧的，造一个新的。就像套餐换不了菜，但可以「照原套餐再加个甜点」点一份新的。

用 + 拼出新元组

Python
1234
t = (1, 2, 3)
t2 = t + (4,)
print(t2)
print('原来的 t 没变:', t)

输出：

输出
12
(1, 2, 3, 4)
原来的 t 没变: (1, 2, 3)

注意 (4,) 那个逗号——右边必须是元组，单元素元组逗号不能省。+ 产生的是新元组，原来的 t 一动没动。

用 * 重复

Python
12
t = (1, 2)
print(t * 3)

输出：

输出
1
(1, 2, 1, 2, 1, 2)

先转成列表改，再转回元组

如果真要改很多，可以先 list() 变列表、改完、再 tuple() 变回元组：

Python
12345
t = (1, 2, 3)
lst = list(t)
lst.append(4)
t = tuple(lst)
print(t)

输出：

输出
1
(1, 2, 3, 4)
+ 和 * 都不会改动原元组，而是返回一个新元组。如果想「更新」t，记得把结果重新赋值给 t（像上面 t = t + (4,)）。
元组「不可变」指的是：它的元素引用不能换。但后面会看到——如果某个元素本身是可变的（比如列表），那个元素里面的内容还是可以动的。

九、元组推导式？其实并没有

列表有列表推导式，字典有字典推导式，集合也有集合推导式……你可能会想：那元组有没有「元组推导式」？

答案是——没有。如果你写成圆括号的推导式，得到的并不是元组，而是一个生成器：

Python
123
g = (x * x for x in range(1, 4))
print(type(g))
print(tuple(g))

输出：

输出
12
<class 'generator'>
(1, 4, 9)

看类型就明白了：打出来是 generator，不是 tuple。生成器是一种「用到才算」的东西，能被 for 遍历，但它本身不是一个元组。

想造元组：外面套一层 tuple()

Python
123
print(tuple(x * x for x in range(1, 6)))
print(tuple([x * x for x in range(1, 6)]))
print(tuple('abc'))

输出：

输出
123
(1, 4, 9, 16, 25)
(1, 4, 9, 16, 25)
('a', 'b', 'c')

上面三种写法都能得到元组：第一种是「生成器 + tuple()」，第二种是「列表推导式 + tuple()」，第三种是把字符串转成元组。

推导式写法得到什么
[x for x in ...]列表 list
{x for x in ...}集合 set
{k: v for ...}字典 dict
(x for x in ...)生成器，不是元组！
tuple(x for x in ...)元组 tuple
这是本节的要点：圆括号的推导式得到的是生成器，不是元组。看到 (x for x in ...) 千万别以为造出了元组——它连 len() 都用不了。
一句话记：想要元组，就 tuple(...) 包一层；只想「边算边用、不占内存」，那就直接用生成器。

十二、常见坑（含「元组里的列表可以改」）

坑 1：单元素元组忘了逗号

Python
12
a = (1)
print('a 其实是', type(a))

输出：

输出
1
a 其实是 <class 'int'>

想写只有一个元素的元组，必须 (1,)，少了逗号就成了普通的整数。

坑 2：元组不能改，但「里面的列表」可以改

元组自己不可变，但如果某个元素是个列表，那个列表内部还能动：

Python
123
t = (1, [2, 3])
t[1].append(4)
print(t)

输出：

输出
1
(1, [2, 3, 4])

这是因为元组锁住的是「第 1 个元素是个列表」这件事，并没锁住那个列表里面的内容。所以别误以为元组里的一切都动不了。

坑 3：想用 append 往元组加东西

元组没有 append，写了会报 AttributeError（见报错手册）。要加东西，用 + 拼出新元组。

坑 4：以为 + 会改原元组

Python
123
t = (1, 2, 3)
t + (4,)
print('t 原样没变:', t)

输出：

输出
1
t 原样没变: (1, 2, 3)

t + (4,) 算出了一个新元组，但没赋值回 t，所以 t 还是老样子。要更新就写 t = t + (4,)。

坑 2 是最反直觉的：元组「不可变」只针对「直接装在里面的引用」。元素本身若是可变对象（列表、字典、集合），它们的内容照样能改。分不清时，记住「锁的是位置，不是内容」。
想往元组里加数据又必须保持元组形态？先 list() 转列表 → 增删改 → 再 tuple() 转回。这是处理「需要改但又想用元组」的标准流程。

十三、报错手册

下面这些报错都是本机真实运行出来的，照抄解释器原文。

运行后会报错（逐字照抄解释器）：

报错
1

原因：同样因为不可变，连删除都不行。

用 append：AttributeError

Python
12
t = (1, 2, 3)
t.append(4)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'tuple' object has no attribute 'append'

原因：元组没有 append 这个方法（那是列表的）。要加元素用 t + (4,)。

索引越界：IndexError

Python
12
t = (1, 2, 3)
print(t[10])

运行后会报错（逐字照抄解释器）：

报错
1
IndexError: tuple index out of range

原因：元组只有 3 个元素（索引 0~2），取第 10 个超出范围。

把非可迭代对象转元组：TypeError

Python
1
print(tuple(5))

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: 'int' object is not iterable

原因：tuple() 需要一个能一个一个取出来的东西（列表、字符串等）。数字 5 不是，会报「int 对象不可迭代」。

列表当字典键：TypeError

Python
1
d = {[1, 2]: 'a'}

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: unhashable type: 'list'

原因：字典的键必须不可变（可哈希）。列表是可变的，不能当键；换成元组 {(1, 2): 'a'} 就正常。

元组相关的报错几乎都围绕「不可变」：object does not support item assignment（不能改）、has no attribute 'append'（没这方法）、unhashable type: 'list'（列表不能当键）。看到这类词，先想「是不是动了不该动的东西」。

  • C. 用 for 遍历
  • D. 用 t[0] = 1 改第一个元素
答案：D。元组创建后不能改，t[0] = 1 会报 'tuple' object does not support item assignment。读取、切片、遍历都是只读操作，不会报错。

4t = (1, [2, 3]) 执行 t[1].append(4) 后，t 变成？

  • A. (1, [2, 3])
  • B. (1, [2, 3, 4])
  • C. 报错
  • D. (1, 2, 3, 4)
答案：B。元组本身不可变，但第 1 个元素是个列表，列表内部能改。所以 t[1].append(4) 把那个列表变成了 [2,3,4]，总体是 (1, [2, 3, 4])。

5t = (1, 2, 3)，想把它倒过来得到 (3, 2, 1)，该用？

  • A. t.sort()
  • B. t.reverse()
  • C. t[::-1]
  • D. sorted(t)
答案：C。切片步长写 -1 即 t[::-1]，直接得到反转的元组。元组没有 sort/reverse 方法；sorted(t) 返回的是列表不是元组。

6t = (1, 2, 3)，执行 t2 = t + (4,) 之后，原来的 t 是？

  • A. (1, 2, 3, 4)
  • B. (1, 2, 3)
  • C. None
  • D. 报错
答案：B。+ 不会改原元组，而是造出一个新元组 (1,2,3,4) 赋给 t2；t 原样不变，仍是 (1, 2, 3)。

7tuple([1, 2, 3]) 的结果是？

  • A. [1, 2, 3]
  • B. {1, 2, 3}
  • C. (1, 2, 3)
  • D. 报错
答案：C。tuple() 把列表转成元组，结果是 (1, 2, 3)。反过来 list() 能把元组转回列表。

8函数 def f(): return 1, 2，调用 f() 得到的返回值类型是什么？

  • A. int
  • B. list
  • C. tuple
  • D. str
答案：C。Python 里函数「返回多个值」本质上是返回一个元组 (1, 2)。所以拿到后可以用 a, b = f() 一次性接住。

9要遍历元组 t 里的每个元素，正确的写法是？

  • A. for x in t:
  • B. for x in range(t):
  • C. while t:
  • D. 元组不能遍历
答案：A。元组和列表一样能用 for 元素 in 元组 遍历。range() 只收整数，不能写 range(t)。

10t = (1, 2, 3)，想把它变成列表再修改，正确做法是？

  • A. t.append(4)
  • B. t[0] = 4
  • C. t.clear()
  • D. list(t) 然后改列表
答案：D。元组没有 append、不能下标赋值、也没有 clear。正确姿势是 lst = list(t) 转成列表改完，再 tuple(lst) 转回。

11元组 t = (5, 8, 5, 2)，那么 t.count(5) 的结果是？

  • A. 2
  • B. 0
  • C. 1
  • D. 3
答案：A。count(x) 数元素 x 出现了几次。5 在下标 0 和 2 各一次，所以是 2。想找位置用 t.index(5)，返回第一次出现的下标 0。

12(x * x for x in range(3)) 得到的是什么？

  • A. 一个元组 (0, 1, 4)
  • B. 一个列表 [0, 1, 4]
  • C. 一个集合 {0, 1, 4}
  • D. 一个生成器（不是元组）
答案：D。Python 没有「元组推导式」。圆括号的推导式得到的是生成器，类型是 generator。要元组就写 tuple(x * x for x in range(3))。
