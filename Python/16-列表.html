一、为什么需要列表

前面学的变量，一次只能装一个值：一个分数、一个名字。但真实世界里，数据常常是一串的。

比如一个宿舍 5 个人的数学分数。最笨的写法，是起 5 个变量：

Python
12345

s2 = 92
s3 = 75
s4 = 96
s5 = 81

分数一多，变量就多到管不过来。更好的办法：用一个列表，把这一串数装进一个名字里。

Python
12
scores = [88, 92, 75, 96, 81]
print(scores)

输出：

输出
1
[88, 92, 75, 96, 81]

一个变量 scores，就装下了 5 个分数。这种「一个变量装一串数」的容器，就是列表。

Python

print('一共', len(scores), '个分数')
print('最高分', max(scores))

输出：

输出
12
一共 5 个分数
最高分 96

列表里每个位置上的数，叫一个元素。元素可以是数字、文字，甚至混着放。

列表是 Python 里最常用的容器。以后你会反复用到它：成绩表、商品清单、逐行读文件……只要东西是一串的，就先想到列表。

二、列表是「序列」家庭的一员

在正式学列表之前，先认识一个更大的概念：序列（sequence）。字符串、列表、元组、range 都属于序列——它们的共同点是：元素排成一队，每个都有自己的位置（下标），可以从 0 开始按位置取。

序列成员例子能不能改
字符串 str'abc'不能改
列表 list[1, 2, 3]能改
元组 tuple(1, 2, 3)不能改
rangerange(5)不能改

正因为是「一家人」，下面这些操作对它们全都管用（只是结果类型不同）：

操作写法说明

判断在不在x in s返回 True / False
拼接s1 + s2接成一个更长的
重复s * 3重复 3 遍

你会看到，字符串上能做的这些事，换成列表也一样能做——因为它们都是序列。这一节学一次，四类东西都能用。

把「序列」当成一个大家庭：凡是「排成一队、能按下标取」的都算序列。本篇讲列表（能改的那个），下一篇《17-元组》讲元组（不能改的那个）。

五、往列表里加东西（append / extend / insert）

列表最棒的一点：它能长大。三个加法各有分工。

append：在末尾加「一个」元素

Python
123
fruits = ['apple', 'banana']
fruits.append('cherry')
print(fruits)

输出：

输出
1
['apple', 'banana', 'cherry']

extend：把另一个列表的每个元素都加进来

Python
1234
list1 = [1, 2, 3]
list2 = [4, 5, 6]
list1.extend(list2)
print(list1)

输出：

输出
1
[1, 2, 3, 4, 5, 6]

insert：插到指定位置

insert(位置, 元素)，新元素会占住这个位置，后面的往后挪：

Python
123
numbers = [1, 2, 4]
numbers.insert(2, 3)
print(numbers)

输出：

输出
1
[1, 2, 3, 4]
方法做了什么例子结果
append(x)在末尾加一个元素 x[1,2].append(3) → [1,2,3]
extend([x,y])把 x、y 一个个加进末尾[1].extend([2,3]) → [1,2,3]
insert(i,x)插到索引 i 的位置[1,2,4].insert(2,3) → [1,2,3,4]
append 和 extend 容易混。append([4,5,6]) 是把「整个列表」当一个元素塞进去，结果变成 [1,2,3,[4,5,6]]；想平铺着加，要用 extend。
如果只是往末尾加，用 append 就够了，它最简单也最常用。insert 要搬动后面所有元素，元素很多时会慢一点。

八、排序与反转（sort 与 sorted 的区别、sort 返回 None）

把列表排个序，是日常高频操作。这里有个大坑必须先说。

sort：原地排序，不返回新列表

Python
123
nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums.sort()
print(nums)

输出：

输出
1
[1, 1, 2, 3, 4, 5, 6, 9]

坑：sort() 返回的是 None

很多人写 sorted_nums = nums.sort()，以为拿到了排好序的列表，其实拿到的是 None：

Python
123
nums = [3, 1, 2]
result = nums.sort()
print(result)

输出：

输出
1
None

sort() 是直接把原来的 nums 改掉了（原地排序），它自己不返回任何东西。想要「排好序的新列表又不动原列表」，用 sorted()：

Python
1234
nums = [3, 1, 4]
new_nums = sorted(nums)
print(new_nums)
print(nums)

输出：

输出
12
[1, 3, 4]
[3, 1, 4]

降序与反转

Python
123
nums = [3, 1, 4, 1, 5, 9, 2, 6]
nums.sort(reverse=True)
print(nums)

输出：

输出
1
[9, 6, 5, 4, 3, 2, 1, 1]

reverse() 是把顺序整个倒过来，跟大小无关：

Python
123
nums = [1, 2, 3, 4, 5]
nums.reverse()
print(nums)

输出：

输出
1
[5, 4, 3, 2, 1]
写法动不动原列表返回什么典型用途
nums.sort()动（原地改）None就想把原列表排好
sorted(nums)不动新列表要留着原列表，另存一份排好序的
nums.reverse()动None把顺序倒过来
一句话记住：带括号 sorted() 是函数，会把结果还给你一个新列表；sort() 是方法，直接把原列表改掉，自己什么都不还（返回 None）。

列表推导式：一行生成列表

这是 Python 很爽的写法：用一行，按规则「变」出一个列表。先看三个例子体会一下：

Python
12

输出：

输出
1
1~10 平方: [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

意思是：让 i 从 1 走到 10，把每个 i**2 收进列表。

Python
123

输出：

输出
1

这次多了 if i % 2 == 0：只收偶数。

Python
123

输出：

输出
1

推导式一开始可能绕，先把它读成中文：「对这串东西里的每一个，算出表达式的值，满足条件就收进新列表」。不用强求一步到位，用 for 循环也能做，熟练了再换推导式。

十一、多维列表（列表里装列表）

列表的元素可以是任何东西——包括另一个列表。当每个元素本身也是列表时，就成了多维列表（也叫嵌套列表、二维列表）。它最适合表示一张「表格」：一行一个学生，一列一项数据。

Python
12345
students = [
    ['小明', 92, 88],
    ['小红', 76, 95],
    ['小刚', 85, 79],
]

怎么读它？先把它看成「3 个元素」，每个元素本身又是一个列表。要取到具体的数，就从左到右一层层往里钻：

Python
1234
students = [['小明', 92, 88], ['小红', 76, 95], ['小刚', 85, 79]]
print(students[0])        # 第 1 行（整行）
print(students[0][0])     # 第 1 行第 1 列
print(students[1][2])     # 第 2 行第 3 列

输出：

输出
123
['小明', 92, 88]
小明
95

students[0] 是整行（一个列表），students[0][0] 才是格子里那个值。两个中括号，前一个选行、后一个选列。

别把 students[0][0] 写成 students[0, 0]——普通列表不支持这种写法，会报 TypeError。

用双层 for 遍历

Python
12345
students = [['小明', 92, 88], ['小红', 76, 95]]
for row in students:        # 外层：一行一行拿
    for value in row:       # 内层：把这行的每一格拿出来
        print(value, end=' ')
    print()

输出：

输出
12
小明 92 88 
小红 76 95

常见用法：按行算总分

Python
12345
students = [['小明', 92, 88], ['小红', 76, 95], ['小刚', 85, 79]]
for row in students:
    name = row[0]
    total = sum(row[1:])     # 从第 2 列开始求和
    print(name, '总分', total)

输出：

输出
123
小明 总分 180
小红 总分 171
小刚 总分 164

矩阵：一个 3×3 的数字方阵

Python
1234567
m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9],
]

输出：

坑：[[0] * 3] * 3 造出来的三行其实是「同一行」

Python
123
bad = [[0] * 3] * 3
bad[0][0] = 9
print(bad)          # 三行一起变了！

输出：

输出
1
[[9, 0, 0], [9, 0, 0], [9, 0, 0]]

原因：[X] * 3 是把同一个 X（同一个列表对象）重复了三遍，三个位置指向的是同一行。正确写法是用推导式，让每行都新建一个：

Python
123
good = [[0] * 3 for _ in range(3)]
good[0][0] = 9
print(good)         # 只有第 1 行变

输出：

输出
1
[[9, 0, 0], [0, 0, 0], [0, 0, 0]]
查二维列表时，脑子里默念「先选行、再选列」：m[行][列]。看到 list[i][j] 就读成「第 i 行的第 j 个」。

十二、迭代器：for 背后到底发生了什么

你早就习惯了写 for x in 列表:。但 for 到底怎么把元素一个个拿出来的？答案是：列表先「生产」出一个迭代器，for 每次从迭代器里取一个，取完为止。

手动取：iter() 与 next()

Python
12345
nums = [10, 20, 30]
it = iter(nums)        # 把列表变成迭代器

for 循环内部其实就在做这件事：不停地 next()，一旦收到 StopIteration 就安静地结束——所以平时你根本看不到这个异常。

可迭代对象 vs 迭代器

可迭代对象（Iterable）迭代器（Iterator）
特征能被 for 遍历既能被 for 遍历，也能 next()
必备方法__iter____iter__ 和 __next__
能不能反复用能（每次都重新开一个迭代器）不能，取完就废
例子列表、字符串、字典、集合、rangeiter([1, 2, 3]) 的结果

一句话：列表是「可迭代对象」，但它本身不是「迭代器」。要被 iter() 包装一下，才得到真正的迭代器。

平时写代码根本不用手动 iter() / next()，直接 for 就行。这一节只是为了让你知道 for 的背后是什么——第 24 篇《生成器与迭代器》会顺着这套机制继续往下讲。

十四、常见坑

坑 1：两个变量指向同一个列表（别名陷阱）

写 b = a 并不是复制，而是让 b 和 a 指向同一个列表。改了 b，a 也跟着变：

Python
1234

b.append(4)

想要一份独立的副本，用 copy()：

Python

a = [1, 2, 3]
b = a.copy()
b.append(4)
print('a 没变:', a)
print('b 是副本:', b)

输出：

输出
12
a 没变: [1, 2, 3]
b 是副本: [1, 2, 3, 4]
