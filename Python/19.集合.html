Python 集合：不重复的一袋东西

一、为什么需要集合

列表能装一串东西、能重复、按位置找；字典能按名字找值。但有一类需求这两个都不顺手：「这里面的东西不能重复」和「某某在不在里面」。

比如一份报名名单，同一个名字被填了两遍，要数一数到底有几个人报名：

Python
123
names = ['小明', '小红', '小明', '小刚', '小红']
print('名单条数:', len(names))
print('实际人数:', len(set(names)))

输出：

输出
12
名单条数: 5
实际人数: 3

用 set() 一包，重复的自动就没了。这就是集合：一袋不许重复的东西，它的长项是「去重」和「判断在不在」，而不是「排第几」。

容器一句话最擅长
列表 []一队有顺序的人按位置取、要顺序、允许重复
元组 ()刻在石头上的名单内容不许改
字典 {}一本词典按名字（键）查值
集合 set()一袋不许重复的东西去重、判断在不在、做交并差
记住一句话就行：要顺序用列表，要对应关系用字典，要去重和「有没有」用集合。

二、创建集合的四种方式

方式一：花括号里直接写

和字典一样用花括号，但里面只有元素、没有冒号。

Python
123
fruits = {'apple', 'banana', 'cherry'}
print(len(fruits))
print('apple' in fruits)

输出：

输出
12
3
True

方式二：用 set() 把别的序列变过来（顺手去重）

Python
12
print(set([1, 2, 2, 3, 3, 3]))
print(sorted(set('hello')))

输出：

输出
12
{1, 2, 3}
['e', 'h', 'l', 'o']

set() 能吃掉列表、字符串、元组、range 等任何「能一个个数出来」的东西。字符串会被拆成一个一个字符。

方式三：空集合只能写 set()

这是集合最大的一个坑：{} 是空字典，不是空集合。

Python
12
s = {}
s.add(1)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'dict' object has no attribute 'add'

括号里什么都没有时，Python 默认建的是字典。想要空集合，必须写 set()：

Python
1234
s = set()
s.add(1)
print(s)
print(type(s))

输出：

输出
12
{1}
<class 'set'>

方式四：集合推导式（先看个样子）

Python
1
print({x * x for x in range(1, 6)})

输出：

输出
1
{1, 4, 9, 16, 25}

写法像列表推导式，只是外面换成花括号。它天生就会去重，第八节细讲。

写法结果备注
{1, 2, 3}含 3 个元素的集合最常用
set([1, 2, 2]){1, 2}从别的序列转过来，顺手去重
set()空集合只能用这一种！
{}空字典别搞错
{x for x in range(3)}{0, 1, 2}集合推导式
最常见的新手错误：想建空集合写了 {}。它是个空字典，后面一调用集合的方法（比如 add）就报 AttributeError: 'dict' object has no attribute 'add'。请记牢：空集合写 set()。

三、集合的三条规矩（不重复、无序、元素不可变）

规矩 1：不重复，重复的自动被吃掉

Python
123
s = {1, 2, 2, 3, 3, 3}
print(s)
print(len(s))

输出：

输出
12
{1, 2, 3}
3

规矩 2：无序——不能用下标，也不能切片

集合不记「谁排第几」，所以 s[0] 这种写法直接报错。

Python
12
s = {1, 2, 3}
print(s[0])

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: 'set' object is not subscriptable

两个后果要记住：

  1. 想「按顺序取第几个」，请改用列表。
  2. print(s) 出来的顺序不保证和你写进去的顺序一样（元素越多、越不是小数字，越容易看出来）。想让输出每次都固定，先 sorted()。
Python
123
s = {3, 1, 2}
print(sorted(s))
print(sorted(s, reverse=True))

输出：

输出
12
[1, 2, 3]
[3, 2, 1]

顺带记一句：集合比的是「内容一样不一样」，跟顺序无关。

Python
1
print({1, 2, 3} == {3, 2, 1})

输出：

输出
1
True

规矩 3：元素必须「不可变」

集合内部要靠一个「位置」来快速找到元素，所以元素必须是算得出固定位置的东西（术语叫「可哈希」）。列表和字典会变，放不进去。

Python
1
s = {[1, 2], 3}

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: unhashable type: 'list'

能放的：数字、字符串、True/False、元组（前提是元组里装的也都是不可变的）。

Python
12
s = {(1, 2), (3, 4)}
print(sorted(s))

输出：

输出
1
[(1, 2), (3, 4)]
元素类型能不能放进集合为什么
数字 10能不可变
字符串 'abc'能不可变
元组 (1, 2)能（里面也得都是不可变的）元组本身不可变
列表 [1, 2]不能会变，报 unhashable
字典 {'a': 1}不能会变
集合 {1, 2}不能普通集合会变（frozenset 才行）

四、往里加、往外删（add / update / remove / discard / pop / clear）

集合的增删方法不多，记住下面六张「面孔」就够了。

方法作用要不要给值
s.add(x)加一个元素给
s.update(序列)一次加一批给
s.remove(x)删掉 x，没有就报错给
s.discard(x)删掉 x，没有也不报错给
s.pop()随便删掉一个并返回它不给
s.clear()全部清空不给

add：加一个（重复加等于没加）

Python
12345
s = {1, 2, 3}
s.add(4)
print(sorted(s))
s.add(4)          # 已经有了，加了也白加
print(len(s))     # 还是 4 个

输出：

输出
12
[1, 2, 3, 4]
4

注意 add() 自己不返回值，别写 s = s.add(4)——那样 s 会变成 None。

update：一次加一批

Python
123
s = {1, 2}
s.update([3, 4, 4, 5])
print(sorted(s))

输出：

输出
1
[1, 2, 3, 4, 5]

remove 和 discard：删一个

差别只有一个：删不存在的元素时，remove 报错，discard 当没事发生。

Python
12
s = {1, 2, 3}
s.remove(99)

运行后会报错（逐字照抄解释器）：

报错
1
KeyError: 99

不确定在不在，就用 discard；确定在、想让它报错帮你查问题，就用 remove。

Python
1234
s = {1, 2, 3}
s.discard(99)     # 没有，也不报错
s.remove(1)       # 有，正常删掉
print(sorted(s))

输出：

输出
1
[2, 3]

pop：随便删掉一个（不能指定删谁）

Python
123
s = {10, 20, 30}
print(s.pop())
print(sorted(s))

输出：

输出
12
10
[20, 30]

因为集合无序，「第一个」没有意义，所以 pop() 删的是随便哪个，只适合「我随便拿一个出来处理」的场景。

clear：清空

Python
1234
s = {1, 2, 3}
s.clear()
print(s)
print(bool(s))    # 空集合在判断里算「假」

输出：

Python
12
set()
False

六、四个集合运算（交集 &、并集 |、差集 -、对称差 ^）

集合最漂亮的用法，是「拿两个集合比一比」。四个符号，对应四种关系：

符号名字含义生活里的样子
&交集两边都有的两个班都报名的同学
|并集两边合起来全部（自动去重）两个班加起来的所有人
-差集在左边、不在右边的只在 A 班、没去 B 班的人
^对称差只出现在一边的（去掉共同部分）只在一个班出现过的人
Python
1234567
a = {1, 2, 3}
b = {2, 3, 4}
print('交集:', a & b)
print('并集:', a | b)
print('差集 a-b:', a - b)
print('差集 b-a:', b - a)
print('对称差:', a ^ b)

输出：

输出
12345
交集: {2, 3}
并集: {1, 2, 3, 4}
差集 a-b: {1}
差集 b-a: {4}
对称差: {1, 4}
差集有方向！a - b 是「在 a 里但不在 b 里」，b - a 正好相反。写的时候先在心里念一遍「谁减谁」。

换成人名，就是一道很常见的题：

Python
123456
class_a = {'小明', '小红', '小刚'}
class_b = {'小红', '小刚', '小美'}
print('两个班都有的:', sorted(class_a & class_b))
print('两个班全部的人:', sorted(class_a | class_b))
print('只在 A 班的:', sorted(class_a - class_b))
print('只在一个班的:', sorted(class_a ^ class_b))

输出：

输出
1234
两个班都有的: ['小刚', '小红']
两个班全部的人: ['小刚', '小明', '小红', '小美']
只在 A 班的: ['小明']
只在一个班的: ['小明', '小美']
中文用 sorted() 排出来是按字符编码排的，不是按拼音，所以顺序看着可能有点怪，这不是错。

七、方法版（intersection / union / difference / issubset…）

同样四件事，换成方法写

四个运算符都有一个同名的方法：

Python
12345
a = {1, 2, 3}
print(a.intersection([2, 3, 4]))
print(a.union([4]))
print(a.difference([2]))
print(a.symmetric_difference([3, 4]))

输出：

输出
1234
{2, 3}
{1, 2, 3, 4}
{1, 3}
{1, 2, 4}

结果是 {2, 3}、{1, 2, 3, 4}、{1, 3}、{1, 2, 4}，和用符号一模一样。

运算符号写法方法写法
交集a & ba.intersection(b)
并集a | ba.union(b)
差集a - ba.difference(b)
对称差a ^ ba.symmetric_difference(b)
两者有个关键区别：符号两边必须都是集合，方法可以吃列表。{1, 2, 3} & [2, 3] 会报 TypeError，而 {1, 2, 3}.intersection([2, 3]) 是好的。数据本来就在列表里、又不想先转成集合时，用方法更省事。
Python
1
print({1, 2, 3} & [2, 3])

运行后会报错（逐字照抄解释器）：

报错
1
TypeError: unsupported operand type(s) for &: 'set' and 'list'

三个判断题

这三个返回的都是 True / False，用来问「集合之间是什么关系」。

Python
1234
a = {1, 2}
print(a.issubset({1, 2, 3}))      # a 是它的子集吗（a 全在里面）
print({1, 2, 3}.issuperset(a))    # 它把 a 全包含了吗
print(a.isdisjoint({4, 5}))       # 两边完全没有重复吗

输出：

输出
123
True
True
True

子集也能用比较符号写，但这里有个大坑：

Python
12
print({1, 2} <= {1, 2, 3})    # True：是子集
print({1, 2} < {1, 2})       # False：小于等于成立，但不「小于」

输出：

输出
12
True
False
集合里的 <= 不是「小于等于」，是「子集」；< 是「真子集」（少一个才算）。看到集合比较大小别想成数字，{1, 2} < {1, 2} 是 False 而不是 True，正是这个道理。

八、集合推导式

和列表推导式长得几乎一样，只是把方括号换成花括号。得到的结果是一个集合，所以天生去重。

Python
12
print({x * x for x in range(1, 6)})
print(sorted({x for x in range(10) if x % 3 == 0}))

输出：

输出
12
{1, 4, 9, 16, 25}
[0, 3, 6, 9]

把「每个元素的第一个字母」收集起来，重复的自动只留一个：

Python
12
words = ['apple', 'banana', 'avocado']
print(sorted({w[0] for w in words}))

输出：

输出
1
['a', 'b']
集合是无序的，字符串集合打印出来的顺序每次运行都可能不一样，所以这里先 sorted() 排一下。自己调试时看到顺序变了，不是程序出错。
推导式 + 集合 = 一句话完成「挑出来 + 去重」。比如 {n % 10 for n in nums} 就是「所有数字的个位数有哪几种」。

九、frozenset：不可变的集合

集合本身是可以改的，所以集合不能放进集合，也不能当字典的键。要这个能力，就用 frozenset——冻结版集合，建好之后一个都改不了。

Python
1234
fs = frozenset([1, 2, 3])
print(fs)
print(len(fs), 2 in fs)
print(sorted(fs))

输出：

Python
123
frozenset({1, 2, 3})
3 True
[1, 2, 3]

想改它？方法和列表一样，直接没有：

Python
12
fs = frozenset([1, 2])
fs.add(3)

运行后会报错（逐字照抄解释器）：

报错
1
AttributeError: 'frozenset' object has no attribute 'add'

换来的好处是：它能当字典的键，也能被放进别的集合里。

Python
1234
d = {frozenset([1, 2]): '一对'}
print(d[frozenset([1, 2])])
s = {frozenset([1]), frozenset([2])}
print(len(s))

输出：

输出
12
一对
2

四个运算它全都能用（因为不需要改动自己）：

Python
1
print(sorted(frozenset([1, 2, 3]) & {2, 3, 4}))

输出：

输出
1
[2, 3]

十、类型转换：四种容器怎么互转

到这儿，四种组合数据类型——列表、元组、字典、集合——就都学完了。实际写代码时经常要在它们之间来回转，靠的就是几个同名的转换函数。

函数把一个东西变成例子
list(x)列表list('abc') → ['a', 'b', 'c']
tuple(x)元组tuple([1, 2]) → (1, 2)
set(x)集合（顺手去重）set([1, 1, 2]) → {1, 2}
dict(x)字典（元素要是键值对）dict([('a', 1)]) → {'a': 1}
str(x)字符串str(123) → '123'

列表 / 元组 / 集合：三者随便转

Python
1234
lst = [3, 1, 2, 1]
print(set(lst))        # 去重
print(tuple(lst))
print(list(set(lst)))  # 去过重的列表

输出：

输出
123
{1, 2, 3}
(3, 1, 2, 1)
[1, 2, 3]

注意 list(set(...)) 出来后的顺序不保证——集合本身是无序的。要固定顺序，先 sorted() 一下：

Python
12
lst = [3, 1, 2, 1]
print(sorted(set(lst)))

输出：

输出
1
[1, 2, 3]

1想把一个列表里重复的元素去掉，最省事的一行是？

  • A. nums = list(set(nums))
  • B. nums = set(nums) + []
  • C. nums.remove(nums)
  • D. nums = sorted(nums)
答案：A。先用 set() 把重复的吃掉，再用 list() 转回列表。B 那行会报错（集合不能加列表），D 只是排序，重复的还在。

2下面哪一行创建的是一个空集合？

  • A. s = {}
  • B. s = []
  • C. s = set()
  • D. s = ()
答案：C。空集合只能用 set()。{} 是空字典（最容易踩的坑），[] 是空列表，() 是空元组。

3s = {1, 2, 3}，执行 print(s[0]) 会发生什么？

  • A. 输出 1
  • B. 报 TypeError: 'set' object is not subscriptable
  • C. 输出 {1}
  • D. 输出 None
答案：B。集合无序，没有「第 0 个」，所以不能用下标。要按下标取，先转成列表 list(s)。

4下面哪个不能放进集合？

  • A. 数字 10
  • B. 字符串 'abc'
  • C. 元组 (1, 2)
  • D. 列表 [1, 2]
答案：D。集合的元素必须不可变（可哈希）。列表会变，塞进去会报 TypeError: unhashable type: 'list'；想放一组数就用元组。

5s = {1, 2, 3}，想删掉 4、而且「没有这个元素时也不报错」，该用哪个？

  • D. s.delete(4)
