Python 内置函数：七类常用函数一次讲清

一、内置函数是什么

前面几篇里，我们已经用过好几个「拿来就用」的东西了：print() 负责输出、input() 负责收数据、len() 负责数长度、type() 负责看类型。它们有一个共同的名字——内置函数。

「内置」两个字的意思很直白：Python 装好就自带，不用导入、不用定义，写出来就能用。就像手机里预装的相机和计算器，开机就在那儿，不用自己装。

1.1 内置函数长什么样

用起来只有一个套路：函数名（要处理的东西）。

Python
123
print("你好")        # 把 "你好" 交给 print，它负责显示出来
len([1, 2, 3])       # 把列表交给 len，它负责数出有几个
abs(-5)              # 把 -5 交给 abs，它负责变成正的

可以这样理解：你把东西递给一个工具，工具把处理好的结果还给你。括号里的东西叫「参数」，还回来的东西叫「返回值」。

1.2 它和别处的函数有什么不一样

称呼怎么来的要不要先准备例子
内置函数Python 自带不用，装好就有len() max() sorted()
模块里的函数别的文件里写好的要先 import 进来math.sqrt()（先 import math）
自己写的函数你自己 def 出来的要先定义第 22 篇《函数》里讲

第 5 篇《语法规范》里讲过一个容易混的点：print、input、len 这些 不是关键字，而是内置函数。关键字是语法里的零件（不能拿来当变量名），内置函数是现成的工具（名字可以被你覆盖，但强烈不建议）。

1.3 怎么自己查一个函数

  1. 看说明书：写 help(函数名)，会把官方说明打印出来（英文的）。例：help(abs)。
  2. 看某类东西都会干什么：写 dir(类型)。例：dir(str) 能列出一大串名字，第 10 篇讲过的 upper()、isalpha() 都在里面。
  3. 翻官方文档：搜「Python built-in functions」，第一条就是。
Python 3 的内置名字有一百多个，但这里面包含了 int、str、bool 这些类型和 True、False 这类常量。真正算「函数」的有几十个，新手要熟练的就是本篇这三十来个，不用全背。

二、数学运算类（7 个）

这一类最直观：给你一个数或一串数，帮你算出另一个数。

函数干什么例子结果
abs(x)求绝对值（去掉负号）abs(-5)5
max(...)求最大值max([1, 3, 5, 2])5
min(...)求最小值min([4, 2, 7, 1])1
sum(x)把一串数字加起来sum([1, 2, 3, 4])10
pow(x, y)x 的 y 次方pow(2, 3)8
round(x)四舍五入round(2.7)3
divmod(x, y)一次拿到商和余数divmod(10, 3)(3, 1)

2.1 abs()：把负号去掉

Python
123
print(abs(-5))       # 5
print(abs(3.14))     # 3.14
print(abs(-0.25))    # 0.25

常用在「不管正负，我只看差多少」的场合，比如比较两个数相差多大。

2.2 max() 和 min()：两种用法都行

它们既能收一串东西，也能收好几个单独的参数——这是新手最容易迷糊的一点。

Python
1234567891011
# 用法一：括号里放一个「一串东西」
print(max([1, 3, 5, 2]))     # 5
print(min((4, 2, 7, 1)))     # 1

# 用法二：括号里放好几个单独的值
print(max(10, 20, 5))        # 20
print(min(8, 3, 6))          # 3

# 字符串也能比，按「字典顺序」一个字符一个字符比
print(max("abc", "abd", "abe"))   # abe
print(min("xyz", "xy", "xya"))    # xy   （短的更小）

如果要比的不是数值本身，而是「按什么标准比」，可以加 key=：

Python
1234
words = ["apple", "hi", "banana"]
print(max(words))            # banana  （字母顺序最后）
print(max(words, key=len))   # banana  （按长度比，最长的是它）
print(min(words, key=len))   # hi      （最短的是它）

2.3 sum()：一串数字求和

Python
123
print(sum([1, 2, 3, 4]))       # 10
print(sum((5, 6, 7)))          # 18
print(sum([1, 2, 3], 10))      # 16   （第二个参数是「起点」，从 10 开始加）
sum() 只能加数字。sum([1, "2"]) 会报 TypeError，因为数字和文字不能相加（第 7 篇《运算符》里讲过的老问题）。
另外，较新的 Python 3 版本 里，sum() 对小数求和做了精度优化：sum([0.1, 0.2, 0.3]) 会得到干净的 0.6，而手写 0.1 + 0.2 + 0.3 会得到 0.6000000000000001（第 8 篇讲过的浮点精度问题）。

2.4 pow()：次方，还能顺带取余

Python
123
print(pow(2, 3))        # 8     2 的 3 次方
print(pow(3, 2))        # 9     3 的 2 次方
print(pow(2, 3, 5))     # 3     2³ = 8，8 除以 5 余 3（第三个参数是「再对谁取余」）

平时算次方直接写 2 ** 3 更方便；pow() 的长处是带上第三个参数时，能一次性算出「次方再取余」，处理很大的数字时很快。

2.5 round()：四舍五入（但有坑）

Python
1234
print(round(3.14159, 2))   # 3.14   第二个参数是「保留几位小数」
print(round(3.14159, 3))   # 3.142
print(round(2.7))          # 3      不写位数就取整
print(round(4.49))         # 4
round() 并不总是你想的那个「四舍五入」。round(2.5) 得到的是 2（不是 3），round(2.675, 2) 得到的是 2.67。原因和正确用法见第九节 9.3。

2.6 divmod()：商和余数一次拿走

Python
123
print(divmod(10, 3))    # (3, 1)   10 除以 3：商 3，余 1
print(divmod(20, 4))    # (5, 0)   正好除尽，余数是 0
print(divmod(7, 2))     # (3, 1)

它是 // 和 % 两个运算符的合体：divmod(10, 3) 等价于 (10 // 3, 10 % 3)。拿到的是个元组，可以一次拆成两个变量：

Python
12
q, r = divmod(17, 5)
print(q, r)             # 3 2

三、类型转换类（8 个）

这一类干的活只有一件：把一种类型变成另一种。第 6 篇里 int(input(...)) 用的就是它。

函数变成什么例子结果
bool(x)真假值bool(0)False
int(x)整数int('10')10
float(x)小数float('3.2')3.2
str(x)字符串str(123)'123'
list(x)列表list('abc')['a', 'b', 'c']
tuple(x)元组tuple([1, 2, 3])(1, 2, 3)
dict(x)字典dict(a=1, b=2){'a': 1, 'b': 2}
set(x)集合（自动去重）set([1, 2, 2, 3]){1, 2, 3}

3.1 三个最常用的：int / float / str

Python
12345678910
print(int(3.14))        # 3      小数变整数是「砍掉小数部分」，不是四舍五入
print(int('10'))        # 10     文字里的数字能变过来
print(int(True))        # 1      真假值也能变，True 就是 1

print(float(5))         # 5.0
print(float('3.2'))     # 3.2
print(float(False))     # 0.0

print(str(123))         # '123'   变回文字
print(str(True))        # 'True'
int(3.14) 是 3，小数部分直接扔掉，不做四舍五入。想四舍五入要另外用 round(3.14)。

3.2 转换的结果要「接住」

转换不会改动原来的变量，它只是算出一个新值还给你。必须用变量接住才有用：

Python
1234567
x = "18"

int(x)              # 算出一个 18，但没人接，马上就被丢掉了
print(x)            # 输出 18（还是字符串，前后都有引号）

y = int(x)          # 这样才对：用 y 接住
print(y + 1)        # 19
判断「接到没接到」的小办法：看等号左边有没有变量。int(x) 单独一行什么也不会发生，写 y = int(x) 才留下结果。

3.3 列表、元组、字典、集合之间也能互相转

Python
123456789
print(list('abc'))                # ['a', 'b', 'c']  字符串拆成单个字符
print(list((1, 2, 3)))            # [1, 2, 3]        元组转列表
print(tuple([1, 2, 3]))           # (1, 2, 3)        列表转元组
print(set([1, 2, 2, 3]))          # {1, 2, 3}        去重
print(sorted(set([3, 1, 3, 2])))  # [1, 2, 3]        去重之后再排序

# 字典要用「键值对」来建
print(dict(a=1, b=2))                                  # {'a': 1, 'b': 2}
print(dict([('name', '张三'), ('age', 18)]))           # {'name': '张三', 'age': 18}

这几个转换在第 8 篇《基本数据类型》里都埋过伏笔，现在你知道它们其实都是内置函数了。

四、序列操作类（5 个）

这一类管的是「一串东西」——字符串、列表、元组、字典都算。数个数、排序、配编号、两两配对，全靠它们。

函数干什么例子结果
len(x)数有多少个元素len('hello')5
sorted(x)排序，返回新列表sorted([3, 1, 4, 2])[1, 2, 3, 4]
reversed(x)倒过来list(reversed([1, 2, 3]))[3, 2, 1]
enumerate(x)每个元素配上序号list(enumerate(['a', 'b']))[(0, 'a'), (1, 'b')]
zip(a, b)两串合成一对一对list(zip([1, 2], ['a', 'b']))[(1, 'a'), (2, 'b')]

4.1 len()：数一数有几个

Python
1234
print(len([1, 2, 3, 4]))        # 4
print(len('hello'))             # 5
print(len('你好世界'))          # 4   中文字也算 1 个
print(len({'a': 1, 'b': 2}))     # 2   字典数的是「有几对键值」

4.2 sorted()：从小到大排

Python
1234
print(sorted([3, 1, 4, 2]))                    # [1, 2, 3, 4]
print(sorted([3, 1, 4, 2], reverse=True))      # [4, 3, 2, 1]  从大到小
print(sorted('dcba'))                          # ['a', 'b', 'c', 'd']
print(sorted((5, 3, 1)))                       # [5, 3, 1] 升序结果是 [1, 3, 5]

还可以用 key= 指定「按什么排」：

Python
123
words = ['banana', 'hi', 'apple']
print(sorted(words, key=len))       # ['hi', 'apple', 'banana']  按长度
print(sorted([-3, 1, 2], key=abs))  # [1, 2, -3]                 按绝对值
sorted() 只是算出一份新的排好序的列表还给你，原来的列表一点没变。要改原来那个列表，得用列表自己的 .sort()——两者的区别见 9.1。

4.3 reversed()：倒过来

Python
12
print(list(reversed([1, 2, 3])))   # [3, 2, 1]
print(list(reversed('abc')))       # ['c', 'b', 'a']
reversed() 还回来的是一个「反向迭代器」，不能直接打印或取下标。想看结果要包一层 list()：print(reversed([1, 2, 3])) 只会显示一串看不懂的地址。

如果只是想把字符串倒过来，第 10 篇里那个切片写法更短：'abc'[::-1]。

4.4 enumerate()：一边拿序号，一边拿元素

遍历列表时想知道「这是第几个」，它最省事。

Python
12345678910111213
names = ['小明', '小红', '小刚']
for i, name in enumerate(names):
    print(i, name)
# 0 小明
# 1 小红
# 2 小刚

# 让编号从 1 开始，加 start=1
for i, name in enumerate(names, start=1):
    print(i, name)
# 1 小明
# 2 小红
# 3 小刚
不写 start 的话序号从 0 开始——这是 Python 的习惯（第 10 篇讲索引时也是从 0 开始的）。给人看的编号一般要写 start=1。

4.5 zip()：像拉链一样合起来

Python
12345678910111213
names = ['小明', '小红', '小刚']
scores = [88, 95, 76]

print(list(zip(names, scores)))
# [('小明', 88), ('小红', 95), ('小刚', 76)]

# 最常见用法：边配对边取
for name, score in zip(names, scores):
    print(name, score)

# 也能一次拉三条
print(list(zip('abc', [1, 2, 3], [True, False, True])))
# [('a', 1, True), ('b', 2, False), ('c', 3, True)]

配上字典，两个列表能立刻变成一张对照表（第 8 篇的字典派上用场了）：

Python
12
print(dict(zip(names, scores)))
# {'小明': 88, '小红': 95, '小刚': 76}
zip() 以最短的那一串为准，多出来的部分直接丢掉：list(zip([1, 2, 3], ['a', 'b'])) 只会得到 [(1, 'a'), (2, 'b')]，那个 3 不见了。

4.6 顺便认识 any() 和 all()

示例里没提，但做判断时很好用，一起收着：

Python
1234
print(any([0, 0, 1]))    # True    只要有「一个」为真就是 True
print(any([0, 0, 0]))    # False   全是假才 False
print(all([1, 1, 0]))    # False   有一个假就是 False

五、高级操作类（4 个）

这一类比前面难一点，看懂了会用就行，不必强求一次记住。它们的共同点是：把「对每个元素做同样的事」这件事，写得比 for 循环更短。

函数干什么例子结果
range(a, b, n)生成一串整数list(range(1, 10, 2))[1, 3, 5, 7, 9]
map(f, x)把每个元素都用 f 处理一遍list(map(len, ['a', 'bb']))[1, 2]
filter(f, x)只留下 f 判为真的元素list(filter(str.isdigit, 'a1b2'))['1', '2']
reduce(f, x)把一串「揉」成一个值reduce(lambda a, b: a + b, [1, 2, 3])6

5.1 range()：生成一串整数

Python
123456
print(list(range(5)))            # [0, 1, 2, 3, 4]
print(list(range(2, 6)))         # [2, 3, 4, 5]
print(list(range(1, 10, 2)))     # [1, 3, 5, 7, 9]  第三个参数是「每次加几」

for i in range(3):
    print(i)                     # 0 1 2
和切片一样：含头不含尾。range(5) 从 0 数到 4，不包括 5；range(2, 6) 不包括 6。

5.2 先认识 lambda：一行的临时小函数

后面三个函数都要「递一个规则进去」，这个规则常写成 lambda。它就是一个没有名字的迷你函数，格式是 lambda 参数: 结果。完整的函数写法在第 22 篇《函数》里讲，这里先做到「看得懂、照着会改」就够了。

Python
1234567
# 这两行效果一样：
def double(x):        # 正常写法：要起名字，要写 return
    return x * 2

double2 = lambda x: x * 2    # lambda 写法：一行搞定，连名字都是临时起的

print(double(3), double2(3))   # 6 6
看 lambda x: x * 2 时，在心里读成「给一个 x，还你 x 乘 2」就好。冒号后面是结果，不用写 return。

5.3 map()：每个元素都过一遍同一个处理

Python
12345678910
nums = [1, 2, 3]

print(list(map(lambda x: x * 2, nums)))    # [2, 4, 6]  每个都乘 2

# 递现成的函数进去也行
print(list(map(str, [1, 2, 3])))           # ['1', '2', '3']  每个都变字符串
print(list(map(len, ['a', 'bb', 'ccc'])))  # [1, 2, 3]        每个都量长度

# 也能同时处理两串（一一对应）
print(list(map(lambda x, y: x + y, [1, 2, 3], [4, 5, 6])))   # [5, 7, 9]

5.4 filter()：只留下符合条件的

前面那支 lambda 要能判断真假：真就留下，假就丢掉。

Python
1234567
nums = [1, 2, 3, 4]
print(list(filter(lambda x: x % 2 == 0, nums)))   # [2, 4]  只留偶数

print(list(filter(str.isdigit, 'a1b2c3')))        # ['1', '2', '3']  只留数字

# 第一个参数写 None，就按「真假」自动筛（第 8 篇《数据类型》里的假值清单）
print(list(filter(None, [0, 1, False, True])))    # [1, True]

5.5 reduce()：把一串揉成一个

它不在内置函数里，要先从 functools 里请出来（这是唯一需要 import 的一个）。

Python
12345
from functools import reduce

print(reduce(lambda a, b: a + b, [1, 2, 3, 4]))    # 10   等于 ((1+2)+3)+4
print(reduce(lambda a, b: a * b, [1, 2, 3]))       # 6    连乘
print(reduce(lambda a, b: a if a > b else b, [5, 3, 7, 2]))   # 7  变相的求最大值
map()、filter()、reversed() 还回来的都不是列表，而是「迭代器」——想看结果就包一层 list()。原因见 9.5。
另外说实话：map 和 filter 能做的事，用 for 循环加 if 也都做得到，而且更好读。先能看懂别人的代码，写的时候挑顺手的就行。

六、字符与编码类（2 个）

这一对函数是「互相反着来」的搭档：一个把字符换成编号，一个把编号换回字符。

函数方向例子结果
chr(n)编号 → 字符chr(65)'A'
ord(s)字符 → 编号ord('A')65

这里的「编号」叫 Unicode 码位，就是全世界每个字符在计算机里对应的一个数字。

Python
123456
print(chr(65))       # A
print(chr(97))       # a
print(chr(26417))    # 朱     中文也有编号
print(ord('A'))      # 65
print(ord('a'))      # 97
print(ord('朱'))      # 26417
记方向的办法：ord 是 order（顺序、序号），把字符变成序号；chr 是 character（字符），把序号变回字符。两个来回转能还原：chr(ord('朱')) 还是 '朱'。

6.1 有什么用

最典型的用法是让字母按编号移动——比如把 'A' 往后挪两位变成 'C'：

Python
12345
print(chr(ord('A') + 2))     # C

# 大小写字母的编号正好差 32
print(ord('a') - ord('A'))   # 32
print(chr(ord('a') - 32))    # A   小写变大写（手写版，实际用 .upper() 更方便）

也能拿来生成一段字母表：

Python
12
letters = [chr(i) for i in range(ord('a'), ord('e') + 1)]
print(letters)               # ['a', 'b', 'c', 'd', 'e']
ord() 一次只能传一个字符。ord('ab') 会报 TypeError: ord() expected a character, but string of length 2 found；想一次转一串，得用 list(map(ord, 'ab'))。

它负责打开一个文件，还给你一个文件对象，后面读还是写都由参数决定。

九、最容易搞混的几组对比

这一节专门收拢「长得像、其实不一样」的几组，都是新手真的会写错的。

9.1 sorted() 和列表的 .sort()

一个是函数，一个是列表自带的方法，行为完全不同：

Python
12345678
L = [3, 1, 2]

print(sorted(L))        # [1, 2, 3]   返回一个全新的列表
print(L)                # [3, 1, 2]   原来的 L 一点没变

result = L.sort()       # 列表自己的方法：原地排序
print(result)           # None        它不返回东西！
print(L)                # [1, 2, 3]   但 L 自己已经被改成有序的了
对比项sorted(L)L.sort()
是谁内置函数列表的方法
要几个参数sorted(L)（列表当参数传进去）L.sort()（点号调用）
返回什么新的排好序的列表None
原列表变没变不变变了
最常见的错误是把 L.sort() 的返回值接住：写成 new = L.sort()，new 会是 None。原地改的方法都不返回结果，别去接它。

9.2 reversed() 和列表的 .reverse()

同样是「函数 vs 方法」的关系，坑法一模一样：

Python
1234567
M = [1, 2, 3]
print(list(reversed(M)))    # [3, 2, 1]   返回新的，M 没动
print(M)                    # [1, 2, 3]

r = M.reverse()             # 原地倒过来
print(r)                    # None
print(M)                    # [3, 2, 1]
记法一句话：带 ed 的是函数（sorted / reversed），返回新的；不带 ed 的是方法（.sort() / .reverse()），原地改、不给回结果。

9.3 round() 的「四舍五入」有时不对

Python
1234
print(round(2.5))        # 2   ← 你以为会是 3
print(round(3.5))        # 4
print(round(0.5))        # 0
print(round(2.675, 2))   # 2.67   ← 你以为会是 2.68

两件事在捣乱：

  1. 「五入」在 Python 里做的是「取最近的偶数」（数学上叫「银行家舍入」）。所以 2.5 变成 2、3.5 变成 4，在 0.5 这个点上永远往偶数那边靠。
  2. 小数在电脑里存不准（第 8 篇讲过的浮点精度问题）。2.675 在电脑里真实的值其实是 2.67499999...，所以被「舍」掉了，得到 2.67。
实用结论：round() 拿来做「显示」很好，拿来做「精确计算」不行。算钱、算成绩这类要求严格的地方，要么先放大成整数算完再缩小（round(2.675 * 100) / 100），要么用专门的 decimal 模块，别指望 round()。
另外小数点后的位数只影响显示时，其实可以交给 f 字符串：f"{3.14159:.2f}" 得到 '3.14'（第 10 篇讲过）。

9.4 type() 和 isinstance()

isinstance() 示例里没提，但判断类型时比 type() 更常用，顺便认识一下。

对比项type(x) == intisinstance(x, int)
问的问题「它就是 int 类型吗」「它算不算 int 这一类」
子类算不算不算算
举例type(True) == int → Falseisinstance(True, int) → True
一次查多种类型要写好几遍isinstance(x, (int, float))
做类型判断优先用 isinstance()，它更宽松也更符合直觉。为什么 isinstance(True, int) 是 True？因为在 Python 里，真假值本身算整数的一个小分支——这也是 True + 1 等于 2 的原因（第 8 篇提过）。

函数返回的是能直接 print 吗能取下标吗怎么办

  • D. 报 ValueError: max() iterable argument is empty
答案：D。空的东西里挑不出最大值，Python 会报 ValueError 而不是猜一个 0 或 None 给你。如果数据真可能为空，要提前给个兜底：max([], default=0)。这也是为什么打分、比大小的代码要先判断列表是不是空的。
