## 功能说明

### 链接管理

- 点击「添加链接」按钮可创建新的导航链接，需填写**链接标题**和**链接地址**
- 支持对已有链接进行编辑
- 删除链接时需要二次确认，且删除后无法撤销
- 当没有导航链接时，页面会显示空状态提示：「暂无导航链接，点击上方"添加链接"按钮开始创建」

### 其他特性

- 页面顶部实时显示当前日期与时间（自动同步）
- 暖灰极简主题设计，支持响应式布局
- 阻止浏览器缓存 HTML，确保每次访问都是最新版本
- 数据存储在本地，可通过「下载保存」导出
